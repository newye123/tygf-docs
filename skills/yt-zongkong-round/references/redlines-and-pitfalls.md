## B. 假结果形状（写判据、下结论前先对照）

1. **管道后的退出码不是命令的**：`git ... | head` 的 rc 属于 `head`。要取码就直接取码。
2. **`node` 里 fetch 失败但 `curl` 通**：站端读数一律走 `curl`（本 skill 的脚本就是这么写的）。
3. **`spawnSync` 超时会伪装成业务失败**：给足 timeout，并把 timeout 与 rc 分开报。
4. **临时路径**：`node -e` 里写 `/c/Users/...` 会解析成 `F:\c\...` 报 ENOENT ⇒ 只用 `os.tmpdir()`。
5. **反引号在双引号里会被当命令执行**：正文一律用 Write/Edit 落，不用 shell 引号拼。
6. **CRLF 树**：autocrlf 使"按字节哈希"自检出现 blob 命中／工作树不命中＝**环境红**，不记产品红；还原用 `git cat-file blob`。
7. **负控按 `\n` 改文件**在 CRLF 树下静默失配＝假绿 ⇒ 按不含换行的子串改，先证锚点唯一，同脚本内还原。
8. **`git grep -- <不存在的路径>` 的 rc=1 会冒充"0 命中"** ⇒ 先 `git ls-files` 证路径在。
9. **`git log -G` 不吃 PCRE**，且把非零码当 0 ⇒ 门禁会永久假绿。
10. **判 git 忽略只能用 `git check-ignore -v`**，grep 规则文本会漏前导 `/`。
11. **状态码／字节数未标定不得当判据**：200 可以藏 `valid:false`；两条 403 文案字节可以相等；`ticket/verify` 凭证无效也返 200。
12. **判"谁在写"已无只读手段**（`updatedAt` 与 mtime 矛盾、日志 mtime 会全体刷新）⇒ 只信文件 mtime ＋ git 现场。
13. **台账钟点可被文件自己的 mtime/ctime 证伪**：先自证时钟（新建文件比 `date` 与 `stat`），ctime≥mtime 同秒＝普通写入形状；"已授权／已发生"这类决定副作用的句子必须先跑这一条。
14. **禁止无出处的否定式断言**：说"没有 X"要给清单行号或实测 0 命中的命令＋真实退出码，否则只能写「未核实」。
15. **引他人言行须给刚 grep 到的 `file:line`**；口头汇总要拿他自家台账行去对（附 mtime）。
16. **计数正确≠计数对象正确**：判"某取值不存在"要给写入面落点＋域出处（schema 注释不是权威域）；只有一个 group by 时只许写"当前实测 0 行"。
17. **两点计数冒充区间**（开工 2→交包 2）⇒ 红线自证要逐时点写；交包后用 `log --all --since`／`-S`／porcelain 三条只读命令定性，归属写"未核实"。
18. **置顶追加会吞标题**：锚点别用旧条目标题行；改完必查 `diff` 纯增量＋标题计数。
19. **`round.lock` 的 `owner` 字段每轮被覆写⇒不可信**，只认锁目录 mtime；抢锁失败≠项目停摆。
20. **`git apply` 在仓库子目录里按仓库根解析路径** ⇒ rc=0 却静默 no-op；复现补丁要自己 `git init` 空仓，事后 grep `+` 侧关键字。`git apply -R` 会连补丁里新增的文件一起删。
21. **在飞判据**：`ExecutionBatch` 无 RUNNING ＋ `CreditReservation` 无 `reserved`；**不得单用 `attempt.state`**（已知永久假红）；判"跑了几语"只数产物。
22. **两站日志**：共用一份 `access.log` 且无 `$host` ⇒ 状态码不能按站归属；测试站在 `tygf-test/logs/out-0.log`；源站 nginx＝CST，助手日志＝UTC（差整 8 小时）。

23. **会话 ID 不许手写**：任何 `send_message_to_chat_session`／`fork`／`read` 的 `sessionId` 只能取自**本轮 `list_chat_sessions` 的返回值**（13 位毫秒 `updatedAt` 顺带证明它是活的）。心跳轮 4 编了一个补零 ID `149d2185-0000-…` ⇒ 平台报"不存在或已归档"。**这是第 17 条（出处只能是本会话刚跑的那条命令）在 ID 上的形状**：短前缀好记、补零看着合法，比记错更危险，因为它会静默投给一个不存在的对象，看上去像"对方没回"。
24. **引别人产出的状态，只认"作者自标的当前状态"**：字节数/mtime 变了 ≠ 状态变了（今天 MERGE-ORDER 三次改体积、最后一次才在首行自标"不作执行依据"）。裁决件必须写"取数时刻＋引的是哪一版"，并带失效条件。
25. **`round-scan.mjs --since` 的真因是「参数格式 ⇒ NaN ⇒ 静默空表」（15:1x 二次更正）**：`new Date(SINCE.replace(" ","T")+":00+08:00")` 只吃 `HH:MM`，**传带秒的 `HH:MM:SS` 会拼成非法串 ⇒ NaN ⇒ `mtime>=NaN` 恒假 ⇒ 印成 `(none)`**，看起来像"没人交件"。我 14:4x 把它误诊成"窗起点取错"，正因由心跳轮 14 追加更正给出并复现（同一条命令 `14:32:46`⇒空、`14:32`⇒两件齐全）。**已修**：脚本现同时吃 `HH:MM` 与 `HH:MM:SS`，解析不出即 **rc=2 并打印用法**（负控实测：`今天 14:32` ⇒ rc=2）。**教训：判工具坏了之前先跑两条对照命令换参数形状；报了因也要允许自己被证伪——我这条错因还写进了 cron 与记忆。**
