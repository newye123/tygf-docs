# 图译工坊：10 套不同宣传策略的完整 HTML 原型

版本日期：2026-10-27

## 打开方式

1. 解压整个文件夹。
2. 用 Chrome、Edge、Firefox 或 Safari 打开 `index.html`。
3. 在总览页点击任意方案的「打开完整 HTML」。
4. 每套原型顶部和底部都有导航，可切换首页及 8 个内页路由。

每套都是单文件 HTML，不依赖外部 CSS、JavaScript 库、图片 CDN 或构建工具。页面可离线查看。点击官网政策、下载页等明确标注的外部链接时，会打开图译工坊正式网站。

## 每套包含的页面

- 首页
- 交互演示
- 证据与案例
- 工作台模拟
- 下载与环境要求
- 数据处理说明
- 试跑申请模拟
- 账户与设备模拟
- 积分与计数口径说明

## 十个方向

1. `01-cinematic-journey.html`：电影叙事，以流程故事解释重复操作与复核。
2. `02-interactive-photoshop.html`：编辑器现场，先体验仿编辑器和语言切换。
3. `03-evidence-dossier.html`：调查档案，优先解释报告数字的证据边界。
4. `04-persona-branching.html`：角色分镜，按设计师、负责人、服务商分流。
5. `05-mission-control.html`：任务塔台，以多语言状态矩阵解释异常管理。
6. `06-creative-lookbook.html`：创意画册，以商品视觉和语言延展切入。
7. `07-workshop-learning.html`：交付课堂，以练习和知识内容获客。
8. `08-data-trust-map.html`：数据透明，以数据流和处理边界建立信任。
9. `09-time-economics-lab.html`：工时实验室，用可被推翻的模型讨论 ROI。
10. `10-fit-first-diagnostic.html`：适配诊所，先判断输入条件再引导试跑。

## 重要边界

- 这些页面是完整的前端概念原型，未连接正式账号、支付、任务队列、Photoshop、本地助手或官网申请后端。
- 所有示意账户、状态、文件名、任务数据和 UI 数字均为模拟内容。历史报告摘要在原型中会明确标出需要回到原件复核。
- 试跑表单只在当前浏览器中生成本地摘要，不会把内容提交到服务器。若要正式申请，请使用官网真实入口。
- 不要将仿编辑器、数据流图、工时计算器或任务状态截图当成真实产品截图或实际测试结果。
- 页面中公开的兼容信息和数据处理说明以本轮访问的正式网站为依据，发布前仍需确认版本和政策是否变化。
- 原型加入了不同的内页视觉模块，但不代表这些功能已经在产品端实现。

## 设计与审查文件

- `DESIGN_AUDIT.md`：对抗式审查方法、每个方向的假设与风险。
- `FACTS_AND_RISKS.md`：已确认事实、待验证事项、关键风险与发布门槛。
- `QA_REPORT.md`：本轮静态代码检查结果和未完成的浏览器验证项。
- `SOURCES.md`：项目官网与非中文官方方法资料来源。
- `manifest.json`：十套方案的机器可读清单。
- 本包以最终 HTML 为交付物。要修改页面，可直接编辑 `sites/` 中的独立 HTML 文件。
