## 尚未完成的检查

**真实浏览器交互与视觉 QA 尚未完成。** 本轮执行环境中的 Chromium 自动化导航被环境策略阻断，因此没有把它记为浏览器通过。原型的 JavaScript 语法、页面结构和链接关系已做静态检查，但还需要在真实 Chrome、Edge 或 Firefox 中验证以下内容：

1. 首页 CTA 和九个路由的实际切换。
2. 语言切换、角色分流、工作台步骤、筛选、计算器和本地表单的运行状态。
3. 320、390、768、1440 CSS 像素宽度下的横向溢出、标题换行和卡片重排。
4. 键盘导航、焦点可见、表单验证提示和屏幕阅读器标签。
5. 各浏览器对 `scroll-behavior`、`position: sticky`、渐变、CSS 网格和表单下载行为的差异。

## 当前交互边界

- 表单：仅在浏览器内生成申请摘要；没有真实提交。
- 工作台：仅切换示意步骤；不读取本地文件、不连接 Photoshop。
- 语言、角色、筛选和问答：仅改变前端演示内容。
- 计时模型：使用人为设定的演示假设；不是历史项目统计。
- 账户与积分：没有后端、登录、计费或授权动作。

## 上线前建议的验收标准

- 所有主要 CTA 都到达预期路由或正式页面。
- 任何模拟数据在第一视线内有清晰标签。
- 320 CSS 像素宽度下，除确需二维展示的表格外，不要求用户横向滚动整页。
- 所有交互都可通过键盘完成，焦点可见。
- 正式表单接通前，不显示“已提交”或“申请成功”。
- 正式产品截图、案例数字和数据流文案经过产品、技术、交付和授权负责人审核。
