## 如何查看

直接用桌面版 Chrome / Edge 打开 `tuyigf-complete-v10.html`。单文件内置 CSS、JavaScript、SVG；无需安装 Node、调用 CDN 或联网。地址栏中的 `#/home`、`#/app/typography` 等为浏览器内的模拟路由。可使用右下角主题切换器对比石白鸢尾、暖灰陶土、冷灰青绿三组配色。移动端主题切换器默认隐藏以减少遮挡，工作台设置页仍可切换。

## 关键交互

首页右侧点击 PSD 文件与语种切换，展示其独立字体与排版示例。下方 2×3 矩阵的每个单元格也可点选。

进入工作台 `#/app/typography`：
1. 选择项目、文件和语种。
2. 指定作用域：仅这份 PSD，或语言默认规则。
3. 设置字体、字号 pt、字距（Photoshop 1/1000 em 单位）、行距 pt、自动字距方式。
4. 保存并切换同一语言的另一份 PSD，验证设置独立。
5. 选择“恢复语言默认”取消具体文件覆盖。
6. “导出模拟规则 JSON”下载浏览器中当前演示设置。

“新建任务”五步向导包含设置字体的步骤，保存后可在确认摘要中看见每种语言的生效规则。创建任务后，在任务详情能查看字体规则快照。

CSV 演示与异常列表支持局部操作，真实运行不在本 HTML 范围内。

## 已知限制

- 这是一份完整的交互设计概念原型。浏览器不能扫描 PSD 图层、枚举 Photoshop 安装字体、修改实际 PSD、生成真实 JPG、验证文件保存或执行真实收费。
- 字体下拉列表为演示候选名称。浏览器预览的字体可能回退，不能当成 Photoshop 渲染证明。
- 本地演示数据保存在 JavaScript 运行状态；当浏览器策略允许 localStorage 时会同时保存在该浏览器的本地存储。隐私浏览、严格文件安全策略或运行在不可信 origin 时可能限制持久化。
- `#/pilot` 仅生成本地摘要，不会发送给图译工坊。
- 团队协作、账单、权限等产品页仍为未来真实系统的数据结构和 UI 概念。
