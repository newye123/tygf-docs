THE PROBLEM / 你每天遇到的事

多语言改稿，耗时通常
花在这些重复环节。

译文已经审核过，设计师仍要寻找图层、反复设置字符样式、检查漏改和导出。语言越多，工作越容易变得碎片化。

01 · FIND
▦　Hero / Headline TEXT
▦　CTA / Shop now ?
▦　Footer / Shop now TEXT

图层与译文对不上

一个“Shop now”出现在多个位置，表格和 PSD 很难只靠原文自动对应。

方案：对象级对账，歧义留给人工
02 · REPEAT
DEFRJAES
同一套文件反复修改

每个语言都要再做一遍

复制文件、逐层粘贴、检查与导出，每增加一个语种就重复一组操作。

方案：同一任务组织多个语言
03 · TYPE
Lightweight design
Leichtes, kompaktes Design
Font / Leading / Tracking

字体和版式需要重新调整

德语长词、日语字形与不同详情页版式，需要逐文件设定字体及字符参数。

方案：PSD × 语言独立排版
04 · CHECK
● 已匹配 待执行
▲ 重复原文 待确认
○ 不可编辑 保留原文

交出去之前没底

漏改、错配与字体风险分散在不同文件里，逐个打开检查容易遗漏。

方案：异常集中处理，结果保留记录
