HOW TO USE / 使用方法

四步完成一次多语言 PSD 任务。

从已有译文和本机设计稿出发，先核对对象，再配置字体，最后执行并检查交付。下面的界面使用模拟样例解释每个阶段。

进入任务创建向导 ↗先体验字体设置 ↗
01 / INPUT

准备 PSD / PSB 和译文表

选取设计文件夹，导入已有译文表。原文可对应 DE、FR、JA、ES 等语言列。准备阶段只读取所需信息，源文件应保持不变。

02 / MATCH

检查图层与译文的匹配关系

按对象检查已匹配、重复原文、空译文和无法可靠处理的图层。需要设计师决定的地方明确标出，避免未经确认的匹配。

03 / TYPOGRAPHY

为每份 PSD 的每个语种设置样式

指定字体、字号、字距、行距与自动字距。保留语言默认预设，也能为具体 PSD 覆盖设置，互不干扰。

04 / EXECUTE & QA

由本地 Photoshop 处理并检查

提交已确认的任务，本机写入并读取核对。交付时检查异常、保存结果与最终视觉，输出 PSD、JPG 和记录报告。

先确认 Photoshop 运行条件

正式使用需要 Windows、已安装的 Photoshop 与官方本地助手。浏览器示例不读取真实 PSD、不枚举本机字体、不执行文件写入。不同 PS 版本和复杂图层结构应通过官方兼容性说明与实测确认。

THREE LEVELS OF CONTROL

三层优先级，
保证规则明确、避免相互覆盖。

BASE / ORIGINAL

原稿保留

默认不主动修改字号、字距、行距与字体。需要替换时由用户明确指定。

PRESET / LANGUAGE

语言默认设置

例如日语默认使用某款字体，德语使用另一款。不同语种独立记录。

OVERRIDE / FILE × LANGUAGE

PSD 独立覆盖

同是德语，主图可使用 32pt 字号，详情页使用 22pt；覆盖只影响这一份文件的该语言。

BEFORE EXECUTION

确认生效规则

在执行前检查使用的是语言默认还是单文件覆盖，避免批量处理时发生无意的样式变化。

TYPOGRAPHY SETTINGS

五类字符参数，都能清楚调整。

字体 / Font Family实际可用字体需由本机 Photoshop 确认
字号 / Font Size明确 pt 值，或保留原稿
字距 / Tracking使用 Photoshop 的 1/1000 em 计量方式
行距 / Leading明确 pt 值，或保留原稿
字偶距 / Kerning保留原稿 / 度量 / 视觉，具体可用性需实测

预览可能因浏览器字体缺失出现回退。保存浏览器规则仅影响本地演示状态；还需通过 Photoshop 验证字形、复合字体、缺字、禁则与溢出风险。

一份 PSD 的字体设置变化，不会自动修改项目里其他 PSD。

选择项目 → 选择设计文件 → 选择语言 → 设置字符参数 → 保存。需要统一调整时，可以修改语言默认值；已经设置独立覆盖的文件仍保留自己的值。此规则在工作台模拟中可以直接操作。
