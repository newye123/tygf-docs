# 图译工坊对抗式官网审查报告
日期：2026-10-27。范围：公开官网、下载说明、操作指南、隐私政策、第三方处理方清单、用户协议、中英文页面及现有 V3 原型。限制：不是渗透测试、源代码审计或法律意见；未访问后台、安装包内容、真实表单提交或生产网络流量。

## 决策问题
目标客户能否理解产品用途、判断 PSD/PSB 适配性、理解数据流，并完成可信的试跑申请？

## 已确认事实
- 产品定位是已有译文的多语言 PSD/PSB 文字图层替换与交付工作流。
- 公开页面称单批最多 12 个目标语种。
- 下载页列出本地助手 v3.7.15、Windows 10/11 64 位，并称 Photoshop 2021（22.0）已实机验证，其他版本未逐项验证。
- 公开说明称 PSD/PSB 文件本体和替换后图像在本机处理；图层文字、译文表原文与译文、设计稿路径等会离开本机。
- 第三方处理方清单列出自有服务、DeepSeek 文本生成 API、腾讯云 SES、Cloudflare 和 PaddleOCR API；清单称 PaddleOCR 当前尚未接入产品流程。
- 当前任务 UI 标注为示意界面。
- 首页上方示意状态为 43 已核对、3 需要判断、1 执行失败；下方显示总计 48、43 完成、3 需要判断、2 无法处理或失败。计数不一致。
- 下载页要求比较 SHA-256，但本次可读取页面内容中未看到实际校验值。
- 处理方清单说明运营主体信息未在该页面公示。
- 用户协议说明服务处于 Beta 阶段。
- 当前公开页面有中英文首页、下载页、隐私政策、处理方清单和用户协议。
- Pinterest 搜索链接本次返回 403，无法查看具体 Pin 图。

## 高优先级发现
### F-01 示意计数不一致
严重程度 P1，置信度高，已证实问题。首页出现 43+3+1=47 与 48、43+3+2=48 两种口径。影响：削弱对报告统计逻辑的信任。修复：所有状态由单一数据源生成并定义状态是否互斥。验收：每页总数等于分项总和，中英文一致，示意标签清楚。

### F-02 SHA-256 校验值不可见
严重程度 P1，置信度中高，信息缺口。下载页要求比较 SHA-256，但可读取内容中未看到实际校验值。修复：发布负责人提供版本对应的真实校验值、文件名和发布日期。验收：下载文件计算值与页面值一致。

### F-03 数据处理信息出现较晚
严重程度 P1，置信度高，信任风险。首页强调文件本体留在本机，文字、译文、路径和第三方 AI 处理范围主要在 FAQ、隐私政策和处理方清单说明。风险：用户误解为所有数据都不离开本机。修复：首页首屏下方与试跑入口增加简明数据披露。验收：访客能说清文件本体、文字数据、路径与第三方 AI 的区别。

### F-04 本地助手与浏览器信任边界待技术核验
严重程度 P1，置信度中，风险假设，尚未证实漏洞。公开下载说明称本地助手通过 127.0.0.1 与网页工作台通信。验证：检查绑定地址、来源校验、授权、CSRF、防重放、请求结构、任意文件访问和错误日志。验收：有可复现测试，未经授权请求无法触发受保护操作。本次没有执行渗透测试。

### F-05 第三方 AI 数据保留需进一步解释
严重程度 P1/P2，置信度高，待验证风险。公开清单称智能检测会向第三方模型发送图层原文和当前译文，保留期以第三方政策为准。修复：确认 API 数据使用条款、日志、保留、触发条件和可选关闭机制。验收：数据流图、处理方清单和产品行为一致。

## 中优先级发现
### F-06 中英文页面同步机制不足
英文 FAQ 对状态定义有更多解释，计数问题同时存在。维护统一事实表和术语表。

### F-07 兼容性在转化入口不够突出
下载页列出 Windows 10/11 64 位、Photoshop 2021（22.0）已验证。首页、适用范围和试跑入口应显示摘要。

### F-08 缺少公开的最终 QA 案例证据
当前页面主要使用示意 UI；已有报告存在待复核、未覆盖、未命中等状态。完成去重、输出检查、逐语言 QA、完整工时与授权后再发布。现有材料不足以确认任何候选案例已通过发布门槛。

### F-09 试跑商业规则不够明确
已检查页面未给出统一费用、交付物和响应时限。运营负责人需明确并公开。

### F-10 企业信任材料不完整
处理方清单称运营主体信息未在该页公示。确认运营主体、服务联系渠道与采购所需材料。

### F-11 智能学习范围与退出机制需要更清晰
政策说明注册时视为同意处理去标识化排版特征数据。产品、隐私和法律负责人需确认处理对象、目的、保留期和选择机制。

## 待验证事项
- 线上表单是否提交成功、是否有邮件通知、反垃圾和错误状态。
- 登录、重置密码、邀请码注册和工作台路径的实际状态。
- 安装包可用性及 SHA-256 是否在其他位置发布。
- 当前版本兼容性与语言处理边界。
- robots.txt、sitemap.xml、结构化数据、分析事件和 SEO 索引状态。本次工具无法读取 robots.txt 与 sitemap.xml，不能据此判断它们不存在。
- 页面键盘可访问性、移动端溢出、性能、网络请求和安全头。
- 是否有完成最终 QA 并获授权的公开案例。
- 真实访客、试跑申请、合格线索与付费转化数据。

## 执行顺序
1. 统一示意计数并补齐真实 SHA-256。
2. 在首页和试跑入口披露数据流与兼容性。
3. 对本地助手 127.0.0.1 接口做专项安全审查。
4. 确认第三方 AI 处理范围、运营主体、试跑费用和响应时限。
5. 对报告去重，选一个候选项目完成最终 QA、工时记录和授权。
6. 发布真实案例和操作录屏。
7. 接通表单、邮件通知、登录、下载、工作台和分析事件。
8. 完成 SEO、移动端、无障碍、性能和回滚检查。
