# 上线执行与验收清单

- [ ] 确认单批 12 个目标语种的定义和限制。
- [ ] 确认 54 种语言名称识别口径，不与排版支持混淆。
- [ ] 确认 Windows / Photoshop 支持范围。
- [ ] 实测栅格化文字、智能对象、长译文、RTL 和特殊字体。

## 隐私与安全
- [ ] 绘制浏览器、本地助手、Photoshop、自有服务、AI API、邮件服务和 CDN 数据流图。
- [ ] 确认图层原文、译文、路径、诊断和账号信息的传输触发条件。
- [ ] 确认第三方 AI 数据使用条款、日志和保留规则。
- [ ] 检查路径字符串是否包含客户名或项目名。
- [ ] 审查本地助手 127.0.0.1 接口的来源校验、授权、输入校验和异常处理。
- [ ] 确认智能学习范围、同意方式、保留期和退出后果。
- [ ] 核对运营主体、服务邮箱、删除渠道和处理时限。

## 案例
- [ ] 按源文件、项目 ID、批次和日期去重。
- [ ] 确认输出文件存在并逐语言打开。
- [ ] 区分回读验证和视觉 / 语言 QA。
- [ ] 处理或解释未覆盖、未命中、疑似未翻译和版式待复核项。
- [ ] 记录准备、执行、异常、返工和最终 QA 的完整工时。
- [ ] 确认授权、脱敏和素材许可。

## 转化
- [ ] 明确试跑费用、范围、交付物、响应时间和后续流程。

- [ ] 提交后有真实通知或 CRM 记录。
- [ ] 申请有明确负责人和下一步时限。
- [ ] CTA、演示、下载、登录和政策链接指向真实入口。
