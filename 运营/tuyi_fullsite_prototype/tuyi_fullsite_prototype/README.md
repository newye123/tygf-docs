# 图译工坊全站 HTML 模拟包
版本：2026-10-27。用途：页面结构、文案、交互和审查流程的静态原型，不连接生产环境。

## 打开
解压 ZIP，保持 assets 目录与 HTML 文件同级，双击 index.html 打开中文首页；英文首页为 en.html。可打开 prototype-map.html 查看全站原型目录。

## 页面清单
中文公开页面：index.html、workflow.html、guide.html、demo.html、scope.html、faq.html、trial.html、download.html、privacy.html、subprocessors.html、terms.html。
英文页面：en.html、en-download.html、en-privacy.html、en-subprocessors.html、en-terms.html。
账户与产品 UI：login.html、register.html、reset.html、workbench.html、task.html、report.html。
内部模板：case-template.html。

## 边界
- 表单只显示静态原型提示，不发送数据。
- 登录、注册、密码重置、下载、工作台和报告没有连接真实服务。
- 示例计数统一为 48 = 43 + 3 + 2，并标注为示意数据。
- 隐私政策、处理方清单和用户协议页面为摘要或结构模拟，正式上线须同步完整现行原文。
- 没有新增客户案例、评价、效率百分比或价格承诺。
- Pinterest 搜索链接本次访问返回 403，未直接复制 Pin 图；视觉沿用官网低饱和绿色、浅色背景、圆角导航和克制留白。

## 建议顺序
1. 修复线上示意计数不一致，补齐真实 SHA-256。
2. 技术负责人确认兼容性、12 语种上限、数据流和本地助手安全边界。
3. 运营 / 隐私负责人确认试跑费用、响应时限、数据告知、运营主体和联系渠道。
4. 完成一个真实项目的去重、最终 QA、工时记录和授权。
5. 用真实录屏、产品截图和审核通过的案例替换示意素材。
6. 接入表单、下载、登录、工作台、分析事件、SEO 元数据和真实链接。
