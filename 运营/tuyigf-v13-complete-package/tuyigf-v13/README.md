# Tuyi Workshop V13

This package contains a single-file HTML prototype for the full public website and interactive simulated workbench.

## Open
Open `tuyigf-v13-fullsite.html` in a modern desktop browser. The file includes CSS, JavaScript and embedded screenshots. No external JavaScript or CSS packages are required.

## Main routes
- `#/home`: public homepage
- `#/how`: four-step workflow
- `#/typography`: typography rules
- `#/cases`: PSD stress-test method
- `#/security`: data boundaries
- `#/studio/single`: screenshot-faithful single-design workflow
- `#/studio/batch`: screenshot-faithful batch workbench
- `#/studio/type`: typography drawer
- `#/app/overview`: full SaaS workspace overview
- `#/app/tasks/new`: four-step simulated task wizard
- `#/app/typography`: project x file x language typography matrix
- `#/app/quality`: issue review
- `#/app/deliveries`: delivery center

## Simulation boundary
The browser prototype can read CSV/TSV/TXT text locally, create simulated tasks, save simulated typography rules in localStorage, record issue decisions and export a clearly labeled simulated HTML report. It does not parse PSD/PSB layers, connect to Photoshop, enumerate installed fonts, write PSD files, create genuine JPGs, charge credits or submit a real application.

## Source basis
The UI reproduces the user's supplied six workbench screenshots and preserves the V12 page architecture. It also uses the supplied execution report as a reference for quality-state distinctions. It does not claim the sample report proves final visual quality.
