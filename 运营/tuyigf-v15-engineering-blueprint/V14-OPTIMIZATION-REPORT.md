# Tuyi Workshop V13 → V14 优化审查报告

## 结论

V13 的四阶段单稿流程、批量文件队列和独立字体抽屉具备可用的产品结构。此次升级保留原有信息架构与视觉基调，集中处理流程越级、检测结果表达、风险重复、交付范围不明确、批量状态串用和字体抽屉的信息密度。

## V13 中识别出的主要问题

1. 单稿步骤导航允许直接跳转到后续阶段，前置条件没有被强制校验。
2. 检测表的语言列与当前语言之间缺少严格映射，容易把错误列当作目标语言。
3. 重复原文、原文未变、数字缺失等风险缺少统一摘要，用户需要逐行寻找重复提示。
4. 设计稿校对阶段的示例风险容易被误读为真实 PSD 扫描结果。
5. 交付页把语言范围、输出数量和费用信息放在一起，固定示例数值容易被误认为实时报价。
6. 语言选择按钮没有完整影响输出范围，存在选择状态与交付摘要脱节的风险。
7. 批量步骤可越级，且批量报告状态可能继承单稿报告状态。
8. 字体抽屉中的参数缩写较多，基础参数与高级参数没有分层，关闭抽屉时可能丢弃未保存修改。
9. 部分生成报告模板在脚本字符串中直接出现 HTML 的 `</script>`，会提前结束外层脚本标签，导致部分独立入口的脚本解析异常。

## V14 实际调整

### 1. 流程约束

- 单稿四阶段增加前置条件：先选择真实 PSD / PSB 文件或明确使用示例文件，再记录文件名并导入可解析译文表，才能进入检测；检测确认后才能进入校对；人工确认风险后才能进入交付。
- 后续步骤锁定，已完成步骤允许返回。
- 批量工作台增加独立的检测、审阅和报告状态，避免单稿状态污染批量任务。

### 2. 智能检测

- 按导入表格实际包含的语言列生成语言选择项。
- 汇总空译文、与原文相同、重复原文组和数字待核数量。
- 增加“只看待复核项”过滤。
- 重复原文仍保留行级定位，同时在摘要中汇总组数。
- 明确提示数字格式、单位转换、品牌名和型号可能有意保留，风险信号不自动等同于错误。

### 3. 设计稿校对

- 将版本差异、重复原文、数字与单位、版式变化拆成独立风险类型。
- 明确区分译文表解析、PSD 图层扫描、Photoshop 连接、对象匹配和最终视觉批准。
- 当前原型未连接本地助手，因此所有相关状态明确显示为未执行或示例。

### 4. 生成交付

- 增加目标语言多选、全选和仅当前语言操作。
- 交付摘要显示目标语言数、译文行数和计划规模参考。
- 删除固定积分估值，正式费用需读取生产系统实时报价。
- 单稿和批量报告分开生成，报告明确标记 SIMULATED ONLY。

### 5. 字体抽屉

- 参数拆分为基础排版和高级排版。
- 将“字、体、号、行、距”等缩写改为完整字段名。
- 增加单位提示、浏览器预览和保存反馈。
- 清除与重置操作增加确认，关闭时检查未保存修改。
- 设置仍只保存在浏览器 localStorage，不写入 PSD。

### 6. 代码与兼容性

- 修复生成报告模板中的嵌套脚本闭合问题。
- 使用独立 V14 localStorage 命名空间，避免 V13 原型状态污染。
- 增加移动端工作台与字体抽屉的响应式布局。

## 验收结果

- HTML 结构、重复 ID、页面路由和内嵌截图检查通过。
- 所有 HTML 入口的内联 JavaScript 语法检查通过。
- CSV / TSV 解析回归测试通过。
- 单稿流程门禁、批量流程门禁通过。
- 四类检测信号的数量统计和只看问题过滤通过。
- 字体抽屉保存流程和移动端渲染通过。
- 单稿、批量模拟报告下载通过。
- 浏览器运行期间未发现页面级 JavaScript 错误或控制台错误。

## 尚未实现的生产能力

V14 仍是前端交互原型。PSD / PSB 选择只记录文件名，未读取图层；未连接 Photoshop 或本地助手；未枚举本机字体；未执行真实文字写入、读回、保存重开和 JPG 输出；未接入认证、计费和实际文件目录。上述能力需要独立的本地执行服务、文件读写权限、Photoshop 脚本接口和可审计的执行日志。

## 下一阶段建议

优先做真实数据链路，不建议继续叠加装饰性 UI。建议按“PSD 只读解析 → 译文表绑定 → 图层匹配与冲突队列 → 单对象写入 → 读回验证 → 保存重开 → JPG 导出 → 人工终检”逐步接通，每一阶段保留输入、输出、失败原因和证据。
