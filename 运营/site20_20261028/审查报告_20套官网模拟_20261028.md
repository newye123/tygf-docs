## 三、逐项核查通过的（不是缺陷，但不查不敢说）

1. **单字不成行**：20 套 × 中/英 × 1440/1024/768/390 = 160 次页面视图，`node review-lines.mjs` → `files with issues: 0 instances: 0`。做法是 CSS `text-wrap: pretty` + 段末 `nowrap` 锁字 + 加载后逐字符 Range 测量，字体变化/切语言/缩放都会重跑。
2. **没有编造的营销证据**：全套没有客户数量、客户 logo、用户评价、认证、奖项、效率百分比。「100%」只出现在 CSS 的 `width:100%`。
3. **绝对化表述**：全文抽出 8 句含「保证 / guarantee / never / 绝不」的独立句子，逐句读上下文，全部是边界说明或否定语境（例如「要求所有 Photoshop 版本、所有复杂结构都保证可用」是在描述**做不到的期待**；「It is not a compatibility guarantee」是在**否认**兼容承诺）。
4. **示意标签密度**：每页 16–28 处「示意」（英文页 18–36 处 `schematic / illustrative / not a real` 类标记），全部页面首屏之后 1 屏内必出现一处。
5. **英文文案**：439 条英文串，机检 0 处双空格、0 处标点后缺空格、0 处重复词；9 条「小写开头」逐条查看，全部是被 `<span>` 拆开的句中片段，不是句子开头。
6. **页脚外链**：`tuyigf.com` 首页 / `/download` / `/privacy` / `/privacy/subprocessors` 四个地址 2026-10-28 实测全部 `http=200 rc=0`，无死链。
7. **零外部依赖**：20 个站点里外部 `<script src>` / `<link href>` 数量为 0，无外部字体、无外部图片，完全离线可开。
8. **同质化（量化，不含主观分）**：两两模块重合度平均 0.429，最高 0.750（03 与 17），**没有任何两套模块顺序完全相同**，首屏视觉 20 套 20 种，宣传主轴 19 类（18 画册与 19 宣言同属品牌轴，靠排版与语气区分）。
