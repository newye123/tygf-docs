01判定

结论

有条件放行——作为「挑方向的模拟件」可以放；作为「直接上线的官网」不行。
不放的原因是两件具体的事：视频位还是示意动画，断行只在本机 Chrome 上验过。

可以信任的部分

  • 没有编造营销证据：全套零客户数、零客户 logo、零评价、零认证、零效率百分比。「100%」只出现在 CSS 的 width:100%。
  • 单字成行确实是 0：20 套 × 中英 × 1440/1024/768/390 共 160 次页面视图，实测 0 例。
  • 演示真能点：12 项交互全部通过，包括批量表格跑批、排版实验室、长文断行回读、自查问卷、工时重算、语言切换。
  • 完全离线：20 个站点里外部脚本、外部样式、外部字体、外部图片数量均为 0。

不能当成能力证据的部分

  • 每一处产品界面都是 CSS 画的。每页 16–28 处「示意」标注撑着这条边界；删掉标注，它就变成了一张假截图。
  • 视频位是示意动画，不是录屏。页面上写了，但真实投放时读者会跳过这行小字。
  • 「12 稿 × 12 语」是画出来的，未对生产环境逐条实测——这属于产品侧口径核对，不在本次范围。
