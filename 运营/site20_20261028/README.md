# 图译工坊 · 22 套官网模拟（2026-10-28）

## 这是什么

22 个独立的单文件 HTML 官网模拟件，中英双语，每套含 4 个视图（首页 / 演示 / 适配自查 / 申请）和可点可玩的产品演示。

全部离线：不加载外部脚本、外部样式、外部字体、任何图片文件。所有产品界面都是 CSS 画出来的示意图，不是真实截图——每页有 20–25 处「示意」标注（英文页 21–35 处）。

**用途是挑方向，不是上线成品。** 选定方向之后，视频位要换成真录屏，文案要按最终口径重写。

## 怎么看

1. 打开 `index.html`——22 张卡片 + 缩略图的一览页。
2. 或者直接开 `sites/XX-名字.html`。
3. 右上角「中 / EN」切语言，选择会记住（localStorage `tygf.site20.lang`）。
4. 站内用地址栏直达：`#/home` 首页、`#/demo` 演示、`#/fit` 适配自查、`#/apply` 申请。
5. 整页截图在 `screens/`；`screens/contact-zh.png` 和 `contact-en.png` 是 22 套的一览联系表。

## 22 个方向

模块缩写：**流程** = 阶段说明；**能力** = 功能卡片；**适配** = 什么样的稿能跑、什么不能；**证据** = 证据边界与可核对字段；**问答** = 常见问题；**排版** = 可调的字体/字重/行距/字距实验室；**12×12** = 12 份稿 × 12 种语言的批量表格；**痛点** = 长文痛点叙事；**换行** = 长文案窄层断行回读；**立场** = 产品态度长文；**行动** = 收尾的行动号召；**逐站点** = 换一个站点后版面上会变什么（分语种页签）；**行前核** = 开跑前的六项检查清单；**分工** = 七段活分别归谁（可点换人）。

## 文案口径：不写「不是…而是」

首屏和正文一律不用「不是 A，而是 B」「Not X, but Y」这类修辞对立句——它把句子写成辩论，读者拿不到信息。写法改成直陈：先说会发生什么，再说边界。

机检脚本 `_build/review-copy.mjs` 用 7 条模式扫源文件和生成的 22 套页面，当前 **0 命中**；负控（临时塞入 3 句违规文案）**3 命中、退出码 1**，证明这条闸不是空转。

保留的例外只有一类：给数字和主张加诚实限定，例如「not a real screen recording」「not efficiency claims」「not evidence of capability」——共 12 处，逐条列在脚本输出里。这些句子去掉就会变成假话，所以按关键词放行。


## 单字不成行（硬规则）

中日韩正文不允许一行只剩一个字，英文不允许只剩一个单词。做法是三层：CSS `text-wrap: pretty` 兜底；每段最后两个词/最后一个字用 `nowrap` 锁住，逼浏览器把行重新分配；页面加载后逐字符测量再修一次（字体加载、语言切换、窗口缩放都会重跑）。

实测：22 套 × 中/英 × 1440/1024/768/390 四个宽度 = 176 次页面视图，**0 例单字成行**。脚本 `_build/review-lines.mjs`。

## 事实边界（重要）

- **所有产品界面都是 CSS 示意**，不是截图、不是录屏。每页 20–25 处「示意」标注。
- **没有任何客户数量、客户 logo、用户评价、认证、奖项、效率提升百分比。** 22 套全部是空的。
- 「100%」在全套里只出现在 CSS 的 `width:100%`，正文里没有效率百分比。
- 12×12 表格演示的是「12 份稿、每份 12 种语言、按稿分批」，不是「一次并发跑 144 份」。
- 时间轴只写阶段，不承诺每阶段几分钟。
- 工时实验室的默认数字标了「示例」，且允许算出负数。
- 21 亚马逊页不抄平台图片、不引用平台规则条文：每个站点的差异都写成「以卖家后台为准」，判断权留给卖家和平台。
- 22 外包页不写价格、账期、责任划分：分工与报价一律标示意，实际按各家合同。
- 绝对化词（保证 / guarantee / never / 全自动…）机检只做定位、不做判定，逐条读过的结论是这样三类：技术术语（智能对象、自动换行）、否定语境（「不自动加行」「要求所有 Photoshop 版本、所有复杂结构都保证可用」——这句是在说一个做不到的期待）、以及误报（`execution` 里含 `cut`、`second line` 里的 second）。
- 页脚四个外链（`tuyigf.com` 首页 / 下载 / 隐私 / 子处理者）2026-10-28 实测均返回 200。

## 已知偏差（写在明处）

1. **排版实验室的控件行在 390px 宽度下内部有 2px 溢出**（滑块轨道 326 vs 容器 324），页面级没有横向滚动；这一处没修掉，因为改动会把控件压变形。
2. **首屏插画里的文字不再是标题元素**——之前它们是 h3/h4，会让标题层级从 h1 直接跳到 h3，被审计判为结构错误。已改成同样样式的 div，视觉不变，屏幕阅读器不再把这些装饰文字当章节标题。
3. 为了让深色面板上的状态徽标和小字达标，4 个浅色主题的强调色、4 个主题的次要文字色做了加深（色相偏移 ≤12%，正常观看几乎看不出）。这是可读性换的，不是设计改动。21 的强调色也是这样从 `#b4570c` 调到 `#a34d08` 的：前者在软底上只有 4.30:1。
4. **整个目录还没入 git**（`git status` 显示 `?? 运营/site20_20261028/`），目前只有本机这一份。要不要提交、提交到哪个分支，等 Owner 定。
