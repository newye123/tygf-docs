## 状态术语

- 已写入：执行记录表明写入动作已发生。
- 回读验证：保存/写入后读取文字内容与目标译文一致。
- 保存重开验证：关闭并重新打开后验证通过。
- 版式需复核：机器或规则发现宽度/行数等风险，仍需人工看渲染结果。
- 未覆盖对象：设计稿中存在，但译文表无对应源文。
- 表格侧未命中：译文表有行，但当前设计稿中没有匹配对象；共享表场景可能正常。
- 视觉批准：人工检查 Photoshop 渲染结果后记录的最终批准。当前上传报告没有提供此批准记录。
