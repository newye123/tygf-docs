# 项目决策与硬约束

## 产品范围

- 产品名称：图译工坊 / Tuyi Workshop。
- 目标：将已审核的多语言译文写入可编辑 PSD / PSB 文字图层。
- 处理单位：设计文件 × 目标语言 × 文字对象。
- 输出：每种语言的 PSD/PSB 与 JPG/PNG 预览、执行日志、异常清单、报告。
- 不承担机器翻译和自主视觉重设计。

## 数据与状态约束

- 写入操作数不得写成唯一图层数。
- 回读验证、保存重开验证、人工视觉批准、最终交付完整是不同状态。
- 未命中译文表不自动等于错误，共享表场景需允许映射或忽略。
- 原文与译文相同不自动等于漏翻；型号、品牌、材料、规格可能有意保留。
- 数字、单位、型号、URL、占位符应单独做内容完整性检查。
- 版式宽度增加和行数变化是风险信号，不直接证明溢出。
- 未记录的数据必须显示“未记录”，不能猜测填充。
- 输出文件名记录不等于输出实体存在或可下载。

## 文件安全

- 真实生产必须在源 PSD/PSB 的任务副本上工作。
- 永远不覆盖原始母版。
- 每个文字对象有稳定任务级 ID 和幂等操作 ID。
- 记录源文件、工作副本、输出文件 SHA-256。
- 保存后必须重开验证。
- 失败项可单独重试，不重复写入已成功对象。
- 本地 Agent 默认只监听 127.0.0.1，使用随机会话 Token、Origin 校验和用户选择文件范围。

## UI/UX

- 使用克制、清晰、专业的工具型视觉语言。
- 状态名称必须准确，不得以“成功”掩盖待复核项。
- 主任务突出，次级诊断信息折叠或进入二级视图。
- 表格支持搜索、筛选、分页、导出。
- 所有修改有问题证据和验收标准。
- UI 展示的能力必须与实际后端能力一致。

## 交付约束

- 每次交付包含完整项目 ZIP。
- ZIP 内必须包含 README、完整上下文交接文档、决策记录、当前状态、路线图、文件地图、测试说明和恢复提示词。
- 每次交付标明哪些功能已实现、哪些仍是模拟、哪些是计划。
- 保留 V13/V14 基线，新增版本不得覆盖旧版。
