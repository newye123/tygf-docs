# 图译工坊 V7：整站宣传与交互原型

## 打开方式

1. 解压当前 ZIP。
2. 双击 `index.html`。
3. 点击顶部导航，进入产品能力、交互演示、实测计划、隐私、设计指南、计费、FAQ 和试跑表单。
4. 在“交互演示”中，可以直接使用样例 CSV，点击“检查译文与图层”，选中重复译文，确认或跳过，并运行模拟执行，导出 HTML 演示报告。

`index.html` 已内嵌 CSS、JavaScript 和矢量图形，不依赖 CDN 或远程图片。可在普通现代桌面浏览器中直接查看。

## 特别说明

- 这是完整可交互的 **前端原型**，未接正式登录、任务后端和 Photoshop 引擎。
- 选择 PSD 仅读取文件名，不解析文件内容，也不上传设计稿。
- CSV / TSV 文本解析发生在浏览器内。
- 演示报告、模拟任务状态和数据为前端演示，不可作为真实处理结果。
- 试跑申请表单只能生成本地摘要，无法直接提交，需通过正式官网申请。
- 官方账号、下载、正式隐私和用户协议链接会打开 `tuyigf.com`。
- 首屏和产品案例画面中的设备为虚构矢量示意。

## 文件说明

- `index.html`：完整单文件站点。
- `marketing-direction.md`：宣传方向变更、页面结构与上线前工作清单。
- `site-overview.png`：首页六屏缩略总览。
- `desktop-preview.png`：桌面首屏。
- `mobile-preview.png`：移动端首屏。
- `workbench-preview.png`：交互工作台。
- `sample-translations.csv`：交互演示的样例译文表。
- `stress-test-template.csv`：未来真实 PSD 实测记录表。
