# 图译工坊 tuyigf.com 官网宣传方向升级说明（V7）

版本日期：2026-10-31

## 1. 核心调整

当前官网突出“让设计师改语言变轻松”。V7 提案将首屏改成更具体、能够通过真实项目验证的表述：

**一套 PSD，多语言批量处理。异常集中复核。**

副标题统一解释：已有译文、按文字图层匹配与写入、需要人工判断的地方集中列出、最终视觉由设计师确认。

目标用户优先级：
1. 高频制作跨境电商详情页、Amazon A+ 与主副图的品牌视觉团队。
2. 设计外包工作室与多语言物料交付团队。
3. 独立设计师，主要作为教程内容和早期体验用户。

核心转化动作：体验交互演示，申请真实项目试跑。

## 3. 站点信息架构

- `#/home`：六屏营销长页。
- `#/product`：详细产品工作流、适用范围与兼容要求。
- `#/demo`：可交互的 CSV / TSV 文本解析、图层匹配模拟、人工确认、跳过及演示报告。
- `#/cases`：PSD Stress Test 测试矩阵、可下载的测试记录模板。
- `#/security`：本地、服务器、第三方 AI 的数据流与独立说明。
- `#/pricing`：积分和任务报价原则，不伪造当前费用。
- `#/guides`：译文表、排版、交付三类操作指南。
- `#/faq`：完整 FAQ。
- `#/pilot`：真实项目试跑申请原型（本地摘要，未提交后台）。

该网站是单 HTML 的前端交互原型。通过哈希路由模拟多页面，方便在本地直接打开并完整体验。

## 4. 交互原型已实现的前端能力

- 首页语言对比切换：英文原稿、德语、法语、日语、西班牙语。
- 首页四步工作流切换。
- 浏览器本地 CSV / TSV / TXT 文件导入以及粘贴内容解析。
- 演示样例基于固定的虚构 PSD 图层清单运行图层匹配逻辑。
- 空白译文、重复原文、不同候选译文、不可编辑文字、长度变化等示意问题。
- 人工确认候选译文、保留原文、恢复检测默认状态。
- 模拟执行日志、进度与带醒目标识的 HTML 演示报告导出。
- 样例 CSV 和 Stress Test 记录模板下载。
- 试跑申请表的前端校验、本地摘要生成与复制。
- 桌面端和移动端响应式布局，导航、FAQ 与指南可以使用。
- 首页的四步动效故事属于界面动画，明确为模拟。

## 5. 重要边界

1. HTML **不连接 Photoshop、本地助手、用户账号或正式图译工坊后端**。
2. PSD 选择控件仅读取文件名。实际图层清单是内置虚构样例，页面未读取 PSD 字节。
3. 演示版只解析 CSV、TSV、TXT，不解析 Excel XLSX。正式产品能力以真实工作台为准。
4. 演示日志、报告、状态统计均属于浏览器模拟，不可作为处理性能与兼容性证据。
5. 试跑表单没有网络提交，用户必须前往现行官网完成正式申请。
6. 交付前应将概念图、演示数据和测试计划替换为经验证、获授权的真实截图及测试记录。
