# 图译工坊 V12：实际工作台界面接入与全站原型

## 如何打开

直接使用 `tuyigf-v12-integrated.html`。这一文件内嵌全部 CSS、JS 和六张经脱敏的产品界面截图，可在浏览器离线打开。建议在 Chrome 或 Edge 中预览。

主要入口：

| 地址片段 | 内容 |
|---|---|
| `#/home` | 官网首页，基于实际界面重写首屏，并加入六张真实界面截图轮播与执行报告摘要 |
| `#/typography` | 新的排版功能介绍页，使用当前右侧排版抽屉的真实参考形态 |
| `#/studio/single` | 单个设计稿四步工作台，可交互前端复原 |
| `#/studio/type` | 进入单稿工作台并展开排版定制抽屉 |
| `#/studio/batch` | 多设计稿批量工作台，按 SKU 文件队列组织 |
| `#/app/overview` | 保留之前的完整 SaaS 项目管理概念工作台 |
| `#/how`, `#/product`, `#/cases`, `#/security`, `#/pricing`, `#/faq`, `#/pilot` | 保留并连通其余营销与服务页面 |

## 可以实际操作的交互

- 单稿和批量工作台切换。
- 单稿准备 / 智能检测 / 设计稿校对 / 生成交付四步导航。
- 模拟扫描、粘贴样例译文、切换 12 个语言、查看示例异常。
- 右侧排版定制抽屉，按 **设计文件 × 语言** 分别设置字体、字重、字号、行距、字距、自动字距、基线。
- 保存当前语言与文件的独立偏好到浏览器 localStorage，重选其他文件时不会相互覆盖。
- 批量模式的 12 个文件队列选择与搜索。
- 下载明确标注为模拟的 HTML 报告。
- 真实产品截图轮播、查看大图及对应工作台入口。

## 严格的能力边界

本交付是全站前端原型，**没有连接真实 Photoshop、本地助手、云端账户、真实定价或后端支付系统**。扫描结果、语种数字、任务状态和报告内容均为模拟或来源已标明的案例记录。XLS/XLSX 前端导入仅记录文件名，不能从中解析电子表格内容；完整解析须接入正式产品。

字体下拉选项是示例，不会调用本机字体目录，也不能保证字体已经安装。真实字体族、PostScript 名称、字形支持和 Photoshop 最终渲染必须由本地助手验证。浏览器设置持久化依赖用户浏览器允许 localStorage。

旧的 SaaS 概念工作台保留在 `#/app/overview`，与截图复原的操作工作台明确区分。

## 实测记录的宣传使用规则

用户提供的《图译工坊执行报告》记录：12 种语言、每语言 52 次计划写入、总计 624 次；报告记录写入和保存重开验证通过，另有 40 处版式需复核和 3 个未覆盖文字对象。

这一组记录可以用于解释产品检查流程，但不能据此宣称 12 个版本已经全部通过最终视觉验收；行数变化也无法单独证明发生真实字符截断。

## 交付内容

`assets/` 为脱敏界面截图；`preview/` 为主页、单稿工作台、排版抽屉、批量工作台、手机端和整套视觉概览图；`docs/` 为 UX 决策和接入契约；`qa-results.json` 为自动浏览器检查结果；`source/` 为可继续编辑的增量构建代码。
