# 图译工坊 V12 宣传与 UI/UX 接入决策

## 一句话传播原则

首屏说“重复改字、逐语言调字体”，紧接着展示与实际软件一致的四步向导。让访客先认出场景，再理解功能和适用范围。

## 按真实界面重建的页面结构

- 官网首页：痛点 → 产品输入/输出 → 六张真实操作截图 → 独立排版抽屉 → 产品功能 → 真实执行记录 → 隐私与试跑。
- 单稿工作台：准备素材 → 智能检测 → 设计稿校对 → 生成交付。
- 排版配置：固定右侧抽屉，不用全屏矩阵替代用户熟悉的操作方式。
- 多稿工作台：按 SKU 的文件列表 + 右侧单稿详情，承接文件夹批次。

## 对抗式 UX 审查

1. 截图上存在“1293 款字体”的当前机器计数。这仅证明截图所用设备显示该数量，不能让网页模拟宣称已经读取访问者电脑的字体。新版字体列表是样例，并标注正式执行依赖本地助手。
2. 按语言保存字体时，必须明确作用的 PSD 文件。新版在抽屉中加入“当前设计文件”，存储键为 `文件|语言`，避免用户误认为修改一个语言就覆盖所有 PSD。
3. 浏览器原型无法扫描 PSD，只能读取用户选择的文件名称。因此所有“扫描完成”均标为演示，不生成真实图层数量证据。
4. 真实执行报告可以证明 624 条写入回读记录，不能证明译文语义和版面视觉全部合格。官网将写入、内容和视觉三个判断分开说明。
5. 批处理工作台中有真实客户项目名、本机路径和内部业务网址。面向公众的截图必须脱敏，ZIP 已用脱敏版代替原始图片。
6. 用户尚无译文、只有 JPG、或使用不兼容 Photoshop 环境时，产品应清楚说明适用条件，避免获取无效线索。

## 下一步接入顺序

1. 真实 PSD / PSB 文件扫描与对象身份模型。
2. 译文表解析及匹配证据。
3. 字体列表和字体规则按文件、语种、可选图层组的应用范围。
4. 排版与内容风险的人工确认。
5. 本地 Photoshop 执行，保存后重开核对，真实报告产出。
6. 认证、额度、计费、隐私告知和正式任务流水。
