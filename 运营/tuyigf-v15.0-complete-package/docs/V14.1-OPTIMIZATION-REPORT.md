# Tuyi Workshop V14.1 优化记录

## 本版范围

V14.1 将 V14 工作台原型与用户上传的真实执行报告结合，增加报告中心和跨会话上下文交接文档。没有声称已完成真实 Photoshop 引擎。

## 新增 UI/UX

- 官网导航、首页 CTA、工作台侧栏加入执行报告入口。
- 官网案例区纠正旧报告的过期数据。
- 新建独立报告中心：结果概览、待处理事项、语言与文件交付、替换明细、溯源与证据。
- 报告统计区分写入操作数、唯一对象数、语言数、输出文件数和风险数。
- 将 40 条宽度风险与实际溢出结论分开。
- 将 432 条未命中总数与 HTML 可见的 200 条预览分开。
- 将原文相同汇总 83 与明细严格相同 79 的差异显式呈现。
- 将图层 6350 的 2.8oz 缺失作为二次核对项，不冒充原报告统计。
- 支持搜索、语言筛选、分页、CSV/JSON 导出和打印。

## 上下文交接

新增 `handoff/` 完整交接文档，包含产品背景、版本沿革、事实数据、统计口径、当前实现边界、技术路线、文件地图、决策约束和新会话恢复提示词。

## 尚待验证

- 需要在 Chromium / Edge / Chrome 实际打开页面检查所有交互。
- 需要验证打印样式、移动端表格横向滚动和长文本换行。
- 需要对比新报告每项数据与原始 HTML。
- 真实 PSD / PSB、Photoshop 和 Local Agent 能力仍未实现。
