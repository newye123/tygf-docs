# V15.0 Local Agent API

Base URL: `http://127.0.0.1:<selected-port>` (default 8765). If the default port is occupied, the launcher selects the next available loopback port and prints it in the console.

All API calls except `/api/health` and `/api/session` require `Authorization: Bearer <session-token>`. Retrieve the token from `/api/session` on the same local origin. Cross-origin requests and non-loopback Host headers are rejected.

- `GET /api/health`: agent version, parser availability/version, loopback bind, upload limit, worker timeout and Photoshop/write capability flags.
- `GET /api/session`: per-process session token. Same-origin only.
- `POST /api/scans`: multipart upload with field `file`; accepts `.psd` / `.psb` only. Browser-selected bytes are stored in a task-scoped local directory.
- `GET /api/scans`: recent scan jobs.
- `GET /api/scans/{scan_id}`: scan status and summary.
- `GET /api/scans/{scan_id}/layers?q=&confidence=&offset=&limit=`: paginated text-layer inventory.
- `GET /api/scans/{scan_id}/export.json`: full scan JSON, including `style_runs` when available.
- `GET /api/scans/{scan_id}/export.csv`: flat text-layer CSV; nested arrays are serialized into JSON strings.
- `GET /api/events`: recent append-only task events.
- `DELETE /api/scans/{scan_id}`: delete task record and local uploaded task copy. Returns 409 while status is `queued` or `scanning`.

## Worker behavior

The default parser runs in `local-agent/scan_worker.py` as a separate process. Default timeout is 1200 seconds and can be changed with `TUYI_SCAN_TIMEOUT_SECONDS` (minimum 30 seconds). Parser structural limits are set in `app/scanner.py`; worker result JSON is limited to 512 MiB. The main process calculates the task-copy SHA-256 before and after parsing and rejects the result if it changes.

No API accepts an arbitrary local filesystem path. No write, Photoshop, translation-mapping or export-image endpoint exists in V15.0.
