# V15.0 Scan Data Schema

Each completed scan contains a `summary` and an ordered `layers` array. JSON is the canonical export; CSV flattens arrays and nested values into readable strings/JSON cells.

## Summary fields

- `scan_id`: local scan task ID.
- `source_name`: uploaded filename.
- `source_sha256`: SHA-256 of the bytes uploaded from the browser file selection.
- `task_copy_sha256_after_scan`: SHA-256 of the task-scoped local copy after parsing.
- `task_copy_integrity_verified`: true only when the task copy hash before and after parsing is identical. This validates the local task copy; it does not claim that the original filesystem path was opened by the agent.
- `source_size_bytes`: uploaded file size.
- `format`: PSD/PSB format identified from the Photoshop header, not only the filename extension.
- `photoshop_header_version`: 1 for PSD, 2 for PSB.
- `header_notes`: non-fatal header/extension observations.
- `width`, `height`, `depth`, `color_mode`, `color_mode_code`, `channels`: document properties where exposed, with header values used as fallback where appropriate.
- `total_layers`: depth-first count including groups.
- `group_count`: number of groups.
- `text_layer_count`: recognized text layers.
- `text_with_content_count`: text layers with extracted content, including known empty strings only when content is explicitly available.
- `metadata_partial_count`: text layers whose parser confidence is not high.
- `unsupported_feature_count`: number of unsupported-feature flags across text layers.
- `parser`, `parser_version`, `mode`: parser provenance and read-only mode.
- `font_metadata_method`: method summary for typography extraction.
- `scan_isolated_process`: whether the parser ran in a separate worker process.
- `scan_timeout_seconds`: configured worker timeout.
- `scan_completed_at`: local task completion timestamp.

## Layer fields

- `object_id`: deterministic task-local object ID. Not a permanent Photoshop ID.
- `layer_index`: depth-first traversal index.
- `layer_id`: Photoshop/parser layer ID if exposed, otherwise null.
- `name`, `path`, `kind`: layer identity and group path.
- `text`, `text_length`: extracted text and character count; null means unavailable, empty string means known empty content.
- `text_type`: `point`, `paragraph`, or null when unavailable.
- `visible`: layer's own visibility flag where exposed.
- `effective_visible`: visibility including parent group visibility where exposed.
- `locked`: layer lock state where exposed, otherwise null.
- `opacity`: layer opacity where exposed, otherwise null.
- `bbox`: left/top/right/bottom/width/height in parser document pixels, or null.
- `transform`: parser transform representation if exposed, otherwise null.
- `font_family`, `font_postscript_name`, `font_style`, `font_size_pt`, `leading_pt`, `tracking`: summary typography fields, generally representing the first character style run where available.
- `font_names`: distinct PostScript font names reported for the text layer where available.
- `style_run_count`: number of character style runs when exposed.
- `style_runs`: per-run text and typography metadata where the installed psd-tools typesetting API exposes it. Unknown run properties remain null.
- `font_metadata_scope`: `single_style_run`, `first_style_run_only`, or `unknown`. The summary fields use the first run; `style_runs` preserves all runs that were successfully extracted.
- `parser_confidence`: `high`, `partial`, or `low`.
- `parser_notes`: non-fatal extraction notes.
- `unsupported_flags`: features the current extraction path cannot fully represent.

## Confidence semantics

- `high`: text and bbox extracted, one style run or known single-run structure, and at least one font identity field present.
- `partial`: text extracted but some metadata is missing, or multiple style runs mean summary typography fields describe the first run even though per-run records may also be available.
- `low`: text layer recognized but text content could not be extracted.

Confidence is a metadata completeness signal, not a guarantee of Photoshop correctness or visual layout approval.
