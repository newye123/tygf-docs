# Tuyi Workshop V15.0 Implementation Report

Implementation follow-up: 2026-10-31

## Delivered

- FastAPI local agent bound to `127.0.0.1`, random per-process bearer token and Host/Origin validation.
- Browser file picker and drag/drop upload for PSD/PSB only; no arbitrary filesystem-path endpoint.
- Upload-size limit and full 26-byte Photoshop header validation: signature, version, reserved bytes, channels, dimensions, bit depth and color mode code.
- Task-scoped source copy, SHA-256 before/after verification and JSONL audit events.
- Default parser execution in a separate worker process with configurable timeout, parser structural limits and a 512 MiB worker-result JSON cap.
- Read-only `psd-tools` adapter with recursive layer-tree traversal.
- Text content, layer path, layer ID where exposed, point/paragraph text type, own/effective visibility, lock state, opacity, bbox and transform where available.
- Typography extraction through `TypeLayer.typesetting` and `font_names`, with raw EngineData / FontSet fallback. Font indexes are mapped through FontSet rather than misreported as font names.
- Per-run typography records where the parser exposes them; summary fields identify the first run and mixed-run layers remain partial.
- SQLite scan history/layer inventory with foreign-key enforcement; append-only JSONL task event log.
- Search, confidence filtering, pagination, JSON/CSV export and safe task deletion (active scans cannot be deleted).
- Scanner UI improvements: actual upload byte progress, parser/timeout status, task-copy integrity disclosure, text type, layer ID, font family/PostScript names, mixed style-run count, effective visibility and opacity.
- Responsive desktop/mobile scanner UI, V15.0 home entry and Windows install/run batch files.
- Updated adversarial review, API/schema/QA docs, previews and complete context handoff.

- No PSD/PSB write operation.

- No Windows/Photoshop font enumeration.
- No Photoshop rendering, JPG/PNG export or visual approval.
- No installer executable or code signing.

## Environment limitation

The build container does not have `psd-tools`, and outbound package installation is unavailable. The real parser package could not be installed or exercised against an actual PSD/PSB in this environment. The code pins `psd-tools>=1.23` for `ParseLimits`, integrates the documented typesetting/font-name APIs behind a guarded adapter, and fails closed with a clear error when the parser dependency is missing. This is recorded as an unverified integration, not reported as a successful real PSD scan.

## Target Windows startup

1. Install Python 3.11 or newer with the Python Launcher.
2. Run `install-v15-local-agent.bat` once. Network access is needed to install dependencies.
3. Run `run-v15-local-agent.bat`.
4. Browser opens the local scanner route.
5. Select a PSD/PSB and scan.

## Current release classification

Developer preview / controlled evaluation. Not production-ready until the real PSD/PSB corpus, Windows compatibility, large-file and Photoshop comparison gates pass.
