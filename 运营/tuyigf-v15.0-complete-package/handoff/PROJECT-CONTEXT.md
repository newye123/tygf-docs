# Project Context

## Product

图译工坊 / Tuyi Workshop is a local-first production tool for placing already-approved translations into editable Photoshop PSD/PSB text layers. It manages the design-file × target-language × text-object workflow and produces traceable outputs.

## Users and jobs

Cross-border e-commerce visual design teams and external design vendors localize Amazon main images, A+ pages and product detail graphics. Translation is prepared and approved elsewhere. The tool reads design layers, maps approved copy, applies language typography settings, writes via Photoshop in a future milestone, validates and reports.

## Current milestone

V15.0 read-only PSD/PSB inventory scanner. No translation mapping or Photoshop write is included.

## Product principles

- Preserve the original layout and source file.
- Unknown metadata remains unknown.
- Parser confidence is not a Photoshop-render correctness guarantee.
- Machine validation and human visual approval are separate.
- Every output and decision must be traceable.
- Do not represent mock UI as a connected production capability.
