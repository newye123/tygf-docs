# 图译工坊项目上下文交接总文档

> 新会话或新开发者恢复项目的第一入口。当前版本：Tuyi Workshop V15.0 Developer Preview。更新日期：2026-10-31。

## 0. 30 秒恢复摘要

图译工坊（Tuyi Workshop）是面向已有译文的多语言 PSD/PSB 本地化改稿工具。目标是读取 Photoshop 可编辑文字图层，将已审核译文映射到文字对象，按文件和语言设置字体参数，在 Photoshop 中执行写入、验证、保存和交付。产品不负责机器翻译，也不自主重新设计原始版式。

当前版本 V15.0 已实现 Windows-first Local Agent 的只读扫描、PSD/PSB 文件上传、图层解析适配器、SQLite 任务存储、JSONL 审计日志、JSON/CSV 导出和扫描 UI。后续对抗式修订增加了独立解析进程、超时、结构解析限制、任务副本扫描前后 SHA-256 校验、混合字体样式段提取和更完整的移动端展示。构建环境缺少 `psd-tools`，且无法联网安装，因此本次没有对真实 PSD/PSB 执行解析验证。当前版本属于 Developer Preview，不能宣称生产就绪。

## 1. 产品目标与边界

### 产品目标

- 批量处理已有译文的多语言 PSD / PSB 文件。
- 读取可编辑文字图层并提取图层路径、文本和可用排版元数据。
- 将 CSV / TSV / XLSX 译文表与 PSD 文字对象可靠匹配。
- 按文件、按语言设置字体、字重、字号、行距、字距等参数。
- 通过 Photoshop 执行真实文字写入，并完成读回、保存、重开和预览验证。
- 按语言输出可编辑源文件与 JPG / PNG 预览。
- 输出可追溯执行报告、异常清单、人工决定与最终视觉验收状态。

### 产品不负责

- 不自动生成或翻译译文。
- 不自主重构或重新设计原有视觉版式。
- 不把浏览器预览当作 Photoshop 实际渲染。
- 不把机器检测信号自动判定为内容错误或视觉失败。

## 2. 用户与生产场景

主要场景是跨境电商视觉设计团队和设计外包团队，将已经审核的多语言译文写入 Amazon 主图、A+ 页面、详情页等 PSD / PSB 文件。语言依项目配置，可能包括英语、德语、法语、西班牙语、日语、意大利语、波兰语、韩语及其它语言。

核心生产对象：源设计文件、译文表、文字对象/图层路径、目标语言与字体配置、每个语言输出文件、逐对象写入日志与验证证据、最终视觉复核与交付状态。

### V15.0（当前）

本次开发只实现 Local Production Engine 的第一个里程碑：PSD/PSB 只读扫描。

已实现：
- FastAPI Local Agent，默认只监听 `127.0.0.1`；默认端口 8765 被占用时自动选择后续可用端口。
- 每次进程启动生成随机 Bearer Token；检查 Host 与 Origin。
- 浏览器选择/拖入 PSD/PSB，上传到本机任务目录；没有任意路径扫描 API。
- 文件大小限制、扩展名校验、Photoshop `8BPS` 文件头和 PSD/PSB 版本校验。
- SHA-256、SQLite 扫描记录、JSONL 事件日志。
- `psd-tools>=1.23` 只读扫描适配器，递归遍历图层组。
- 优先通过 `TypeLayer.typesetting` 与 `font_names` 提取字体和字符样式段；原始 EngineData / FontSet 作为回退。
- 提取文字、文本类型、字体列表、每个可用样式段、字号、行距、字距、坐标、图层可见性、父组有效可见性、锁定状态和不透明度。
- 默认在独立 worker 进程中解析，设置 20 分钟默认超时、ParseLimits 结构限制和 512 MiB 结果 JSON 上限。
- 扫描前后对任务目录中的上传副本计算 SHA-256；副本变化时拒绝完成任务。
- 禁止删除 queued/scanning 状态的任务，防止扫描期间删除工作目录。
- JSON/CSV 导出、搜索、置信度筛选、分页、历史记录和删除本机副本。
- 本地扫描 UI、V15.0 首页入口、Windows 安装和运行脚本。
- 对抗式审查、QA、API、Schema 与交接文档。

尚未验证：真实 `psd-tools` 解析、真实 PSD/PSB 兼容性、Windows 10/11 安装、Photoshop 对照测试、大型 PSB 内存表现。构建环境没有 `psd-tools`，网络安装被阻断；代码遇到缺少依赖会明确失败，不会假报扫描成功。

未实现：译文导入、对象匹配、本机字体枚举、Photoshop 写入、保存重开、JPG/PNG 导出、人工视觉批准。

数据来源为用户上传的 `图译工坊执行报告.html`，归档于 `reference/original-execution-report.html`。

- 图层 ID 6350 原文含 `80.0g / 2.8oz`，12 种语言目标文本均未保留 2.8oz，需要确认是否有意省略。
- 40 条版式风险全部为“比原稿宽”，行数未变；不能据此断言已溢出。
- 432 条未命中中，原 HTML 只展示 200 条预览，行号显示缺失。
- “8 个未覆盖”与“0 未纳入替换”的统计口径未说明。

## 5. V15.0 技术架构

- 前端：`local-scanner.html`，由 Local Agent 同源提供。
- 本地服务：Python + FastAPI，loopback only。
- PSD/PSB 解析：`psd-tools`，只读。
- 存储：SQLite 任务和图层记录；JSONL 追加事件日志。
- 输出：JSON / CSV 图层清单。
- Windows 启动：根目录 `install-v15-local-agent.bat` 和 `run-v15-local-agent.bat`。

安全边界：只允许浏览器上传用户明确选择的 PSD/PSB；无任意本地路径扫描 API；文件进入 `local-agent/data/scans/<scan_id>/`；默认 2 GiB 上传上限；每次启动随机 token；Origin/Host 检查；解析器在独立进程运行并设置超时与结构限制；任务副本扫描前后 hash 必须一致；无 Photoshop 写入 API。`task_copy_integrity_verified` 只证明本地任务副本在扫描期间未变化，不代表 Agent 直接打开了用户原始文件路径。

## 6. V15.0 扫描数据语义

详见 `docs/V15.0-SCAN-SCHEMA.md`。

- `object_id` 是任务内确定性 ID，不是永久 Photoshop layer ID。
- `layer_id` 仅在解析器提供时记录。
- `text=null` 表示无法提取；空字符串表示确知文字内容为空。
- `visible` / `locked` 未知时为 null。
- `bbox` / 字体属性无法解析时保持 null。
- `font_names` 和 `style_runs` 在解析器可用时保留全部字体名称与逐 Run 样式信息；主摘要字体字段仍以首个 Run 为代表，混合样式对象标记 `first_style_run_only` 并将置信度设为 partial。
- `parser_confidence` 是元数据完整度信号，不代表 Photoshop 渲染正确。
