# 关键词承接页模拟件（2026-10-28）

一个搜索词一页。每页先定「搜这个词的人此刻在干什么」，再定承接形态（教程 / 对比 / 清单 / 落地 / 技术 / 问答 / 品牌），最后才配色调。共 12 页 + 1 张矩阵索引页，中英双语，单文件自包含（CSS/JS 全内联，零网络请求）。

## 怎么看

- 总览：双击 `sites/index.html`，12 张卡片可点进对应页。
- 单页：`sites/01-psd-batch-edit.html` 起，按编号排。
- 每张截图在 `screens/`（1440 桌面、390 手机、英文态各一张）。
- 页面右上角「EN / 中文」切换；03 页的清单可勾选（只存本机浏览器）；02/09 页的对比表可切换「按项目看 / 按路线看」。

## 改文案 / 重新生成

文案与色调都在 `_build/kwdata.mjs`（12 个页面的全部文字 + 12 套调色变量），版式在 `_build/kwui.mjs`，外壳在 `_build/page.mjs`。改完跑：

```
cd 运营/kwland_20261028/_build
node build.mjs
```

产物整批重写到 `../sites/`，手改 HTML 会被下次构建覆盖。

## 五道体检闸（都在 `_build/`，失败即退出码 1）

| 命令 | 查什么 |
| --- | --- |
| `node review-a11y.mjs` | 对比度、点按区小于 24px、重复 id、缺标签、无文字替代 |
| `node review-lines.mjs` | 单字成行 / 孤字尾行，5 档宽度 × 中英两轮 |
| `node review-copy.mjs` | 「不是…而是」类反义句式、对外主张用词、中英排版毛刺 |
| `node verify.mjs` | 真实浏览器：JS 报错、页面级横向溢出、首屏标题、中英切换 |
| `node interact-kw.mjs` | 12 语种写回演示、对比表转置、清单勾选与持久化、首屏标题字号 |

负控（证明闸真的会拦）：`node negctl.mjs` — 往产物里注入五类缺陷，逐条要求对应闸报非 0，跑完自动重建还原。
