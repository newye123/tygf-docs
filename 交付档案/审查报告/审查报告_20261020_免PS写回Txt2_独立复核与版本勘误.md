## 一、三句话结论

1. **根因判决成立，且我独立复现了它**：引擎会多写一个全局 `Txt2` 块；把这个块摘掉后，**4 个夹具全部被 Photoshop 打开、137 个文字层齐全、改过的层显示新文本**（PS 还能把补丁件正常另存并再次打开）。
2. **但「PS 2026 27.10 真机复验」这句不成立**：本机唯一可用的 Photoshop 是 **22.0（2021）**，没有任何 2026 安装；10-19 与 10-20 两份报告的同一句版本标注均无 `app.Version` 原始读数支撑。
3. **所以处置不变、措辞要改**：仍不能开放写回（`#6129`/`#2717`/跨版本/多语种未验），但「免 PS 做不到」可以撤回；准确说法是**「0.7.0 直出不可用；根因已定位为 Txt2；修复路径在 PS 22.0 上已复现可用，按 Gate 验版本与保真后再定」**。

## 五、对既有 A 档方案的三处修订

并行线方案 A（`doc.save` 后摘 Txt2）方向正确，落地细节建议改三处：

1. **清洗时机放到 `doc.close` 之后**。`pc-executor.js:360` 是 `doc.save`、`:364` 是 `doc.close`；文件句柄未释放时改盘，Windows 上会撞占用。顺序应为 save → close → sanitize → 写 `executor-result.json`。
2. **fail-closed 且必须留痕**。摘不掉 / 结构不符 / PSB ⇒ `PSD_SANITIZE_FAILED` / `PSD_SANITIZE_UNSUPPORTED_PSB`，本次执行失败，不产出交付物；成功时报告与回执写明「已移除引擎写入的文档级 Txt2（N 字节）」，不许装作没发生。
3. **Gate 判据补两条**：① 每次 PS 复验必须把 `app.Version` 写进证据（本轮就是缺这一条才让版本漂了两份报告）；② 补「PS 另存后重开」——本轮已验证补丁件可被 PS 另存（6,231,713 B）并再次打开、新文保留。
