02多稿一次接表：两条路

方式 A · 新选文件夹（推荐）design-file-card.tsx:950

选文件夹扫描 → 结果里出现「译文表配对建议：N / M 稿已配上」→ 点「加入并导入表格（N 稿）」→ 确认框一行一稿、可逐行改选或选「不导入」→ 「导入选中的 N 张表」。

方式 B · 稿子已经在工作台里workbench-view.tsx:3240

多稿面板右上角「一次导入多张表」→ 一次框选多张 csv / tsv / txt / xlsx / xls → 同一个确认框 → 一次导入。浏览器直接读文件字节，不经助手。

单稿模式：完全不变workbench-view.tsx:3225

入口只在「批量模式且已有稿件」时挂载，单稿看不到这个按钮；单稿的解析、导表、执行路径一行未改。

03配对规则：宁可问你，也不瞎配

置信度规则界面上的话
同名去掉扩展名、「译文/翻译/表格/translation」等词与分隔符后同名；允许 -en、2 这类尾巴同名配对
同目录唯一设计稿同目录里恰好一张表同目录里只有这一张表
译文子目录唯一只允许一层层「译文 / 翻译 / 表格 / i18n」目录译文子目录里只有这一张表
上级目录唯一设计稿上一级目录里恰好一张表上一级目录里只有这一张表
全夹唯一整个文件夹只有这一张表整个文件夹只找到这一张表
判不了多张同名候选、同目录多张表等有 N 张同名候选，请手动选择

两条关键约束：一张表只归名字最像的那一稿；并列最长视为歧义，不参与自动配对（table-pairing.ts:138）。配对永远只是建议，必须逐行核对后才读表——错配一张表就是错译一整稿。

04安全边界：读表接口不能变成任意文件读取

1

根目录内，前后各判一次

先按字面路径判一次（read-table-path.js:19），再按真实路径判一次（:58），防 .. 逃逸与同前缀兄弟目录。

2

拒绝软链

lstat 看到符号链接直接拒（:52），避免借链接跳到根目录外。

3

扩展名白名单 + 5MB 上限

只认 csv / tsv / txt / xlsx / xls（:16）；单文件 5MB（:17），并带接口限流。

4

先授权，后碰盘

扫描票据校验通过才进文件系统；日志只写文件名与字节数，不写表格内容（server.js:5138）。
