  - 'heading "Before running a batch: check these 7 things" [level=2]'
  - paragraph: "Short answer: keep the text editable; use a translation table that matches this PSD; put one object per row; review translations before writing; run at most 12 drafts per batch, one at a time; process at most 12 target languages per draft; and review the layout language by language after writing. Get these seven right and batch language replacement will not need rework."
  - paragraph: Prepared by the 图译工坊 team · Published 2026-10-17
  - button "Is the text still editable text layers?"
  - paragraph: If text has been flattened into the background image, Photoshop has no replaceable text content. Open a few representative pages first; special effects, complex fonts, or titles split across several layers deserve an extra look.
  - button "Does the translation table match this PSD?"
  - paragraph: "Generate the table template from the PSD you are about to process, then fill in confirmed translations. Do not reuse a table from another design file: identical-looking source strings do not guarantee identical layers or positions. Spot-check a few rows before you start."
  - button "One design object per row?"
  - paragraph: Multi-line text in the same text layer belongs in a single cell; do not split it into several rows by the line breaks you see on screen. Splitting makes the layer-to-translation mapping ambiguous.
  - button "Review translations before writing?"
  - paragraph: Check for empty translations, duplicated source strings, and the same source string mapped to different translations. The product shows items needing confirmation before execution; ambiguous content should be decided by a person, never treated as a confirmed translation.
  - button "How many design files fit in one batch?"
  - paragraph: The current per-batch limit is 12 design files, run one draft at a time; within each draft the languages are processed one by one. For larger projects, split into batches and check which translation table belongs to each draft.
  - button "At most 12 target languages per draft?"
  - paragraph: Each design draft can process up to 12 target languages, one language at a time. For projects with more languages, split into batches and check that each draft uses the intended translation columns.
  - button "Check the layout language by language after writing?"
  - paragraph: Longer translations may take more space; line wrapping, fonts, and right-to-left scripts all affect the final layout. Read-back verification checks the text result but cannot judge semantics or aesthetics — open the output files in Photoshop and review text, wrapping, fonts, and the final visual for each language.

  - heading "Is this an automatic image-translation tool?" [level=3]:
    - button "Is this an automatic image-translation tool?" [expanded]
  - paragraph: "No. It does not translate. It targets the delivery workflow of multilingual design files: batch-writing translations you already have into PSD text layers. Translation quality remains the responsibility of your translation source."
  - heading "Do I have to upload my design files?" [level=3]:
    - button "Do I have to upload my design files?"
  - paragraph: PSD / PSB source files and replaced images are not uploaded; both are processed on your computer. However, layer text, table source strings and translations, and path data are transmitted and processed per the Privacy Policy. When you use OCR or AI features, necessary content is also sent to the corresponding services. See the Privacy Policy and the list of subprocessors for details.
  - heading "Can it guarantee fully automatic, correct results?" [level=3]:
    - button "Can it guarantee fully automatic, correct results?"
  - paragraph: No. Rasterized text, smart objects, and other complex cases cannot be replaced automatically; they are listed in the report for you to handle. The product promise is "reviewable", not "fully automatic".
  - heading "Why do some positions need my decision?" [level=3]:
    - button "Why do some positions need my decision?"
  - paragraph: One source string with multiple translations, a read-back that does not match what was written, or a translation that may overflow the layer — the tool lacks evidence at these positions, and writing blindly is risky. Stopping to ask you is the safer choice.
  - heading "What is the difference between \"needs review\" and \"needs your decision\"?" [level=3]:
    - button "What is the difference between \"needs review\" and \"needs your decision\"?"
  - paragraph: "\"Needs review\" is a suggestion for a human to double-check (the write already happened or was skipped, and a reviewer can take over). \"Needs your decision\" must be resolved by you; the tool will not write on your behalf."
