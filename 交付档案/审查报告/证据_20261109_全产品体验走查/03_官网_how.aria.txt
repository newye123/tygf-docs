- main:
  - text: HOW TO USE / 使用方法
  - heading "四步完成一次多语言 PSD 任务。" [level=1]
  - paragraph: 从已有译文和本机设计稿出发，先核对对象，再配置字体，最后执行并检查交付。下面的示意图用样例数据解释每个阶段。
  - link "工作台":
    - /url: /workbench
  - link "看真实排版设置":
    - /url: /workbench
  - article:
    - text: 01 / INPUT
    - heading "准备 PSD / PSB 和译文表" [level=3]
    - paragraph: 选取设计文件夹，导入已有译文表。原文可对应 DE、FR、JA、ES 等语言列。准备阶段只读取所需信息，源文件应保持不变。
  - article:
    - text: 02 / MATCH
    - heading "检查图层与译文的匹配关系" [level=3]
    - paragraph: 按对象检查已匹配、重复原文、空译文和无法可靠处理的图层。需要设计师决定的地方明确标出，避免未经确认的匹配。
  - article:
    - text: 03 / TYPOGRAPHY
    - heading "为每份 PSD 的每个语种设置样式" [level=3]
    - paragraph: 指定字体、字号、字距、行距与自动字距。保留语言默认预设，也能为具体 PSD 覆盖设置，互不干扰。
  - article:
    - text: 04 / EXECUTE & QA
    - heading "由本地 Photoshop 处理并检查" [level=3]
    - paragraph: 提交已确认的任务，本机写入并读取核对。交付时检查异常、保存结果与最终视觉，输出 PSD、JPG 和记录报告。
  - heading "先确认 Photoshop 运行条件" [level=3]
  - paragraph: 正式使用需要 Windows、已安装的 Photoshop 与官方本地助手。浏览器示例不读取真实 PSD、不枚举本机字体、不执行文件写入。不同 PS 版本和复杂图层结构应通过官方兼容性说明与实测确认。
  - text: SEE THE CONTROLS
  - heading "每个按钮都对应明确的下一步。" [level=2]
  - text: 导入设计文件 选择工作目录 → 读取文字图层 导入译文表 源文 / 目标语言列 → 按对象对账 设置排版 PSD × 语言 → 字体 / 字号 / 字距 / 行距 确认执行 异常与计费核对 → Photoshop 写入 → 交付
