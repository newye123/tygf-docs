取证：主审自己抓 15 家产品首页首屏文案＋打 GitHub 搜索 API＋取 4 个最相近仓库的 README 正文逐轴判。

## VERDICT

**三条主张：一条必须撤、一条必须改措辞、一条暂时站得住但不能当"独家"讲。**

最要紧的一句：**"把译文表里的文字批量替换进 PSD 文字层"这件事，开源界已经有人做了，而且连智能对象都做。** 我们对外如果讲成"只有我们能写回图层"，是被一个 ★0 的免费插件就能反驳的话。真正没查到别人当卖点讲的，是**"写完重新打开、逐层读回来比对、不一致的单列一行"**这一环。

## 二、开源同类实测（A 级，README 正文逐轴判）

| 仓库 | 星 | 许可证 | 最近推送 | 它到底做什么 |
|---|---|---|---|---|
| **CBETVN/Prevoda4ka** | 0 | 无 license | 2026-08-20 | **Adobe Photoshop UXP 插件：用预先准备的 Excel 译文表自动翻译 PSD/PSB 里的文字，翻译智能对象与普通文字图层**；自带 `psdParser.js`／`validateMasterFile.js`（自写二进制解析器做嵌套智能对象检测、字体抽取、链接图层扫描） |
| float3/psd_translate | 4 | **AGPL-3.0** | 2026-10-21 | 只翻 **图层名**（日中韩→英），不翻文字内容 ⇒ **不是同类**，别误判 |
| eddiesigner/sketch-translate-me | 74 | 无 license | 2019-05-18 | Sketch 插件，翻 Sketch 文字层/画板，Google 驱动，四轴 0 命中，**已停更 7 年** |
| snowydad/Make-Screenshots-for-App-Stores | 3 | 无 license | 2021-01-28 | JSX 脚本，批量出多语言 App 商店截图 ⇒ 相邻工作流，非同类 |

**Prevoda4ka 是本轮最该记住的一条**。它和我们重叠的部分：译文表驱动、PSD/PSB、**含智能对象**、还自写了 PSD 二进制解析器做嵌套智能对象与字体抽取。
它和我们的差异（**这条我还没读到实现级证据，判"待确认"**）：它的 `validate` 命中 20 处，但读上下文看是**校验母版文件**（`validateMasterFile.js`、`ValidateMFButton.jsx`）与"显示原始英文短语供参考"（`PhraseReference.jsx`），**不是"写完之后重新打开文件逐层读回来比对"**。

它★0、无 license、单人项目、只在 UXP（要较新 PS）。**这些都不改变一件事：主张"只有我们能写回图层"是讲不得的。**

## 三、三条主张逐条判

1. ❌ **"把译文批量写回 PSD 原图层"＝我们的独家能力** → **必须撤**。Prevoda4ka 已做到（含智能对象）。可改成的说法：**"我们做到了，而且是产品化交付（含批量、逐语言、可核对）"**——把"没人做过"换成"我们做到了别人没做成的产品形态"。
2. ⚠️ **"含智能对象"当卖点** → **改措辞**。开源侧已宣称支持嵌套智能对象检测。我们的差异只能落在**"批量 12 语种 × 逐对象结算 × 失败可重试"**这种工程完成度上，不能落在"支持智能对象"这个功能点上。
3. ✅ **"写完重新打开、逐层读回来比对、不一致的单列"** → **暂时站得住**，15 家商业首页 0 家讲、4 个开源仓库里没有一个把它做成"写后回读比对"。但**必须补一步实现级复核**（读 Prevoda4ka 的 `validateMasterFile.js` 到底校验什么）才能对外写成硬主张。在此之前，片子里那句"能替换的文字层，写完都回读一次"可以讲（它讲的是我们自己做了什么，不是"只有我们能做"），**但不得升级为"业界唯一/别人做不到"**。

## 四、对片子与文案的具体影响

- **第 7、8 镜（写入／回读核对）不用改**——它们讲的是"我们做了什么"，措辞已经是这个形状。
- **禁止新增任何"只有我们／别人做不到／独家"句式**，包括竖版 dev-log 的口播稿。这条要进禁词闸（现在画面像素文字还没进闸，见 10-23 记录）。
- 若要做"对比型"内容（业界常见手法），只能对比**形态**（表格驱动 vs 逐格手贴；批量 vs 单语言），**不能对比"能力有无"**。

## 六、覆盖缺口（明确没做到）

- **只查了 GitHub 英文检索**（6 组查询式：`psd translate`／`photoshop localize`／`psd translation`／`photoshop i18n`／`balloons translator`／`design file translation`，total_count 分别 56／9／50／4／9／279）。**中文圈的商业同类（淘宝/闲鱼上的"PSD 多语言代改"服务、国内 SaaS）没查**——那才是真正抢预算的对手。
- **Prevoda4ka 只读了 README**，没读它的源码；"它的 validate 不是写后回读"这句是**从文件名与摘要推断（D 级）**，需实现级复核。
- Canva Translate／Adobe Express／稿定的翻译功能页没取到（重定向／403／404）＝未核实。
- 未查这些开源项目的**实际可用度**（能不能真跑通一份中文母版）——★0 不等于不能用，也不等于能用。
- 两路在跑的调研 agent（品牌话术结构／同品类宣传口径）本轮未并入。
