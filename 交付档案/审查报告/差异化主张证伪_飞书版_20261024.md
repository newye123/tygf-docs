差异化主张证伪：竞品首页与开源同类实测（结论版）

这次审的是我们自己对外讲的话，不是别人的方案。

先给结论

三条主张：一条必须撤、一条必须改措辞、一条暂时站得住但不能当"独家"讲。

最要紧的一句：把译文表批量替换进 PSD 文字层这件事，开源界已经有人做了，而且连智能对象都做。所以"只有我们能写回图层"这句话讲不得——它被一个零星的免费插件就能反驳。真正没查到别人当卖点讲的，是"写完重新打开、逐层读回来比对、不一致的单列一行"。

我抓了什么

第一层，15 家产品首页的首屏第一句话，我用 curl 直取 HTML 自己解析，不是转述。Crowdin 是"Localization that just works"，Lokalise 是"Language quality. Turnaround speed. No compromise."，Phrase 是"The world's leading Language Intelligence Platform"，Smartling 是"Translate for every market, automatically"，Lionbridge 是"Think Big. Be Bold. Go Beyond."，DeepL 是"AI solutions that help you get work done"，Canva 是"What will you design today?"，美图设计室是"Your AI Marketing Studio"，Figma 是"The full-stack creative canvas"，稿定首页全是模板和节日专题。

统计下来：十五家里提"图层"的零家，提"PSD 或 Photoshop"的零家，提"写回"的零家，沾一点"校对、核对、验证、质量"的只有一家，而且只是 Lokalise 标题里那个 quality 词。

这一层的读法要两面说。商业本地化平台的首页叙事确实全部不谈设计文件图层，它们讲的是软件界面文案、内容翻译、企业流程——所以"设计稿图层级多语言替换"在商业产品的首页叙事里是个空位。但空位不等于没人做，看第二层。

第二层，我去 GitHub 搜了六组英文检索式，把最像的四个仓库的 README 正文拉下来逐轴判。

最该记住的一个叫 Prevoda4ka：它是一个 Photoshop UXP 插件，用预先准备好的 Excel 译文表自动翻译 PSD 和 PSB 里的文字，明确写了"翻译智能对象和普通文字图层"，还自带手写的 PSD 二进制解析器做嵌套智能对象检测、字体抽取、链接图层扫描。它零星标、没有许可证、单人项目、八月还在推。它跟我们重叠的部分是：译文表驱动、PSD 和 PSB、含智能对象。它和我们的差异我还没读到实现级证据——它有一堆 validate 命名的文件，但看上下文是"校验母版文件"和"显示原始英文供参考"，不是"写完重新打开逐层读回来比对"。这句现在是推断，要读源码才能钉死。

另外三个不是同类：float3 那个 psd_translate 只翻图层名字（日中韩翻成英文），不翻文字内容；sketch-translate-me 是 Sketch 插件、停更七年；Make-Screenshots-for-App-Stores 是批量出多语言商店截图的脚本，算相邻工作流。

三条主张逐条判

第一条，"把译文批量写回 PSD 原图层"是我们的独家能力——必须撤。改成讲形态：我们做到了产品化交付，批量、逐语言、可核对。把"没人做过"换成"我们做到了别人没做成的产品形态"。

第二条，"含智能对象"当卖点——改措辞。开源侧已经宣称支持嵌套智能对象检测。我们的差异只能落在工程完成度上，比如十二语种批量、逐对象结算、失败可重试，不能落在"支持智能对象"这个功能点上。

第三条，"写完重新打开逐层回读比对、不一致的单列"——暂时站得住。十五家商业首页零家讲，四个开源仓库没有一个把它做成"写后回读比对"。所以片子里那句"能替换的文字层，写完都回读一次"可以讲，因为它讲的是我们自己做了什么；但不得升级成"业界唯一"或"别人做不到"，直到把 Prevoda4ka 的源码读完。

对片子有什么影响

第七镜和第八镜不用改，现有措辞已经是"我们做了什么"的形状。要加的是一条禁令：禁止新增任何"只有我们、别人做不到、独家"这类句式，包括将来竖版口播稿。如果要做对比型内容，只能比形态（表格驱动对比逐格手贴、批量对比单语言），不能比能力有无。

我自己被打掉的一个错误前提

我在给调研 agent 的任务书里把 8am 写成了"设计本地化公司"，抓下来发现是律所管理软件，口号是"Run your Firm, Reclaim the Day"。这个假设是从上一轮转述里继承的，我没核。教训一句话：转述里的公司定位也要现抓一次。

明确没做到的部分

只查了 GitHub 的英文检索，中文圈的商业同类没查——淘宝、闲鱼、小红书上"PSD 多语言代改""设计稿代改"的服务和报价才是真正抢预算的对手。这条值得单独说一句：我们的对手很可能不是软件，是人。

Prevoda4ka 只读了 README 没读源码，所以"它的 validate 不是写后回读"这句是推断。Canva 的翻译页被重定向回首页、Adobe Express 返回 403、稿定翻译子页 404，这三家未核实。也没查这些开源项目的实际可用度，零星标不等于不能用，也不等于能用。

还有一条上一轮我说过的"没有任何开源实现做过按原图层行数重排译文"，本轮没有复核，不得当新证据引用。

下一步建议

一，读 Prevoda4ka 源码，半天能判，把"回读核对是不是我们独占"钉死。二，补中文圈同类普查，看真实在售服务和报价。三，把"禁用只有我们、独家、别人做不到这类句式"写进对外主张闸，跟画面像素文字那道闸同批做。

一个探针教训（记下来免得再犯）

第一次跑 README 分析时，raw.githubusercontent.com 从这台机器超时，结果三个仓库都报"零命中"——那是没取到正文，不是没有内容。改走 GitHub API 的 readme 端点才拿到真文本。抓取失败绝不能当成"没有"，这条我差点写进结论里。
