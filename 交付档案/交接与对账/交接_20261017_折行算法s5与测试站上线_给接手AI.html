§4部署运行手册（照抄级）

1 冻结

Owner 宣布停手后，等 A 线与 site-content 线把提交／现场落定；取当时 tip 为候选 sha；干净分离检出跑门全绿＝无半提交的证据。

2 合流

git fetch origin develop → develop 上 git merge origin/develop（冲突：siteContent.ts 取本地；llms 随取）→ 复跑 tsc=0。

推 origin＝共享状态，执行前向 Owner 再核一句。

3 出包

worktrees/0112-deploy 干净分离树 checkout 冻结 sha → release:preflight:test -- --allow-detached-head <sha> → release:package:test -- --allow-detached-head <sha> → 得 tygf-test-<sha>.zip＋receipt。

4 上传＋部署

scp zip＋receipt 到服务器 → bash /home/ubuntu/deploy-test-release.sh <zip>（脚本从发布包内解出再跑；不许从 Windows 树直接拷 .sh——CRLF 会死在 set -euo pipefail）。

6 回滚（备而不发）
