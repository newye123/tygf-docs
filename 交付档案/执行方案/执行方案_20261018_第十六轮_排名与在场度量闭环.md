## 三、会直接砍掉方案里几条路的六条外部事实

1. **GSC 的 `position` 不是位次。** 官方口径＝"每个日期显示的值是你站点页面的**最高位置的平均**（average topmost position）"，并自认"一般应更关注展示与点击，而不是位置" [P][Performance report 帮助](https://support.google.com/webmasters/answer/7576553?hl=en)。⇒ 谁拿"平均位置 8"当 KPI，谁就是在读一个被系统性美化过的数。
2. **小站的 GSC 表本身就是被筛过的。** 匿名查询（Google 定义：两三个月内只有几十人搜）在**表格与 API 里一律不列**，且**一加过滤器就整体被忽略** [P][2022 deep dive](https://developers.google.com/search/blog/2022/10/performance-data-deep-dive)；Ahrefs 用 146,741 站点实测 **46.08% 的点击来自未列出的隐藏词** [C][近半 GSC 点击数据被隐藏](https://ahrefs.com/blog/zh/gsc-hidden-terms-study/)。
3. **"AI 有没有引用我们"拿不到官方读数。** [searchconsole.v1.json](https://raw.githubusercontent.com/googleapis/google-api-python-client/main/googleapiclient/discovery_cache/documents/searchconsole.v1.json)（discovery `revision: 20260805`）里 `SearchAnalyticsQueryRequest` 只有 10 个字段、`ApiDimensionFilter.dimension` 枚举只有 `QUERY/PAGE/COUNTRY/DEVICE/SEARCH_APPEARANCE`，**grep `generative`/`ai mode`/`ai overview`/`datasource` 全 0 命中**；UI 侧那份报表也只有 impressions、无点击/无查询词/无位次，且不含 ChatGPT/Claude/Perplexity 的引用 [P/W]。基线窗口只能从 **2026-08-20** 之后起算（Google 自认 08-13 起该报表因日志 bug 系统性偏低）[C][SERoundtable](https://www.seroundtable.com/google-search-console-performance-reports-drop-41884.html)。
4. **程序化 SERP 这条路官方已经死了。** Bing Search / Custom Search API **2025-08-11 停用**；Bing Webmaster 的 legacy SOAP/POX **2026-08-31 退役**，REST 侧改 OAuth 2.0 [P][learn.microsoft.com](https://learn.microsoft.com/en-us/bingwebmaster/)（我们 `scripts/submit-indexnow.mjs:128` 打的是 `https://api.indexnow.org/indexnow`，**不在这条退役线上**，实测原式见工具）。百度侧：搜索 Referer API 2022-11-30 下线、普通收录自动推送入口 2020-12-11 下线，索引量只在后台 UI、`site:` 官方定性为"估算值、不准"。
5. **接第三方 SERP 供应商＝把一份仍在诉讼中的合规敞口接进产品。** Google 2025-12 起诉 SerpApi（指其绕过 SearchGuard），2026-07-20 北加州联邦法院**驳回 Google 的 DMCA 诉请**、留 21 天可修改再诉 [W]。百度没有官方 SERP API，只有第三方接口（极速数据 ¥100/10,000 次、天行 ≈¥0.0042—0.005/次、站长之家官方提示"存在异地排名，不保证与查询 IP 一致"，且**只回前 50 名**）[C]。
6. **AI 答案的重复采样门槛比想象高。** SparkToro×Gumshue 2026-01 用 600 名真人、2,961 条提示测 ChatGPT/Claude/Google AI：**两次回答出现同一品牌清单的概率 <1/100，同一顺序 <1/1000** [C]；厂商侧经验值是探索期 5 次/问/引擎为下限。按二项比例自算（我的推导，非引用）：95% 置信 80% 功效下 n≈16·p(1−p)/Δ²，p≈0.3、要检出 20 个百分点的位移 ⇒ **每条件约 56 次**。⇒ 我们手上那条 `geo-baseline_20261017_doubao_v2.jsonl` 的 3/3 单发，**只能判"提没提到"，不能支撑任何趋势主张**。
