03对抗式审查（六路）

A 鉴权/安全

判得对assistant-redemption-token.ts:13-20

true/false 把「无行 / 代次不同 / machineId 变了」压成一个码（assistant-authorization.ts:27），三种处置无法区分。不放松 jti 校验，改细分码。

B 协议/状态机

不可查ticket/verify/route.ts:144-146

拒绝走 200 会让客户端 cloudStatusCode=200 误判为「网络正常」；该分支无服务端日志，测试站无法回溯。补 subReason + warn 日志（零 token）。

C 运行时身份

源码≠运行版58a483c（10-18 22:15）

专属文案只在源码（server.js:3396-3402）；运行版 10-12 构建只有兜底（:3407）。smoke 是静态断言（smoke-local-assistant-errors.mjs:435-467），不校验安装包。

D 运维/部署

缺检查项6d9e169（10-10 引入 jti）

代次语义上线后，发布清单没有「旧 token 负控 + 重连正控」，问题只能在用户机上暴露。

E 可恢复性

文案冲突assistant-setup-banner.tsx:241 / :164

UI 已有「重新连接」按钮且提示正确；助手兜底却说「刷新工作台后重试」，把用户引向无效动作。

F 测试

缺行为断言smoke-local-assistant-errors.mjs

只断言源码存在分支；需补「文案不含刷新」「产物含补丁」「expected==actual」三类硬校验。

04根因分支

分支假设判别恢复
H1 最可能助手 token 的 jti 与 DB 行不一致（代次漂移）DB 只读查该行 tokenJti/updatedAt；助手 token 是否含 jti（只打印有/无）重连即解
H2该 machineId 无 redemption 行（换库/清理）同查询返回 0 行重连会新建行；若码/激活异常走 P2
H3助手 token 来自别的环境/origin助手当前 origin；token 的 aud/iss（不打印值）切回测试站重连
H4码停用/过期、激活超期DB 查 code.status/expiresAt、activation 状态按码续期/重新激活

顺序：先跑 P0（人可恢复）→ 仍失败则按 §05 的只读 SQL 对账，再定 H1/H2；不盲修、不反复点。

05执行方案

P0

立即恢复（Owner，约 2 分钟，不改代码）

① 连接卡点「重新连接」并确认；② 仍失败则托盘退出助手（结束 22684/22720）→ 重启助手 → 再重连 → 刷新；③ 重试「选择文件」。验收：日志无同码、文件框弹出。失败则停止反复点，保留时间点进 P1 对账。

P1

服务端可诊断性 + 细分码（部署测试站需授权）

redemption 查询返回 {matched,rowExists,rowJtiNull,rowUpdatedAt}；细分 GENERATION_STALE / UNBOUND（原码留一版兼容）；route 加 warn 日志（码前 8 位 + machineId 哈希）；工作台两码映射到「重新连接」；owner-only 只读诊断端点。验收：旧代次→STALE、未绑定→UNBOUND、重连后→valid:true。

P2

助手发版：文案真正送到运行版（需授权）

用含 58a483c 的源码打引擎包，buildId 升版并同步 release-identity、安装包声明、站点 expected；文案统一「断开→重新连接当前电脑」，删除「刷新」。验收：provenance expected==actual；旧 token 负控命中新文案。

P3

防复发

部署检查单加「旧代次负控 + 重连正控」；smoke 升级为行为断言（含「重新连接」、不含「刷新」）；expectedAssistantBuildId 与安装包 buildId 绑定校验。

只读对账 SQL（P1 前置）

SELECT id, assistantCodeId, machineId, tokenJti IS NULL AS jti_null, tokenExpiresAt, updatedAt FROM AssistantCodeRedemption WHERE assistantCodeId='<码 id>' ORDER BY updatedAt DESC LIMIT 5;

有行且 jti 非空、updatedAt 晚于 10-18 → H1；0 行 → H2；tokenExpiresAt 已过 → 续期议题。本会话无法直连测试站 DB。
