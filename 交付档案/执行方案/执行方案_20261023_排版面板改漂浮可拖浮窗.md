# 执行方案：排版面板改漂浮可拖动浮窗（2026-10-23）

## 0. 结论（先说这一句）

把右侧全高抽屉改成**内容自适应高度的漂浮面板**：标题栏可拖动、位置记在浏览器里下次还在、方向键也能移动、后面工作台不再被灰罩锁住。**不引入新依赖**——手写约 80 行 pointer-events 拖拽（大厂浮窗如 Excalidraw 同款做法），理由见 §3 依赖实测。

字小的病根：面板正文 39 处用了 9–11px 字号。整体抬一档（9→10、10→11、11→12）。
太高的病根：抽屉是 `fixed inset-y-0 right-0`（通到屏幕上下两端），空态时里面只有一句话——所以"又高又空"。改成高度跟内容走、超过 72vh 才内部滚动。

## 1. 调研：GitHub / 前端社区的四种做法

| 方案 | 是什么 | 实测证据 | 判 |
|---|---|---|---|
| **手写 pointer-events** | 标题栏监听 pointerdown/move/up + `setPointerCapture`，拖动期间只改 transform 不触发 React 渲染，松手才落 state | Excalidraw/tldraw 同款思路；React 19 原生支持 | **推荐**：零依赖、零 peer 风险、无障碍自己说了算 |
| react-rnd 10.5.3 | 拖拽+缩放二合一，内部就是 react-draggable+re-resizable | 实测其 `lib/index.js:451` 已向 react-draggable 传 `nodeRef`（React 19 移除了 findDOMNode，旧版会炸；新版靠 nodeRef 续命）；2026-03 仍在发版 | 可用但**重**：带缩放能力，本单用不上（YAGNI） |
| react-draggable 4.7.2 | 只拖不缩 | 实测 4.7.2（2026-09 发布）源码 `chunk-ACOTSM7X.mjs:497` 自陈"React 19 移除了 findDOMNode，必须传 nodeRef"——能用但只剩拖拽这一半 | 不如直接手写，白添一个依赖 |
| @floating-ui/react | 定位引擎，不管拖拽 | 定位/翻转/偏移，浮窗拖动要另写 | 不对症 |

社区共通要点（多家交叉印证）：拖柄只放标题栏；位置持久化 localStorage 且**恢复时夹回视口内**（防换分辨率后跑到屏幕外）；非模态浮窗 `role="dialog" aria-modal="false"`（ARIA 允许非模态对话框）；Esc 关闭要限定"焦点在面板内"；标题栏 `touch-action: none` 才不被手机滚动抢走；dockview（VS Code 式布局库）专门给浮窗做了 WAI-ARIA 状态。

## 2. 对抗式审查：这个方案会在哪 15 个口子上失败

按"先证伪再下结论"，逐条给处置。审查对象＝我自己上面那个方案。

| # | 口子 | 处置 |
|---|---|---|
| F1 | 拖动时每个 pointermove 都 setState → 整个面板（几十个输入框）每帧重渲染，拖起来卡 | 拖动期间用 ref 直接改 `transform`，**松手才 commit 一次 state**（模拟 HTML 已按此实现可点验证） |
| F2 | 关闭按钮也会触发拖柄 → 点 X 变成拖走 | 拖柄起点排除 `data-no-drag` 元素（X 按钮、徽章） |
| F3 | 位置存 localStorage 后用户换分辨率/缩放 → 面板恢复到屏幕外 | 恢复时夹回视口：x∈[-(w-48), vw-48]、y∈[0, vh-48]；再加 window resize 监听实时夹回 |
| F4 | 非模态后 Esc 若仍挂 document 级：用户在**工作台**输入框里按 Esc 会把面板关掉 | Esc 只在焦点位于面板内时关闭（模拟 HTML 演示） |
| F5 | 移除灰罩+inert+滚动锁+焦点陷阱后，旧测试三处必红 | `aria-modal="true"`→`"false"`；"背景 inert"两条断言改写为**反向负控**（surface 全程不得带 inert）；Esc 用例改为焦点门控 |
| F6 | 标题栏拖动在手机上被页面滚动抢走 | 标题栏 `touch-action: none`；pointer events 天然覆盖触摸 |
| F7 | 拖动中文本被选中 | 拖动期间 `user-select: none`（只挂标题栏） |
| F8 | 默认位置写死 left/top，右侧锚点丢失 | 默认仍落右上（left = vw − 面板宽 − 24、top = 72），与旧抽屉视觉锚点一致 |
| F9 | 抬字号后 24px 高的字格（h-6）可能溢出 | 12px 字号在 24px 格内安全（行高 1.4=16.8px）；格内 select/truncate 已有；出包前浏览器实测 |
| F10 | 抬字号是 39 处全抬，徽章/微字一抬就破 | 分档抬：正文与说明 11→12、10→11，9px 徽章 9→10（最小一档） |
| F11 | 悬浮球在面板打开时仍隐藏（旧模态逻辑）——非模态下没道理 | 保留隐藏：面板默认落右上、悬浮球也在右侧，重叠时点不到；此为刻意取舍，不改 |
| F12 | smoke 守卫防"抽屉化回潮"缺失 | 新增守卫：typography-panel.tsx 源码**不得**再出现 `inert`、`aria-modal="true"`、`inset-y-0`（负控：塞回去必须红） |
| F13 | localStorage 键坏 JSON/旧版本 | 独立小键 `tygf.typographyPanelPos.v1`，try/catch 解析、失败即回默认位置；不与字体偏好键共用结构 |
| F14 | 首次打开 panel 里 `focus()` 旧逻辑（聚焦第一个控件）与"焦点门控 Esc"互相影响 | 非模态不再抢焦点：打开时**不聚焦面板**（旧抽屉聚焦是模态义务），焦点留在触发按钮上，aria-expanded 照旧 |
| F15 | 关闭后焦点归还会不会掉进 inert 背景（10-20 实测过的坑） | 焦点归还逻辑保留但简化：surface 永不 inert，onClosed 回调照旧由 workbench 把焦点还给触发器 |

**否证记录**：调研前我以为 react-rnd 在 React 19 下装都装不上（peer 停在 ≤18）——实测 peer 是 `>=16.3.0` 没上限，**这个否证不成立**；真正的坑在它下游的 findDOMNode，且 10.5.3 已用 nodeRef 修掉。结论仍是不选它，但理由从"装不上"改为"用不上还重"。

## 3. 执行方案（S1–S8，一个提交）

- **S1 模态→非模态**：删 backdrop（`fixed inset-0 … onClick={onClose}`）、删 surface inert、删 `documentElement.overflow` 滚动锁、删焦点陷阱；`aria-modal` 改 `"false"`；Esc 加焦点门控。
- **S2 拖动**：标题栏 pointerdown→`setPointerCapture`，move 期间 ref 直改 transform，up 落 state；`cursor-move`；`touch-action:none`；`data-no-drag` 排除 X。
- **S3 位置持久化**：`tygf.typographyPanelPos.v1`；恢复夹回视口（F3）；resize 监听夹回。
- **S4 键盘**：标题栏 `tabIndex=0` + aria 说明（"拖动或方向键移动面板"）；←↑→↓ 移动 8px、Shift 加速 32px；Esc 焦点门控（F4）。
- **S5 尺寸与字号**：容器高度改内容自适应（删 `inset-y-0`），`max-h-[min(72vh,640px)]` 超出内部滚动；宽保持 `w-[min(360px,92vw)]`；字号分档抬（F10）。
- **S6 workbench-view**：预期**零改动**（悬浮球门控、三处灰度开关、aria-expanded 均不动）；只跑回归确认。
- **S7 测试与守卫**：改 `tests/unit/typography-picker.test.tsx` 三条（aria-modal、inert 反向负控、Esc 门控）＋新增：位置持久化往返、拖柄 data-no-drag、方向键移动；smoke 新增 F12 三条防回潮。
- **S8 验证闸**：`npx tsc --noEmit`、`npm run lint`、vitest 单测、`smoke-typography-picker` + `smoke-typography-customization`、dev 起来真浏览器拖一遍（含窄屏 360px 与恢复夹回）。

**不做**（明说边界）：不做缩放（Owner 没要，浮窗宽度恒 360）；不做多面板；不改入口三处与灰度逻辑。

## 4. 验收判据（Owner 可自己核）

1. 浏览器打开排版面板：不再通天通地，高度跟内容走；字明显变大。
2. 按住标题栏能拖到任意位置，松手后刷新页面位置还在。
3. 面板打开时，后面的工作台能正常点击/滚动（不再有灰罩）。
4. 键盘：Tab 进标题栏后按方向键面板会动；焦点不在面板里按 Esc 不会误关。
5. 三条交付命令全绿：tsc / lint / vitest，两条 smoke 断言数只增不减。
