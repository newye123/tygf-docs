## 一、五件事实清单（结论 · 硬条件 · 数字 · 依据）

### 1. 个体工商户登记（个人营业执照）
- **结论**：全程线上（各省一网通办 / 政务 App），登记不收费，多地承诺 1–3 个工作日办结；2025-07-15 起施行的《个体工商户登记管理规定》明确：仅通过网络开展经营活动的经营者，可登记网络经营场所。
- **硬条件**：经营者身份证；经营场所信息（自有/租赁凭证，或网络经营场所）；店铺名称符合个体户命名规范。
- **关键数字**：注册费 0 元；办理时限常见 1–3 个工作日。
- **办后必做**：税务报到并按期申报（个体户一般小规模纳税人，按季申报，具体以主管税务机关口径为准）；每年 1 月 1 日–6 月 30 日报送年报；刻章与对公账户均为可选（微信支付接受经营者对私账户；公众号认证个体户可走法人验证，无需对公账户）。
- **重要提示**：个体户执照同时是 ICP 备案主体、微信支付商户号主体、支付宝账号主体、公众号/小程序主体——五处必须同一张执照，这是全链一致性的根。

### 2. ICP 备案（决定生死的一环）
- **结论**：国内服务器必须备案；网站卖东西属经营性内容，**必须单位备案**（个体户可作网站主办单位，省管局办事指南明确列示）；个人备案不得含经营性内容（产品/价格/商品），违者注销备案——个人身份卖货直接排除。
- **硬条件**：服务器包周期 ≥3 个月；域名实名认证；接入商（云商）真实性核验；管局审核（官方上限 20 个工作日，通常 1–2 周）；备案号下发后网站底部悬挂；上线后 30 日内做公安联网备案。
- **关键数字**：备案费用 0 元（仅服务器成本，国内轻量约 ¥60–150/月量级）；备案时限最长 20 工作日；罚则：未取得许可擅自从事经营性互联网信息服务，可罚 10 万–100 万（《互联网信息服务管理办法》第十九条）。
- **个体户办不了的事**：经营性 ICP 许可证（增值电信业务经营许可证）要求「经营者为依法设立的公司」，注册资本省内 100 万/全国 1000 万（《电信业务经营许可管理办法》第六条）；腾讯云 FAQ 明示个体工商户不能申请。→ 定位话术按「自研软件授权/数字商品自营」，避开「会员服务费/平台佣金/信息中介」类描述；未来做平台化再升级公司（红队 Q2，留档中风险）。
- **与支付的耦合**：支付宝要求网站已备案且备案主体与支付宝账号主体一致；微信 Native 要求 PC 网站域名已备案（主体不同需加盖公章授权函）。备案是两条支付通道的共同前置，排在关键路径上。

### 3. 支付宝（电脑网站支付）
- **结论**：支持企业/个体工商户签约电脑网站支付，费率 0.6%。
- **硬条件**：网站可正常访问，经营内容与商品信息完整，网站已 ICP 备案且备案主体与支付宝账号主体一致（不一致需授权函）。
- **关键数字**：申请费 0 元；费率 0.6%（特殊行业可能不同）；新签约商家存在结算周期限制（常见口径：签约满一定期限或连续交易满一定天数后转常规结算，签约页为准）；资料不全时有单笔/单日额度限制（随资质完善提升，签约页为准）。
- **项目侧现状**：支付宝全链代码已就位（`src/lib/server/payments/alipay.ts`，636 行；回调只推进 `paid_uncredited`，积分账本由 `creditPaidOrder` 唯一入账）；6 个支付开关默认全 false（`src/config/featureFlags.ts:22-31`）；资质到手后只需配置密钥、开关灰度。
- **重要提示**：签约成功 ≠ 全速收款，现金流预估要留缓冲。

### 4. 微信支付（PC 网站 · Native 扫码）
- **结论**：个体户可申请，申请免费，费率 0.6%–1%（按类目），审核 1–2 个工作日；PC 网站场景使用 Native 支付（商户生成二维码，用户微信扫码）。
- **硬条件**：应用类型须「已认证的服务号/公众号，或已认证的小程序，或已认证的移动应用」；PC 网站域名需 ICP 备案（主体不同需加盖公章的网站授权函）；入驻时选择 PC 网站经营场景并绑定商户号↔APPID；商户简称按规范命名（个体户可用「个体户+经营者名称」或「经营者名称+业务」）。
- **关键数字**：公众号认证 300 元/次/年（个体户可法人验证，免对公）；**小程序认证对个体户限时优惠 30 元/次**（微信开放社区官方精选帖口径，办理时现核）；下单返回 `code_url` 生成二维码；APIv3 回调需用微信支付公钥模式验签解密。
- **缺口**：微信支付官方 SDK 仅 Java/Go/PHP（商户文档 SDK 页），无官方 Node 版；接入计划用社区库 `wechatpay-axios-plugin`（MIT，覆盖 Native/H5/JSAPI、回调解密、退款、账单）或 `wechatpay-node-v3-ts` 备选。
- **项目侧现状**：全仓微信支付相关代码 grep 0 命中，需新建；复用项目既有「回调只推进 paid_uncredited、积分唯一入账」模式。

### 5. 海外收款（无海外公司路线）
- **结论**：Stripe 对大陆主体不开放（支持地区含香港、不含大陆；2026 年多源一致）；无海外公司时，务实路径是 MoR（Merchant of Record）平台，平台作为法律卖方处理海外销售税/增值税/发票/拒付，你只管提现。
- **大陆个人可用候选**（2026 年第三方评测交叉，注册前以官方后台复核）：
  - Creem：3.9% + $0.40；个人提现到支付宝（评测口径：单笔 ≤5 万元人民币，每年 30–60 万额度）；店铺审核 24–72 小时；要求网站上线、价格可见、隐私政策/条款/客服邮箱与域名一致。
  - Waffo Pancake：3.9% + $0.50；CNY 提现到银行卡或支付宝；$20 起提，提现费 1%（最低 $10）；平台较新，长期稳定性待观察。
  - Paddle：5% + $0.50；接受个人/sole trader 注册；电汇或 Payoneer 提现，**能否到达大陆银行官方未说明，注册前须问客服**；<$10 产品需单独定价。
  - Dodo Payments：接受大陆个人/企业（评测口径），国际交易与订阅有附加费，需单算。
  - PayPal：仅辅助（约 4.4% + $0.30，提现 $35/笔，风控冻结风险高），不当唯一通道。
- **排除项**：Lemon Squeezy（被 Stripe 收购后 2026 起停止新独立开发者大陆主体申请）；Polar（无大陆提现通道）；Stripe Atlas（无海外主体前 $500 注册 + 后续维护成本，起步阶段不划算）。
- **税务提醒**：MoR 只处理海外销售税；中国境内纳税义务不变（个体户经营所得，含 MoR 收入，照章申报）。

## 四、执行阶段与时间线

- **阶段 0 · 决策（Owner，0.5 天）**：确认主体路线（建议个体户起步）与全链统一的主体名称；给出执行授权。
- **阶段 1 · 登记（Owner，1–3 天）**：线上个体户登记；同步实核现有域名/服务器，补服务器包周期 ≥3 个月、域名实名。
- **阶段 2 · ICP 备案（关键路径，1–3 周）**：单位备案提交与核验；上线后 30 日内补公安联网备案。此阶段可并行做阶段 3 的认证部分（需执照，不需备案）。
- **阶段 3 · 通道资质（2–5 天）**：公众号/小程序注册+认证 → 微信支付商户号入驻（PC 网站场景 + Native 权限，填备案域名与 APPID）→ 支付宝开放平台个体户账号 + 电脑网站支付签约。
- **阶段 4 · 工程接入（1–2 周）**：微信 Native 接入（provider=wechatpay、channel=native，复用 PaymentTransaction 与「回调只推进 paid_uncredited」模式）→ 回调解密验签 → 退款链路 → 1 分真单 + 重放幂等 smoke → 开关灰度（creditPacks → 支付宝 → 微信）。
- **阶段 5 · 海外通道（并行，3–7 天）**：补齐价格页/隐私政策/条款/客服邮箱 → Creem 或 Waffo 注册与审核 → 1 笔真单 + 提现验证 → PayPal 备用登记。
- **阶段 6 · 上线闸（对齐收口方案 P1.6）**：协议签署 + G1–G8 全绿 + 三步放（网站 → 助手 → 支付开关），每步 Owner 批准。
- **最快总时长：约 3–4 周**，备案在关键路径；阶段 3/5 并行可压缩。

## 五、上线闸门 G1–G8（全绿才开支付开关）

- G1 主体一致性：执照名 = 备案主体 = 商户号主体 = 公众号/小程序主体 = 支付宝账号主体。
- G2 备案落地：备案号下发、底部悬挂；公安联网备案已排期。
- G3 签约完成：微信 Native 权限 + 支付宝电脑网站支付签约双到位。
- G4 密钥纪律：支付密钥只进环境变量/受控凭据，禁明文入库、文档、提交。
- G5 回调幂等实弹：同 notify 原样重放不重复入账（对齐收口方案 A2 用例 3，留请求/响应证据）。
- G6 退款链路：微信侧新建 + 支付宝侧既有，双通可用。
- G7 协议条款：用户协议 + 隐私政策含支付、退款、发票条款（收口方案已列前置）。
- G8 灰度与回滚：开关分步开启；回滚与停止发码条件写清。
