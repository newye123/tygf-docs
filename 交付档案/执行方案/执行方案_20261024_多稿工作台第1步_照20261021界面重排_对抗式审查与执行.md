### 3.2 矩阵格状态机（一稿一表合同下的诚实分层）

| 格态 | 触发 | 颜色 |
|---|---|---|
| 就绪 ✓ | 稿已扫＋表全文已读＋覆盖≥95% | 绿 |
| 待检查 % | 同上，80–94% | 琥珀 |
| 有问题 % | 同上，<80% | 红 |
| 待读全文 | 表头已读、全文未读 | 灰（sunk） |
| 未扫 | 稿扫描中/未扫 | 虚线 |
| 未配表 | 稿没绑定表 | 红框 |
| — 不做 | 本稿的表没有这门语言 | 透明 |
