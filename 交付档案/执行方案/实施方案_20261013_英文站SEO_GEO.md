## 04　范围选择（三选一）

- **A（推荐）最小英文站 + 全套 SEO/GEO 层**：`/en` 四个营销页（首页、下载、条款、隐私），英文静态文案；SEO/GEO 五层同源生成。工程量中等、风险低（不动产品 UI、不动支付/状态机）。
- **B 全量 i18n 双语**：next-intl 基建 + 工作台/结果页/登录后全链翻译。工程量最大，且触碰产品行为（Product Drift Guard 管辖），条款/隐私/产品文案全部要 Owner 定稿。不推荐一步到位。
- **C 只在中文站挂英文钩子（无页面）**：排除——hreflang/sitemap/meta 没有可指向的英文 URL，做了也是空转。

## 07　风险与依赖

- **#130 生产 FAQ 漂移未修**（生产 DB 旧版 7 条覆盖 git 6 条诚实版；Content Studio 生产锁 `src/lib/server/site-settings.ts:361-369`）→ 英文 FAQ 必须走 git 单源（决策点 6），否则把旧承诺文案翻进英文站。

## 09　最后一句

英文 SEO/GEO 不是「在中文站上再贴一层标签」，而是**先把英文页造出来，再让五层（页面 / meta / sitemap / JSON-LD / llms.txt）从同一内容源同源长出英文，并用测试门把双语矩阵钉死**。第一道门是治理立项（G1），第二道门是内容责任（G3）——两道门过了，代码层是低风险机械活；而 Bing 侧今天的验证与 sitemap 底座，已经把 P2 的收录链铺好了一半。
