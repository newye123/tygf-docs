## 2. 执行原则（写死，不能中途改）

- **不重做已完成的东西**：R1–R5 改过的界面，只做缺陷修复与证据补齐。
- **每次只切一刀**：每批一个分支、一份差异、一份证据、可单独撤回；不做"一次改一大片"。
- **不碰合同**：行排除、计费、回执、冻结、报告分母等语义改动必须单独成批，同批同步所有受影响层与夹具，并跑 `test:batch-row-contract`＋`test:trust-chain`。
- **不加没人要的东西**：多稿整批报告、停止按钮、分组字体、自动学习等，未拍板一律不做；文案如实写"当前没有"。
- **提交、发布、删除每次问 Owner**；代码只推到 GitHub 再走测试站，禁止 force push。
- **判据只加不放宽**：测试红了先分"本轮引入"还是"存量"，存量的改钉当前事实并附负控，不删断言、不改跳过。
- **证据分级**：单测/命令输出为 A 级；浏览器实拍为 A 级但只证明渲染；真机 Photoshop 未跑就写"未验证"。
- **隔离**：多会话并行时各用独立 worktree；容器里那 107 个未提交改动不是本方案的写入面。

失败处置：共享 CSS 越界（单稿或弹层变样）→ 先截图对照，再收窄选择器；不在本批改全局变量。

### E6 全链路联调与发布（2–3 天，G 批后半）

目标：拿真环境证明"能用"，而不是只有单测绿。

步骤：

1. 代码推 GitHub：分支 push（非 force）→ 合入 `origin/develop` → 等 CI（`.github/workflows/security-ci.yml`）。
2. 测试站：从 `origin/develop` 出包；`release-preflight.cjs` 必须看到提交已在远端（未推＝拒跑）；部署后核 `.deploy-commit`、`/api/runtime-provenance`、PM2 状态、首页与 `/en` 200。
3. 真机走查（需 Owner 在场登录、选真稿、确认积分）：第 1 步真导表 → 第 2 步逐门确认 → 第 3 步矩阵与归属 → 第 4 步整批范围与费用 → 执行 → 结果与报告。至少 1 份稿×2 门语言；记录命令、截图、时间、扣费与退款。

5. 负控（隔离夹具）：错目标稿、过期确认、缺质检证据，必须分别被拒绝或显示"未检查"；恢复后摘要一致；不在真实材料/积分/生产任务上注故障。

7. 发布：测试站通过＋Owner 明确同意后才发生产（`origin/main`）；支付 flag 保持 false；发布挂号写 `main` short sha。
8. 交付件：md＋HTML、飞书卡片（讲人话）、`AI_MEMORY/TASK_LOG.md` 置顶＋`ledger.jsonl` 一行。

判据：T01–T26 有状态表；真机链路有产物与扣费证据；发布各步有明确授权记录；未完成项逐条列出。

失败处置：

- 出包 preflight 红：先确认提交是否已推远端；远端不可达是硬失败，不许跳过。
- 测试站 500：先看 nginx 与应用日志，区分"本机→CF 段抖动"与"应用失败"；别用模拟结果冒充。
- 真机失败：先按"两次找根因、两次不成就加日志、三次重写问题"的约定办，不凭猜改。
- 助手未就绪：如实标"未验证"，不把模拟件当实机。

| 测试红 | 本轮引入／存量 | 基线复跑对照；存量改钉当前事实＋负控 | 同一红 3 轮不收敛 → 停下重设计 |

| 后台覆盖与默认值不一致 | 覆盖快照过期 | 用 diff 工具核对，bootstrap 只补缺 | 覆盖写成新默认 → 回滚覆盖 |
| 单稿或弹层样式坏了 | 共享 CSS 越界 | 收窄选择器，前后截图对照 | 影响面扩到全站 → 回滚本批 |

## 5. 调整规则（怎么砍、怎么改）

1. **先保正确性，再保好看**。T05–T23 是正确性，T01–T04／T24／T26 是可用性与证据；时间不够先砍 P2 视觉细节（案例美化、窄屏微调、报告排版），不砍数字同源、状态诚实、异常恢复。
2. **新需求一律不进本批**。执行中冒出的"顺手加个按钮/加个汇总"先登记，Owner 点头再立批。
3. **合同类改动单列**。多稿整批报告、停止控制、逐稿历史这类缺 API 的能力，默认"不做＋如实写没有"；要做就单独立项，不混在 UI 批。
4. **证据不足就降级表达**。没测过的写"未检查"，没跑的写"未验证"，没授权的案例标"演示"。
5. **每批超 3 轮审查不收敛**：停手，回到问题定义，考虑换方案而不是继续打补丁。
6. **Owner 否决过的方案不重提**：分组配字体（③字号阈值／④逐层勾选）、批量内存保护闸、"已连接助手"常驻提示条等，按既有裁决执行。
