## 四、外部对标（能抄什么、要回避什么）

1. **上游引擎本身就是一座矿**（`github.com/storytold/photocraft`，Rust，实测 HTTP 200／69,670★／最近 push 今早）。它的 CLI 有 `convert / info / run --cmd / batch / commands / mcp` 六个子命令，`convert` 支持 `.jpg/.png/.webp`；它还有 JSON 控制协议与 MCP 通道、offscreen 快照渲染、真实 PSD 语料库（自带 psd-tools／ag-psd 作 oracle 并按 commit＋sha256 钉值拉取）。**可抄的最小动作**：把交付三件套里的 `jpg` 与"预检/回归语料"这两件事纳入引擎视野——但**先实测再承诺**（见 P2-1 的负控）。
2. **字体这件事别自研**。上游走"PostScript 名精确解析＋回退候选＋CJK 按 locale 排字形偏好"，断行用 parley（HarfRust＋UAX#14）／icu_segmenter。开源界做字体识别的 CNN 只有 artset/WhatTheFont 一类 27★、2023 年停更的复现件，WhatFontIs 本站访问 HTTP 500。**结论：#158 的脸名级方向是对的，不要顺手加"AI 识别字体"。**
3. **craft-fonts 这件事我们自己的两份文件互相矛盾**：`BUILD-MANIFEST.txt:56-62` 实测"带 CRAFT_FONTS_DIR 强制重建后 exe 字节完全相同（sha256 仍是 3cb06ed1…）⇒ CLI 的存活引用图不引用 CRAFT_FONTS"；同目录 `README.txt:13-14` 却写"不用 CRAFT_FONTS_DIR 指向固定 commit，日文字体回退会缺失"。**这是文档自相矛盾**，会误导下一次会话白跑 13 分钟重建，或误以为引擎侧字体回退已生效。修法：以 BUILD-MANIFEST 的实测为准，README 那半句改成"仅 GUI 构建相关，CLI 实测无关（附哈希）"。
4. **同类工具早就存在，只是不做 PSD 图层写回**：AE Sheets／LingoFlip（表格管理文本层＋AI 翻译＋**字体映射表**＋一次出多语言）是批量台 v13 交互现成的参照；Get Localization for Photoshop 用 **XLIFF 往返**（可把活交给任意译员）——它的社区实证翻车点"多语言同名文件互相覆盖只剩一份"正是我们必须防的（文件名带语言码）。
5. **护城河有书面证据了**：Crowdin 官方把 `.psd/.png/.jpeg/.ai` 明确划在"不支持文本翻译"之外（认作 assets）；psd-tools 官方文档明列 Not supported：「Editing of texts in type layers」；ag-psd 作者自报文字层支持不完整且竖排会写出打不开的文件。**这三条该写进对外对比页**——它证明"免 PS 无损写回文字层"是行业级难点，不是我们慢。
6. **收款不必等主体**：Creem 官方文档明确支持向大陆**个人**用支付宝打款（单笔上限 50,000 CNY，费率 3.9%+$0.40）；Paddle 对大陆个人是"不在禁用清单、仅软件、需审核"；Polar 支持国家表**不含大陆**；Lemon Squeezy 官方正在把用户迁往 Stripe Managed Payments（供应商整合期，**别把新收银台建在这栋楼上**）。
7. **可观测性别上重基建**：Sentry 自托管官方门槛 4 核/16GB＋Docker＋Linux（Windows 不支持），PostHog hobby 自托管要 Kafka/ClickHouse——单人运维扛不起。轻量替代：GlitchTip（MIT，兼容 Sentry SDK，换 DSN 即用）。**但更便宜的其实是零基建那条**：Windows 自带 WER LocalDumps 把崩溃转储落到可控目录（默认 `%LOCALAPPDATA%\CrashDumps`），正好治我们"失败现场落在 `os.tmpdir()`、重启即丢＋上传静默失败"这一条。
8. **自动更新不用发明**：Inno Setup 官方流程就是"自查新版→下载新 Setup→`/silent` 拉起、自身退出"，Setup 自带文件占用重试；防"静默替换下载 URL"的现成协议范式是 NetSparkle 的**签名 appcast＋哈希校验**。
9. **治理层**：我们的"机器列/人列分离＋投影前对账闸＋回读告警"这套，开源项目管理工具（Plane/Huly/Leantime）**都没有字段级写隔离**——不缺工具，缺的是"压实"。对症且可搬的最小动作有三个：① 台账条目改"碎片—消费—清空"（changesets 范式）；② 不可逆决策一决策一文件、编号即文件名、`superseded by` 双向链（ADR/MADR 范式，直接治"行号漂移"和"两案同号"）；③ 开场必读从"整档注入"改成"索引＋按需展开"（≤200 行索引，正文按需读）。
