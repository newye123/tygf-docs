④ 对抗式审查（第一刀砍我自己）

A1 我一度判"行距写了不变 ⇒ 撤掉这个字段"——错的
真因是没先关自动行距。outC（不关 55→55）对 outG（关了 55→133）。病根＝把"我没试对"读成"它不行"。规矩补齐：否定式结论必须穷举开关位。
A2 面板存的口径 ≠ PS 认的口径
面板存"族显示名+样式名"，PS 只认 PostScript 脸名；1605 脸只有 1319 个显示名，Noto Sans SC 一名挂七张脸。照现状接线必出静默换脸（实测 Arial→MyriadPro-Regular）。推翻 10-14 方案的"族+样式"字段设计。
A3 假保存（真缺陷，登记 #157）
不填字体名而只填行距/字距 ⇒ 校验整份拒绝、save 直接 return、localStorage 字节一字未变，界面照样回显"已保存到本机浏览器"。探针回显 ok=false / returnValue=undefined / bytes_unchanged=true；码 typography-persistence.ts:42,87-100 + typography-panel.tsx:103-106。
