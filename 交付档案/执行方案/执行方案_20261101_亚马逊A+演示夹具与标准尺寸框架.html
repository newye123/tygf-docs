01判定

结论

方案能落地，但整套压在一只未验证的假设上：用库写出的 PSD，Photoshop 认不认。
所以第一个任务不是做稿子，是花半天把这只假设证伪或证实。

为什么不用图译工坊自己当"品"

  • A+ 内容只有亚马逊上真实注册品牌的卖家才有——我们没有公司主体、不在亚马逊卖货，做一张自己的 A+ 页本身就是一句对外假话。
  • 软件自己讲软件，演示不出难的地方：数字单位、窄列表格、日文行首禁则、泰语无空格断词，只有实物商品稿会同时撞上。
  • 换成虚构商品，文案怎么写都不涉及对外主张，不用每句过禁用词表。

这一版刻意不做的

  • 阿拉伯语、希伯来语不进演示。从右往左写的语言全树没有任何写回处理（RTL 检索仅命中日历组件一行），放进去就是当场演示一个坏结果。缺口登记进 ISSUES，不藏。
  • 不上官网、不外发。09-24 的"产品测通前不做对外素材"与 10-06"不新拍宣传素材"两道令还在册，本轮产物定位＝夹具 + 本地演示件。
  • 二进制母版不进 git。仓库现状实测 0 个 psd/psb 被跟踪，保持——只提交规格与生成器。

① 库写的文字层 PS 认得出但不画。包围盒 0 0 0 0、合并导出暗像素 0；逐层触碰再另存后才出字（暗像素 2739）。所以母版构建必须是"node 出骨架 → PS 烘焙"两步，烘焙不是可选项。
