## §01 一句话结论

**先说路线，再说依据。** 拿到「能合法收钱」的最小路径是：注册**个体工商户**（免费，线上，约 1–3 个工作日）→ 域名实名 + 国内服务器（备案需包周期 ≥3 个月）→ 提交**单位 ICP 备案**（关键路径，通常 1–3 周）→ 管道资质三件套并行办理（微信支付 Native 扫码 + 支付宝电脑网站支付 + 一个海外 MoR）→ 工程接线。全程避开的唯一死路是：**用个人身份备案去卖东西**——个人备案不得含经营性内容（产品、价格、商品），会被注销；而经营性 ICP 许可证要求公司主体（注册资本省内 100 万），个体工商户办不了，所以「自营数字商品」的定位与话术要提前定死。

海外收款**不需要**国内主体走到最后一步：Stripe 对大陆主体不开放（需香港/美国公司），但 MoR（Merchant of Record）平台里 Creem、Waffo Pancake 等接受大陆个人，个人身份即可注册、可提现到支付宝/银行卡——这是无海外公司阶段唯一务实路径。

**项目侧现状**：支付宝全链代码已就位（`src/lib/server/payments/alipay.ts`，636 行；回调只推进 `paid_uncredited`，积分账本由 `creditPaidOrder` 唯一入账——文件头 :1-2）；6 个支付开关默认全 false（`src/config/featureFlags.ts:22-31`）。微信支付**无任何代码**（全仓 grep 0 命中），且微信支付官方 SDK 只有 Java/Go/PHP（商户文档 SDK 页），Node 侧计划用社区库 `wechatpay-axios-plugin`（MIT）。所以本方案落地成本的大头不在代码，在**备案与资质的时间线**。

## §03 五件事逐项核验（结论 · 硬条件 · 数字 · 依据）

### 3.1 个体工商户登记（「个人营业执照」）

- **结论**：全程线上（各省「一网通办」/政务 App），登记不收费；多地承诺 1–3 个工作日办结。2025-07-15 起施行的《个体工商户登记管理规定》明确：仅通过网络开展经营活动的经营者，可用网络经营场所登记。
- **材料**：经营者身份证；经营场所信息（自有/租赁凭证，或网络经营场所）；店铺名称（个体户命名规范内）。微信支付侧对个体户商户简称有专门规则：「个体户+经营者名称」或「经营者名称+业务」（商户平台入驻页）。
- **办完后的三件小事**：税务报到并按期申报（个体户一般为小规模纳税人、按季申报，具体以主管税务机关口径为准）；每年 1 月 1 日–6 月 30 日报送年报；刻章、对公账户均为**可选**——微信支付接受「经营者对私账户」，公众号认证个体户可走法人验证、无需对公账户（腾讯客服）。
- **影响面**：个体户执照同时是 ICP 备案的主体、公众号/小程序的主体、微信支付商户号与支付宝账号的主体——**四处必须同一张执照**，这是全链一致性的根。

### 3.2 ICP 备案（决定生死的一环）

- **结论**：国内服务器必须备案；「网站卖东西」属于经营性内容——**个人备案不能放产品/价格/商品**（云厂商备案口径：个人备案网站不得涉及经营性内容，违者注销备案）。因此本业务必须做**单位备案**，个体户可作为网站主办单位（省管局办事指南明确列示「个体工商户」）。
- **个体户办不了的事**：经营性 ICP 许可证（《增值电信业务经营许可证》）要求「经营者为依法设立的公司」且注册资本省内 100 万/全国 1000 万（《电信业务经营许可管理办法》第六条）；腾讯云 FAQ 明示「个体工商户不能申请，必须为公司」。→ 这不是本方案的硬伤，但决定了定位话术：页面按「自研软件授权/数字商品自营」呈现，避免「会员服务费/平台佣金/撮合交易」类描述；若未来做平台化，再升级公司主体（红队 Q2）。
- **流程与时长**：买服务器（备案要求包周期 ≥3 个月，云商 FAQ）→ 域名实名认证 → 接入商（云商）提交真实性核验 → 管局审核（官方上限 20 个工作日，通常 1–2 周）→ 备案号下发、网站底部悬挂 → 上线后 30 日内做公安联网备案。
- **罚则锚点**：未取得许可擅自从事经营性互联网信息服务，罚 10 万–100 万（《互联网信息服务管理办法》第十九条）。
- **与支付的耦合**：支付宝要求网站已 ICP 备案且**备案主体与支付宝账号主体一致**；微信 Native 要求 PC 网站域名已备案，主体不一致需加盖公章的网站授权函。→ 备案是支付签约的前置，排在关键路径上。

### 3.3 支付宝（电脑网站支付）

- **结论**：支持企业/个体工商户签约「电脑网站支付」，费率 0.6%。签约硬条件：网站可正常访问、经营内容与商品信息完整、网站已 ICP 备案且备案主体与支付宝账号主体一致（不一致需授权函）。
- **新商户两件事**：结算周期限制（新签约存在「满一定期限/连续交易后」才转常规结算的口径，签约页为准）；收款额度随资质完善提升（资料不全时有限额口径）。→ 别把「签约成功」当「全速收款」，现金流预估要留缓冲。
- **项目侧**：代码已就绪，只欠主体资质 + 密钥配置 + 开关灰度（`alipayPaymentsEnabled` 等 6 个开关均 false，`featureFlags.ts:22-31`）。

### 3.4 微信支付（PC 网站 · Native 扫码）

- **结论**：个体户可申请；申请免费；费率 0.6%–1%（按类目）；审核 1–2 个工作日。PC 网站场景用 **Native 支付**（商户生成二维码，用户微信扫码）。
- **准入硬条件（Native 产品文档）**：① 主体支持个体工商户；② 应用类型需「**已认证**的服务号/公众号，或已认证小程序，或已认证移动应用」；③ PC 网站域名需 ICP 备案（主体不同需授权函）；④ 入驻时选择 PC 网站经营场景并绑定商户号↔APPID。
- **认证成本**：公众号认证 300 元/次/年（个体户可走法人验证，无需对公）；**小程序认证对个体户为限时优惠 30 元/次**（微信开放社区官方精选帖，2025-10/11 多次确认）。→ 两条路都可行，小程序路径更省，但需注意「已认证」与「主体一致」两条不放松。
- **开发形态**：APIv3 Native 下单拿 `code_url` → 前端出二维码 → 扫码支付 → 回调验签解密（微信支付公钥模式）→ 复用项目既有的「回调只推进 paid_uncredited、积分唯一入账」模式。
- **缺口**：官方 SDK 无 Node（官方仅 Java/Go/PHP，商户文档 SDK 页）；社区库 `wechatpay-axios-plugin`（MIT，覆盖 Native/H5/JSAPI、回调解密、退款、账单）为首选（见 §04）。

### 3.5 海外收款（无海外公司路线）

- **结论**：Stripe 对大陆主体不开放（支持地区含香港、不含大陆；大陆无官方办公室/代理——2026 年多家评测一致）。无海外公司时，务实路径是 **MoR 平台**：平台作为法律卖方处理税务/发票/拒付，你只管提现。
- **大陆个人可用的候选（第三方评测交叉，注册前以官方后台复核）**：
  - **Creem**：3.9% + $0.40；个人提现到支付宝（评测口径：单笔 ≤5 万元、年 30 万–60 万额度）；店铺审核 24–72 小时；要求网站上线、价格可见、隐私政策/条款/客服邮箱与域名一致。
  - **Waffo Pancake**：3.9% + $0.50；CNY 提现到银行卡或支付宝；$20 起提、提现费 1%（最低 $10）；平台较新，长期稳定性待观察。
  - **Paddle**：5% + $0.50；接受个人/sole trader 注册；电汇或 Payoneer 提现，**能否到大陆银行官方未说明，注册前须问客服**；<$10 产品需单独定价。
  - **Dodo Payments**：接受大陆个人/企业（评测口径），国际交易与订阅有附加费，需单算。
  - **PayPal（辅助）**：大陆账户可收跨境款，4.4% + $0.30 口径，提现 $35/笔，风控冻结风险高——只做辅助通道，不当唯一。
- **排除项**：Lemon Squeezy（被 Stripe 收购后 2026 起停新申请，迁移目标 Stripe Managed Payments 亦不接受大陆）；Polar（无大陆提现通道）；Stripe Atlas（无海外主体前 $500 注册 + 后续维护成本，起步阶段不划算）。
- **税务提醒**：MoR 只处理海外销售税/增值税；**中国境内纳税义务不变**（个体户经营所得同样并入申报）。

## §04 GitHub 开源可复用调查（先查了，再决定）

- **支付宝：已有自研代码，不引第三方**。原因：回调幂等与积分唯一入账是信任链合同的一部分（alipay.ts:1-2），换库等于换合同。
- **微信支付 Node SDK**：官方无 Node 版（官方仅 Java/Go/PHP，商户文档 SDK 页）。
  - 首选 `TheNorthMemory/wechatpay-axios-plugin`（MIT；npm 0.9.6，2026-02 仍更新；Native/H5/JSAPI 下单、回调解密、退款、对账单、CLI；有独立文档站 wechatpay.js.org）。
  - 备选 `klover2/wechatpay-node-v3-ts`（ts/js 封装，功能面略窄）。
- **发卡/自动售货系统（订单→回调→发货→补单 的成熟模式）**：
  - `assimon/dujiaoka`（独角数卡）：12,136 ★、MIT，但仓库已 **ARCHIVED**；`myxiaoao/dujiaoka-next`（Laravel 12 + Filament 3，34 个支付网关）为活跃分支；`BEpusdt` 是 USDT 网关（配合独角数卡）。
  - 结论：**只借流程模式**（订单状态机、回调补单、卡密库存、对账导出），**不引入**——PHP 栈，且与本项目 DB 业务事实（PaymentTransaction/CreditOrder）双写会直接违反「一个业务事实一个 owner」。
- **License/激活码系统**（Keygen、Keygate AGPL、Keymaster ed25519 离线验签、go-license-api、Keyvory、Licora、codegate 等）：本项目已有自研订单+激活邀请体系，**不引入**。可留档借鉴点：ed25519 离线验签（Keymaster 模式）与幂等键设计，与项目「信任链」合同同构，未来若做离线激活可参考。
- **境外收款**：MoR 是 SaaS，无开源可复用项；若未来上 Stripe，Node SDK 即官方 `stripe` npm 包，不需要现在决策。

## §05 对抗式审查：红队八问与裁定

**Q1 用个人备案直接把站挂上去卖行不行？**
不行。个人备案网站不得展示经营性内容（产品/价格/商品），违者注销备案（云商备案口径）。裁定：**必须个体户/单位备案**，没有省钱捷径。

**Q2 个体户办不了经营性 ICP 许可证，自建站卖积分会不会被认定「经营性信息服务」？**
这是真实的合规空档，且无法在本方案内彻底消除。缓解三件事：① 定位「自研软件授权/数字商品自营」（非平台、非佣金、非信息中介）；② 页面措辞避开「会员服务费、平台服务、撮合」类描述；③ 规模上去后升级公司主体再评估许可。风险等级：**中（留档，不阻塞起步）**。

**Q3 微信 Native 的「已认证服务号」是硬门槛吗？花多少钱？**
是硬门槛（产品文档原文）。个体户两条路：公众号认证 300 元/年；或小程序认证 30 元/次（限时优惠，官方社区口径）。裁定：**走小程序（30 元）或公众号（300 元）均可**，注意「已认证」+「主体与商户号一致」两条。

**Q4 顺序搞反会不会白做？**
会。支付宝签约要求备案主体一致；微信 Native 要求备案域名。备案是两条支付通道共同的前置 → **顺序必须是：个体户 → 域名+服务器 → 备案 →（并行）公众号/小程序认证 → 商户号/签约**。反向操作（先签约后备案）会被驳回重来。

**Q5 直接上 Stripe / 不做 MoR 行不行？**
不行。Stripe 大陆主体不可开通；PSP 模式下各国 VAT/销售税要自处理（外包年成本 $5K–20K 级）——MoR 是当下唯一务实起点。但 **MoR 不当唯一通道**（Creem 提现额度有限、Waffo 年轻、Paddle 到账未明），PayPal 留作辅助。

**Q6 退款怎么办？**
微信必须同步实现 APIv3 退款与退款回调（对照支付宝侧 alipayRefundEnabled 的既有模式），否则差评与投诉无法闭环；回调幂等要按收口方案 P1.4「A2 用例 3」实弹重放验证（同一 notify 原样重发不重复入账）。

**Q7 税务谁管？**
MoR 只处理海外侧税务；国内个体户经营所得照章申报（含 MoR 收入），年报照做。会计口径待 Owner 确认后由专业人士复核。

**Q8 治理红线有没有被本方案触碰？**
没有。全部支付开关保持 false（`featureFlags.ts:22-31`）；密钥只进环境变量/受控凭据（密钥纪律）；本报告零登记、零签约、零付款、零代码改动。**执行权在 Owner，逐阶段批准。**

## §06 执行方案（分阶段 · 依赖 · 时长 · 负责人）

- **阶段 0 · 决策（Owner，0.5 天）**：确认主体路线（建议个体户起步）与主体名称（全链一致的那个名字）；授权起点。
- **阶段 1 · 登记（Owner，1–3 天）**：线上个体户登记；同步实核现有测试站域名/服务器（`tuyigf` 相关，见 §09）并补服务器包周期 ≥3 个月、域名实名。
- **阶段 2 · 备案（关键路径，1–3 周）**：单位 ICP 备案提交与核验；上线后 30 日内补公安联网备案。
- **阶段 3 · 通道资质（并行，执照到手后 2–5 天）**：注册并认证公众号/小程序（300 或 30 元）→ 微信支付商户号入驻（选 PC 网站场景 + Native 权限，填备案域名与 APPID）→ 支付宝开放平台个体户账号 + 签约电脑网站支付。
- **阶段 4 · 工程接入（资质到位后 1–2 周）**：微信 Native 接入（新 provider=wechatpay、channel=native，复用 PaymentTransaction 与「回调只推进 paid_uncredited」模式）→ 回调验签（微信支付公钥模式）→ 退款链路 → smoke（1 分真单 + 重放幂等）→ 开关灰度（creditPacks → 支付宝 → 微信）。
- **阶段 5 · 海外通道（可与阶段 2–4 并行，3–7 天）**：补齐价格页/隐私政策/服务条款/客服邮箱 → Creem 或 Waffo 注册与店铺审核 → 1 笔真单 + 提现验证 → PayPal 备用通道登记。
- **阶段 6 · 上线闸（对齐收口方案 P1.6）**：协议签署 + §07 八道门全绿 + 三步放（网站→助手→支付开关）每步 Owner 批准。
- **最快总时长：约 3–4 周**（备案在关键路径；阶段 3/5 并行压缩）。

## §07 上线闸门 G1–G8（全绿才开支付开关）

- [ ] G1 主体一致性：执照名 = 备案主体 = 商户号主体 = 公众号/小程序主体 = 支付宝账号主体
- [ ] G2 备案号下发、网站底部悬挂；公安联网备案已排期
- [ ] G3 微信 Native 权限 + 支付宝电脑网站支付签约均完成
