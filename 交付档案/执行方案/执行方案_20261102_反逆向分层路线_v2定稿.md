## 0. 本质上要成什么（可判定一句）

**让"读走我们的代码"不再等于"拿走我们的能力"**：判断由服务端给出、客户端只持有不可读计算体、每次取用都要消耗一条服务端签发且一次性失效的凭证。

由此得到唯一一条硬判据——**最深处结论**：这套系统里真正读不走的资产是"**签发权 + 一次性消费状态**"（HMAC 密钥 `EXECUTION_TICKET_SECRET`，现成设施 `src/lib/server/execution-ticket.ts:18`；`BillingChallenge` 的 issued→consumed 一次性凭证 `src/lib/server/billing-challenge.ts:89,248`）。凡落在用户机器或发布包里的字节，理论上都可读；动作若不同时命中下面三者之一，就归为心理安慰，不进排期：① 让读出来**没用**（判断交给服务端）；② 让读出来**很贵**（明文→编译件/native）；③ 让取了**能被看见、能被断、能举证**（观测·吊销·归因）。

## 2. 最深的一层：为什么"给 exe 加密"不解决问题

三条依赖互相咬着，构成死结（只针对 v15/绑定这一代）：

1. 助手在本地跑 `compileBindings` 出绑定计划与摘要，服务端**不重算这一段** ⇒ 客户端必须持有可读裁决代码；
2. 助手的完整性自校验要**读磁盘上的 JS 原文**才算哈希（`server.js:122-141`），且 `MANIFEST.json` 期望值就放在**同一个可写目录**里 ⇒ 只要还想"运行时自证"，`pkg.assets` 的明文副本就撤不掉；
3. 缺目录时 `server.js:143-145` 把异常吞成 null-cores 静默降级（端点才 503，exe 照启）⇒ 这道自校验本身就是假绿温床。

⇒ **顺序只能是**：先把裁决与报价权威搬到服务端（断第 1 条），再撤 assets 并把自校验从"读原文"换成"pin 摘要"（断第 2 条，且必须防止 pin 与被校验物同盘可写），最后处理 jsx 的可读性（第 3 条）。倒过来做就是把安全换成一个能被同目录改写的 JSON 字段。

**还有一条 C 路挖出来的下限**：助手送脚本进 Photoshop 只用 `DoJavaScriptFile`，执行前把脚本**明文写出临时 .jsx**（`server.js:2023-2027`、wrapper 生成 `:1734`/`:2008`）。所以 jsxbin 化之后，"版本常量与 include 外壳"仍是明文，而逻辑进字节码——能测的是"执行瞬间磁盘有没有逻辑明文"，**测不到**挂钩引擎在内存里 dump 还原；ExtendScript 本身还有反编译生态。⇒ 这条线的诚实上限只能写到"抬高成本"，"防破解成功"这类措辞禁止出现（项目既有口径，不许松动）。

### E0.5 关掉我们自己的出口：明文母本不再随 Web 包出门｜半天到 1 天

- 事实：`git archive HEAD` 带出 10 个 `.jsx`（含 8 个活引擎脚本），而 distribute 路由又**必须**在服务器上读这些文件（`src/app/api/local-assistant/scripts/distribute/route.ts:56-68` `resolveScriptSourceDir` 找 `process.cwd()/download/local-assistant/scripts`）。⇒ 直接 `export-ignore` 会把分发打断，**必须同批改落点**。

- 判据：`git archive --format=tar HEAD | tar -t | grep -c '\.jsx$'` = **0**；同时测试站 distribute 接口实测仍返回 5 个脚本、助手 `/ping` `phase=ready`（**两半都要验，只验前者=把线摘了**）。
- 风险：动的是发布与分发链，属高风险单向门 ⇒ 必须先在测试站跑一轮，且部署要 Owner 点头。

## 5. 明确不做

- **盘上静态加密（旧 C 案）**：对同权限攻击者增益≈0（既往实测一条 `reg.exe` + 同派生 76 ms 逐字节还原），且会被分发管道自动撤销。不做。（诚实标注：76 ms 那组数是 09-22 那轮测的，本轮未复跑。）

1. **把记忆当现状**——v1 写"jsxbin 产物不在任何分支"，实际分支存在（C 路+我 `git branch -a` 复跑）。原因：沿用 09-23 那条记忆没重跑，而它当时是对的。补法：写成结论前，否定式一律先跑 `git branch -a --list` / `git log --all --grep`，命令与退出码进正文（本条已在 §3-E3 落地）。
