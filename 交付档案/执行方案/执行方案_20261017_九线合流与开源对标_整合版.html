02四路开源调查

子 Agent 调查，主 Agent 逐条复验。外部结论里最关键的一条推翻了既定路线。

维持自研

折行算法

BudouX 只给日文短语切分，不给宽度、不给禁则；linebreak 禁则表最全但数据停在 Unicode 13；text-wrap 需浏览器引擎，离线写回 PSD 不可用。

s5 值钱的是「整数定点宽度 + 固定行数 DP + tier/fail 分级」，开源件零覆盖。不引库，补两张禁则表即可。

借模式

批量工作台

不为一条线性链引状态机库。该引 react-dropzone（getInputProps() 直接接活死控件）与 TanStack Table（headless，不会塞假 0%）。

tus 协议的纪律最值钱：续跑前先问真实 offset，对不上就拒绝 ⇒ 重算每格状态，不信旧百分比。铁律补一条：失败即停 ≠ 丢弃已完成。

冻结

免 PS 引擎

PhotoCraft 的 issue tracker 里 type.edit 写回是明确坏的：

#6968（今天开，high）写回后 PS 2026 27.10 打开即崩；#6971 文件能开但文本层仍是旧文字（Txt2 不同步）；#6129 每次编辑重建 TySh，丢 13+ 段落字段。

⇒ PC-E 出厂面与开旗标立即冻结；退回「免 PS 扫描 + 预览」，写回继续走 PS。

可做待批

GEO 边缘缓存

Vary: rsc… 是 App Router 13.0 起默认加的，不是动态标志；no-store 来自动态渲染。

Cloudflare Edge TTL → "Ignore cache-control"（override_origin）能覆盖 no-store，但只能缓存无 rsc 的匿名 HTML，RSC 必须 bypass，否则串内容。终局是 ISR + purge。
