# 英文站字体「晚发现」修复：执行方案（2026-10-22）

## 一句话

**这一轮不看代码，看线上。** 我用真浏览器加 SSH 隧道对**已上站的测试站**做了一轮巡检，查出一个真实的用户可见缺陷：英文站**没预加载自己的字体**，浏览器要等 CSS 下载完才开始找字体 —— 实测字体请求发生在 **3380 毫秒**（文档 0 毫秒、CSS 1393 毫秒），比中文站晚了整整一个发现阶段 ⇒ 英文首页那个大标题（就是首屏最重要的那个元素）**先用回退字体画一遍、再换成思源黑体**（肉眼可见的闪一下换字）。

修法是**一个 preload 标签**；但真正的交付是**两道门** —— 让「谁把 preload 删了没人管」这件事以后**必然被抓到**。

## 一、巡检怎么做的（可复跑）

- **真浏览器**（本机 chromium + SSH 隧道 `localhost:3000` → 服务器 3001，绕开 Cloudflare 与令牌门）：真实渲染、真实字体请求、真实请求时间线、真实控制台。
- **HTTP 巡检**（18 个公开面 + 21 条站内链接）：**18/18 全 200；站内 4xx/5xx ＝ 0**。
- 另跑英文站自己那道版式门（真浏览器量几何，42 断言）：rc=0。

**巡检边界（如实）**：工作台（`/#workbench`）要登录态，**我这边进不去** ⇒ 多稿台的界面仍只能由您点；本轮只覆盖**公开面**。

## 二、查出来的东西（逐条自审）

**真缺陷（要修）**

- 英文站一个 font preload 都没有 ⇒ 字体晚发现。实测时间线：`document@0ms` → `stylesheet@1393ms` → `script@1394ms` → **`font@3380ms`**。字体是**最后一个关键资源**。中文站对照：预加载了 4 个分片，没有这个问题 ⇒ **两站不对称**。
  修法：给英文站布局加一个 preload 标签。**放在布局而不是首页** —— 因为英文站的字体规则挂在 `html[lang="en"] body` 上，**全部 /en 页面**（首页/下载/条款/隐私）都渲染英文正文；这和中文站「只首页预加载」不同（中文站其余页面不渲染中文正文，预加载会白拉分片）。

**门缺口（这才是根因 —— 缺陷能上线，是因为没人管）**

- 英文站自己那道**真浏览器门**量了字体请求，却**没断言「必须预加载」** ⇒ 这类「晚发现」能过门。⇒ 加一条：英文页必须有指向自己字体子集的 preload；并把中文站「4 个分片全预加载」也钉住防回退。
- **出包门**也只管「字体文件与清单一致」，不管「谁预加载它」 ⇒ 删了 preload 没有任何一道门会红。⇒ 在出包门里加一条**结构性断言**「声明这个字体的那个布局必须预加载它」—— 这道门**在合同总闸的链尾**，每次出包都会跑。

**巡检本身没固化（我自己的责任）**：这轮的全站死链巡检是手写探针，**没变成可复跑的门** ⇒ 如实记为未固化，另立项，不假装有门。

**差点误报（动手前查清了，没写进任何文档）**：我一度以为「已提交的助手源码 require 了未提交的文件 ⇒ 干净检出下助手加载不了」—— **实测证伪**：`git grep` 搜的是**工作树**（含别人在飞的改动），改看提交版本就没有那个 require。已提交树是自洽的。已记一笔，免得下一班重复查。

**顺带核过、确认没问题的**：英文页真浏览器读数（字体族正确、字体 `loaded`、英文作用域类在、语言切换按钮在、**控制台 0 错误**、**无横向溢出**）；英文大标题是**两行两个元素**（之前看着「少个空格」是拼接假象，**不是文案缺陷**）；公开面 18/18 全 200、站内链接 0 条坏链。

## 三、执行五段

1. **修**：英文站布局加字体 preload（覆盖全部 /en 页面）。
2. **加门 A（真浏览器）**：英文页必须预加载自己的字体；中文页必须预加载全部 4 个分片。
3. **加门 B（出包门）**：布局必须预加载该字体。
4. **出包上站**（沿用前两轮的六段法：干净树 → 17 门全绿 → 分片上传 sha256 逐字一致 → 部署 → 服务器侧五项独立实测 → **真浏览器复测**）。
5. **记忆、台账、报告、飞书**。

**门只钉「preload 标签在」这个确定性事实，不钉毫秒数** —— 毫秒数随网络抖，钉了就是假门。「晚发现 2 秒」是**这次为什么要修**的量化证据，**门**负责钉住**原因**。

## 四、这轮不做

- **不碰内存闸会话的在飞改动**（那个会话此刻正在改助手与版本文件，我一动就搅乱）。
- **不碰多稿工作台**（v13 已上站；本轮是英文站的一个独立缺陷）。
- **不做「按组整组排除」**（ISSUES #162）—— 那是**要您拍板的产品决定**，不是顺手能修的缺陷，本轮不夹带。
- **不做全站死链巡检门**（本轮只手工跑了一次）⇒ 如实登记为未固化。
- 不碰生产站、不动 `main`、不推远端、不碰数据库。

## 五、回滚

服务器有自动备份与回滚点；代码侧 `git revert` 本轮那一笔即可（**只回 preload ＋ 两道门**，不动 v13 与英文站工作）；台账追加新状态行再投影。

1. **工作台界面仍无浏览器实测**（我这边没有登录态）⇒ 多稿台那 8 条点验清单仍在您手上。
2. **全站死链巡检未固化成门**。
3. **助手门槛本轮会再抬一次**（内存闸会话已把 3.7.21 入库 ⇒ 测试站要求 3.7.21；3.7.19/3.7.20 仍在归档可回退）。
4. **服务器磁盘紧**（剩 4.8 G / 88%）。
5. **字体子集仍是构建期快照**（运营台运行期改出的新字落系统字体，字形不一致非破版）。
