01判定

结论

这条链上没有不可解的难题，只有一条不能踩的线和一个不能省的等待：
个人备案不能卖东西；备案谁也绕不过。

现在就能做、不花钱的

  • 个体户登记：线上办、不收费、约 1–3 个工作日；它同时是备案、商户号、公众号/小程序、支付宝五处的主体，先把它定下来，全链的「同一个名字」问题就解决了。
  • 海外 MoR 注册：不依赖国内任何资质——Creem / Waffo Pancake 接受大陆个人，审核 1–3 天，跑通第一笔海外收入可以先于备案完成。
  • 支付宝侧工程：代码已就位（src/lib/server/payments/alipay.ts，636 行；回调幂等与积分唯一入账已建模），资质到手后是配置问题不是开发问题。

不能幻想、不能省的

  • 个人身份备案卖货：个人备案不得含经营性内容（产品、价格、商品），会被注销——这条路直接排除。
  • 先签约后备案：支付宝要求备案主体与账号主体一致，微信 Native 要求备案域名——顺序反了会被驳回重来。
  • Stripe / 个人 Paypal 硬扛海外：Stripe 不对大陆主体开放；PSP 模式下各国 VAT 自处理不现实——MoR 是唯一务实起点。
  • 跳过「已认证」：微信 Native 必须绑定已认证服务号或已认证小程序，认证费 300 元/年（公众号）或 30 元/次（个体户小程序优惠价）省不掉。

03五件事逐项核验

3.1 个体工商户登记

免费 · 1–3 天
  • 全程线上（各省一网通办/政务 App），登记不收费；承诺时限常见 1–3 个工作日。
  • 2025-07-15 起施行的《个体工商户登记管理规定》：仅网络经营可登记网络经营场所。
  • 材料：身份证 + 经营场所信息 + 名称。微信商户简称规则：个体户+经营者名，或经营者名+业务。
  • 办后：税务报到并按期申报；每年 1/1–6/30 年报；对公账户与刻章可选（微信支付收经营者对私账户；公众号认证个体户走法人验证）。

3.2 ICP 备案（关键路径）

1–3 周 · 卡先后顺序
  • 国内服务器必须备案；卖东西属经营性内容 → 必须单位备案（个体户可作为主办单位，省管局指南列示）。
  • 个人备案不得含经营性内容（产品/价格/商品），违者注销——排除项。
  • 经营性 ICP 许可证：需公司主体、注册资本省内 100 万（《电信业务经营许可管理办法》第六条）；个体工商户不能申请（云商 FAQ 明示）→ 定位话术按「自研软件授权/数字商品自营」写，避开会员费/佣金/平台类描述。
  • 流程：服务器（包周期 ≥3 个月）→ 域名实名 → 接入商核验 → 管局审核（上限 20 工作日，通常 1–2 周）→ 底部悬挂备案号 → 30 日内公安联网备案。

3.3 支付宝 · 电脑网站支付

费率 0.6% · 代码已备
  • 支持企业/个体工商户签约；网站须可访问、商品信息完整、已 ICP 备案且主体与支付宝账号一致（不一致需授权函）。
  • 新商户有结算周期限制与额度限制口径（随资质完善提升）——签约成功 ≠ 全速收款，现金流留缓冲。
  • 项目侧只欠：主体资质 + 密钥配置 + 开关灰度。

3.4 微信支付 · PC 网站 Native

费率 0.6%–1% · 审核 1–2 天
  • 个体户可申请、免申请费；PC 网站场景 = Native 扫码（下单取 code_url 出二维码）。
  • 硬条件：应用类型须「已认证服务号/公众号 或 已认证小程序 或 已认证移动应用」；PC 域名须备案（主体不同需加盖公章授权函）。
  • 认证成本：公众号 300 元/年（个体户免对公）；小程序对个体户限时优惠 30 元/次（官方社区口径）→ 两条路都通。
  • 回复调：微信支付公钥模式验签解密；复用「回调只推进 paid_uncredited」模式。

3.5 海外收款 · MoR 路线

不依赖国内资质 · 先跑第一笔
  • Stripe 不对大陆主体开放（支持地区含港不含陆）→ 无海外公司阶段排除。
  • 候选（大陆个人可用，注册前以官方后台复核）：Creem 3.9%+$0.40（提现支付宝，额度评测口径单笔 ≤5 万、年 30–60 万）；Waffo Pancake 3.9%+$0.50（CNY 提现银行卡/支付宝）；Paddle 5%+$0.50（个人/sole trader 可，大陆到账官方未说明，先问客服）；Dodo 备选。
  • PayPal 仅辅助（约 4.4%+$0.30，提现 $35/笔，冻结风险）。
  • 排除：Lemon Squeezy（2026 停新）、Polar（无大陆提现）、Stripe Atlas（起步阶段成本不划算）。
  • MoR 只管海外销售税；中国境内纳税义务不变。

05对抗式审查：红队八问与裁定

#质疑裁定
1个人备案直接挂站卖货行不行？不行 个人备案不得经营性内容，违者注销——必须个体户/单位备案。
2个体户办不了 ICP 许可证，被认定经营性怎么办？真实空档·中风险 定位自研授权/数字商品自营，避会员费/佣金话术；规模大了升级公司再评估。

5直接上 Stripe / 不做 MoR？不行 大陆主体不可；MoR 唯一务实起点，但不作唯一通道，PayPal 辅。
6退款怎么办？必须同批做 微信 APIv3 退款 + 回调；幂等按 A2 用例 3 实弹重放验证。
7税务谁管？境内照章 MoR 只处理海外税；个体户经营所得（含 MoR 收入）并入申报，年报照做。
8治理红线触碰了吗？没有 开关全 false；密钥只进环境变量；本报告零执行。
