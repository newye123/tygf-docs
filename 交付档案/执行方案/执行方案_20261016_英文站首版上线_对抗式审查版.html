英文站首版上线执行方案

不是把中文改成英文就行。英文站是独立语言版本，需要独立网址段 /en、独立 lang="en"、中英文互指 hreflang、sitemap 两语并列、llms.txt 英文段、站内语言切换、英文 404，还需要一个正式英文名。现有英文站“只有文字”，缺的正是这些骨架。

核心判定

不是“搜替换中文”。开源参考 Docusaurus（seata.io 中英文）、VitePress（locales 独立标题/导航）、Nextra（[lang] 路由 + _dictionaries 词典），共同点是：独立路由、独立文案源、显式语言切换。中文用户可见文案、支付、API、工作台全部不动。

本轮做 /en 首页 + /en/download 两页，不建 /en/terms、/en/privacy（等英文条款定稿），现行 404 fail-closed 正确。8 项对抗发现中 1 高 / 3 中 / 4 低（F1 英文披露断言缺失最重），F4（英文法律链接）和 F6（email vs 微信承诺口径）需 Owner 拍板，不阻塞代码。

五路对抗式审查反对方会怎么质疑，怎么拆招

结构路

src/app/(zh)/, src/app/en/

中文页面按原 URL 不变移入 (zh)/ 路由组，删掉根 app/layout.tsx，由 (zh)/layout.tsx 当中文根布局；新建真实目录 src/app/en/，放英文根布局（lang="en"）、首页、download、404。

质疑：改路由会不会弄坏中文旧 URL？

拆招：(zh) 是路由组，不改 URL；新增 /en 才是真实段。关键：必须用真实目录 en/，不能用 (en)/，否则 Next.js 报两个平行页面撞车。

内容路

src/config/siteContentEn.ts（新建）

英文 FAQ 6 条 + 营销文案，对照现行中文 siteContent.ts 诚实镜像，不写未经核实的新承诺；英文站不从 SiteSetting 数据库读内容（避开 #130 数据库漂移）。

质疑：英文说 email 联系，中文说微信，矛盾吗？

拆招：这是 F6 承诺分歧（siteContentEn.ts:96），需 Owner 拍板确认 email 是否为真实运营承诺；本轮不阻塞代码。

SEO/GEO 路

src/app/sitemap.ts，两个 layout，public/llms.txt

sitemap 加 /en、/en/download 与两语互指 alternates（x-default 指中文根）；中文页补 alternates 互指；每页一条 canonical；两布局补 openGraph.url；中文侧补 alternateLocale: ['en_US']；llms.txt 加 ## English 段；JSON-LD 英文侧 inLanguage: en。

质疑：不做 og:url / sitemap 会怎样？

拆招：F2/F3 实测 og:url 双语皆缺、locale alternate 不对称，社交分享 URL 归属不明。llms.txt 硬编码生产域名（F7），必须和 /en 页面同一次提交上生产，否则指路 404。

法律合规路

en/layout.tsx:82-114（页脚）

本轮不建 /en/terms、/en/privacy（G3 口子）。但英文页脚和正文里根本没有法律页链接（F4：Privacy Policy 是纯文本无锚点），英文用户无路可达。

质疑：怎么办？

拆招：英文页脚加带语言标注的 /terms、/privacy 链接（注明中文），或排期英文法律页；由 Owner 拍板，不阻塞代码。

测试与回滚路

scripts/smoke-seo-consistency.mjs，deploy/deploy-release.sh

smoke 加英文断言（sitemap 路径、hreflang 三语闭环、en JSON-LD inLanguage: en、FAQ 可见、llms.txt 英文段），补英文 FAQ 披露断言（镜像中文 :366-367，防 #130 类漂移静默打进英文站）；deploy-release.sh 补 NEXT_PUBLIC_SITE_URL 注入。

质疑：出问题怎么回退？

拆招：零数据库、零迁移；未提交时撤回本片路径，已提交时 git revert。验收必须跑 tsc、lint、seo-consistency 与本地 /en 200 检查。

5

/en/terms、/en/privacy、英文 OG 图片、英文 email/应用商店文案、助手协议英文化，留给第二片。

验收尺（可复跑）

  • npx tsc --noEmit 返回码 0。
  • npm run lint 返回码 0。
  • 本地起服务，npm run test:seo-consistency 全 PASS（含新英文断言）。
  • curl 本地 / 和 /download：路径不变，中文首页 HTML 与改前一致（lang="zh-CN"）。
  • /en 和 /en/download 返回 HTTP 200，，只有一条 canonical，hreflang 三语种互指闭环。
  • sitemap.xml 6 条 URL（4 中文 + 2 英文），英文条目带 xhtml:link alternate。
  • git status 只含本片改动；本轮不提交（除非另行要求）。

不做的事（OUT OF SCOPE）

  • 全站 i18n 框架（next-intl 等）、[lang] 动态段改造。
  • Google Search Console 建立、除 Bing 以外的站长平台。
  • 生产 FAQ 漂移修复（#130 挂账）、百度链路（#131）。
  • 英文 OG 图片、英文 email/应用商店文案、助手协议英文化。
