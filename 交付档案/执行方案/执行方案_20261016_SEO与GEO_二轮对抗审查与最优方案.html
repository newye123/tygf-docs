3.5 Cloudflare「Markdown for Agents」—— 新选项，本轮裁定归档

10-10 审查只看了 continuedev/next-geo 的源站实现并判「本期不做」。但 2026-02-12 Cloudflare 已发布边缘侧方案，性质不同：

维度实测事实
机制客户端带 Accept: text/markdown，CF 从源站取 HTML 后边缘转 markdown
代码改动零（无需 md 孪生文件、无需源站协商）
自动附带vary: accept、x-markdown-tokens、content-signal: ai-train=yes, search=yes, ai-input=yes
消费方CF 原文：「We already see some of the most popular coding agents today – like Claude Code and OpenCode – send these accept headers」
套餐仅 Pro / Business / Enterprise（Beta 免费），Free 不可用
我们是否可用项目内证据显示我们当时在 CF Free（20260916_...md:24）⇒ 不可用。⚠️ 该证据为 2026-09-16，需你在 CF 后台确认是否已变更
裁决：仍不做

理由从「官网非文档站」升级为三条：① Free 套餐不可用；② 官网非文档站，消费方是编码 agent 而非搜索爬虫；③ 它会强制下发 ai-train=yes，而训练爬虫策略正是你尚未拍板的 O2——用它等于替你做了决定。归档意义：第三轮不应再被提起。
