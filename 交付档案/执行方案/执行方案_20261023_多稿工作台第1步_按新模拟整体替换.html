03替换范围

换（主路径）

  • 第 1 步整屏：页头、文件夹栏＋扫描条、四统计、两栏、整宽矩阵、页脚。
  • 交互：选文件夹即整批、自动读表出语言、按组拍板、同名稿比对、缺表补/跳、下一步直接进第 2 步。
  • 引导：首登 4 步＋页头「?」＋区块小「?」＋空态/异常态。
  • 文案：全部走键，设计说明句清零。

留（一个能力都不删）

  • 「更多」→「逐稿手动导入…」回老界面；老界面顶部能回来。
  • 旧批量导入弹窗：主路径不再调用，老界面仍可用。
  • 系统对话框、粘贴路径、手动加稿、清除本批、忘掉记忆。
  • 表格格式说明、示例表下载、错误原因、Smart Review 可见性。

04交互逻辑：每份稿一个状态

状态触发界面下一步
stale加入批次、未扫描灰点 + 待扫描扫描条
scanning扫描中转圈 + 进度等
prepared扫描完成绿点进入表的判定
needs-choice冲突 / 同名不同内容琥珀点 + 要你拍板选一个
needs-table没有候选表红点 + 没有表补表 / 先不做
reading正在读表读表中…等
ready表已解析绿点 + 语言数可下一步
read-error读表失败红点 + 原因重试 / 补 / 跳
excluded用户点先不做灰掉 + 可撤销撤销
dup-collapsed同名且指纹相同按 1 份算（可分开）恢复两份
下一步可用条件（缺一不可）

所有未排除的稿都扫描完成 → 都有已读表（语言已知） → 没有待拍板 / 缺表 / 读表失败。不满足就点名差哪几件，不做"点了没反应"。

1

选文件夹之后自动跑

列文件夹 → 自动填批（≤12） → 算归属 → 人手覆盖 > 记忆 > 自动 → 末尾"一表一稿"去重 → 并发 2 读表 → 矩阵逐行点亮。读一张亮一行，不整屏等。

2

拍板一条冲突

右栏只留一句结论＋证据折叠；候选卡显示 sheet 数、语言列、行数；默认"这一组 N 份稿都用这套"，另有"只这一份"。选完立刻读表、变绿、跳到下一条，toast 说清影响几份稿几个格。

3

同名稿：不静默少做一稿

指纹相同 → 折叠成一份，显示"2 份内容相同，按 1 份算"，旁边就是「分开做」；指纹不同 → 冲突卡，两份都做 / 只留一份。没扫描 → 先扫描再比对，不猜。

4

扫描设计稿：手动一键

选文件夹会自动列文件，但深度扫描要开 Photoshop，可能几十秒到几分钟。所以不自动开始：扫描条常驻"还有 9 个稿没扫描"，点一下开始，显示进度与 PS 未连接原因，扫完消失。

05数据层：不碰内核

新增stage-table-loader.ts

读表 + 解析 + 并发 2 + epoch/token 取消。只读被选中的表，不读 orphans；单张 5 MB；失败单行报原因，不拖整屏。

新增stage-rows.ts

同名分组（指纹相同/不同/未知）、悬置选择去重、"能不能继续"判定。纯函数，可单测。

改ParsedCsv.sheetNames?

xlsx 分支顺手填 sheet 名（现有 table-file.ts:61-65 已经有列表），用来对比"两套表结构不一样"。不影响 CSV。

守归属内核不动

sku-attribution.ts 的判定与单测一字不改；冲突仍由内核判，界面只负责把"为什么"说清楚。

手测 12 条（测试站，登录态）

  1. 选 12 稿的文件夹 → 不用点"加入本批"，统计直接有数；
  2. 矩阵先骨架后逐行点亮；读表失败那行有原因和重试；
  3. 冲突行有结构摘要；选"这一组都用" → 两份稿同时变绿；
  4. 同名指纹相同 → 按 1 份算，点"分开"能恢复；
  5. 同名不同 → 冲突卡两个选项都能走通；
  6. 没表的稿：先不做 → 统计/矩阵同步减，撤销能回来；
  7. 扫描条：未扫出现、有进度、PS 没开有原因、扫完消失；
  8. 下一步：有未定/未读/未扫被拦并点名；全绿后直接进第 2 步，不弹旧框；
  9. 清 localStorage 冷启动 → 4 步引导出现；刷新不再弹；页头「?」能重看；
  10. 换文件夹：批非空先确认；换完不串台；
  11. 375px：单栏、引导底部卡片、不遮目标；
  12. 老入口能回老界面，回来选择还在。

负控（防自欺）

  • 去掉读表调用 → 矩阵必须为空、单测失败；
  • 去掉去重守卫 → "两稿一表"单测失败；
  • 主路径再接旧弹窗 → smoke 必须报红；
  • 引导不看 seen 标记 → 第二次必须不弹。

09与模拟的 3 处差异 + 待拍板

#模拟里方案里为什么
1有表无稿的卡给「借用 Amazon 的 JP 表」改成「去补表」+「这稿先不做」违反内核"不跨交付物借表"，字会配到图外
2同名相同稿静默合并折叠显示 + 「分开做」可恢复不静默少做一稿，保留用户控制
3没有"扫描设计稿"这一步文件夹栏下加扫描状态条执行门禁要求全扫，现状新壳没有入口会死锁

要您拍板 ①：跨交付物借用

  • 推荐：删掉。守"不跨交付物借表"，缺表就补表或先不做。
  • 另一条：允许"显式借用 + 一直标借用"，要改内核与合同，风险高。

要您拍板 ②：扫描怎么开始

  • 推荐：手动一键。PS 可能没开，自动启动会变成重操作。
  • 另一条：选完文件夹自动开始，进度条常驻。

第三件是施工本身：按 P0→P1→P2 做，先测试站，验收后再谈生产。
