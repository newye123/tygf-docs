## 2 四路开源调查（子 Agent 产出，主 Agent 逐条复验）

### 2.1 折行算法（A 路）——**维持自研，只借数据表**

| 候选 | 硬数据 | 判定 |
|---|---|---|
| BudouX（Google） | 只给日文短语切分，**不给宽度、不给禁则** | 借鉴，不引 |
| linebreak / unicode-linebreak | UAX #14 断点流；禁则表最全（小書き仮名/ー/括号），但**数据停在 Unicode 13** | 借表 |
| `Intl.Segmenter` | 泰文/日文词典分词可用，但**结果随 ICU 版本漂移**（本机 ICU 78.2） | 谨慎，须固化结果 |
| `text-wrap: balance/pretty` | 需浏览器排版引擎，**离线写回 PSD 场景不可用** | 出局 |

**结论**：s5 真正值钱的是「整数定点宽度 + 固定行数 DP + tier/fail 分级」，开源件零覆盖；能省的只有禁则字符表与泰文分词（约 1/3 代码）。**不引入库**，补两张表即可。

### 2.2 批量工作台（B 路）——**不引状态机，引两个 UI 库**

- TanStack Query 的 `scope.id` 已实现「同 scope 串行排队」（MIT，活跃），但**只给队列、不给 checkpoint**。
- XState 值得抄的只有两点：状态显式枚举、持久化只存可序列化快照 + 版本号。**为一条线性链引状态机库不划算**。
- **tus 协议给的纪律最有价值**：续跑前先问真实 offset，对不上返回 409，绝不覆盖 ⇒ 映射为「续跑前重算每格真实状态，不信任 localStorage 里的旧百分比」。
- 该引：`react-dropzone`（`getInputProps()` 直接接活死控件）、`TanStack Table`（headless，单元格文案可控，不会塞假 0%）。
- 该砍：Uppy（上传器语义）、dnd-kit（官方明说不能从桌面拖入）、Glide（9 个月无提交）。
- **铁律补一条**：失败即停 ≠ 丢弃已完成；已完成项必须落盘成 checkpoint。

### 2.4 GEO 可发现性与边缘缓存（D 路）——**能安全做，但只能缓存匿名 HTML**

- `Vary: rsc, next-router-state-tree, …` 是 **App Router 13.0 起默认加的**，不是动态页标志；`Cache-Control: no-store` 来自**动态渲染**（`headers()`/`cookies()`/`searchParams`/`connection()`）。
- Cloudflare Cache Rules 的 **Edge TTL → "Ignore cache-control header and use this TTL"**（API `edge_ttl.mode="override_origin"`）**能覆盖 `no-store`**（官方文档原句）。
- 但**只能缓存「无 `rsc`、无 `next-router-prefetch`」的 HTML**；RSC 请求必须 bypass，否则 HTML 与 RSC 会串内容。
- 终局是营销页 ISR（`revalidate=300` + `revalidatePath` + CF purge），不是永久硬压 `no-store`。
- `llms.txt` 无实证收益（137K 域实测 97% 零请求）；内链出边才是最高性价比。
