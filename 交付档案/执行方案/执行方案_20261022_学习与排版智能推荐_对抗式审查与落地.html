02这对你意味着什么

现在就能少做的

  • 按原稿字号自动切三档，给出每档的字重、字距、行距，不用一格格手填。
  • 在已经选好的字体族里挑粗细分级，不跨族乱替换。
  • 下一次遇到字号结构相似的稿，沿用你上次改过的值。
  • 每一档都能看到「会影响多少层」和「为什么这样建议」。

现在还不能少做的

  • 跨设备记住你的偏好——那要云端个人学习，必须先把隐私口径改对。
  • 按模板/品牌复用——模板身份现在是文件哈希，同一稿另存一次就失效。
  • 自动应用——Spec 的硬不变量是「只换行，不改字号/字距/行距」，推荐只能由你点。
  • 推荐原稿字体本身——KO/TH 原稿字体常不可解析，推了也落不了地。

03三条根因

学错了对象server.js:2963-2985 · typography-contract.ts:309-315

扫描器把原稿每一层的字体、字号、行距读上来，云端统计成「偏好画像」。这份画像回答「这份稿原来用了什么」，回答不了「你希望改成什么」。拿它训练推荐，推出来的是原稿复刻。

没有分档的地方typography-persistence.ts:13-34 · Thin_Executor.jsx:221

一个语言只存一份排版设置，执行时这份设置套到该语言的每一个图层。哪怕算出「标题该粗、正文该常规」，也没有字段可存、没有协议可发、执行器也不会分层用。

没有消费面rule-resolver.ts:16-21 · deploy/route.ts:22 · feature-flags.ts:36

规则解析器恒返回空建议；管理端「部署」只允许 shadow 模式；建议开关只在管理端概览里显示一次。三层加起来，等于「学到了，但没人用」。

06执行路线

Phase A0 · 网页侧最小版1–2 人日

用浏览器已有的原稿字号分布，算三档阈值，填现有的一份 profile（正文档的值）。不改助手、不动合同。

价值：少填几个格。局限：仍是一语言一个粗细，必须写在按钮旁，不能假装已经分档。

Phase A1 · 真正的分档3–5 人日

profile 增加 tierPolicy（三档阈值 + 每档脸/字距/行距）；信封加兄弟字段 tiers，不进 manifest/digest；执行器按图层字号选档。

字重只能从字体目录的 style 文本解析（没有数值 weight），解析不出就不推，绝不猜。

Phase B · 本机历史2–3 人日

只存语言、字号结构签名、三档实际值、回读结果；上限 50 条，不存正文/图层名/路径/文件名。

用结构相似度匹配，不用文件哈希；失败样本不参与推荐。

Phase C · 云端个人学习需 Owner 批准

新增 typography_tier_choice，只开 personal scope；只在成功执行 + 用户采用 + 回读通过后记 accepted。

硬前置：隐私文案与同意范围先改；LEARNING_AUTO_APPLY_ENABLED 永远 false；合同四层同步。

Phase D · 模板 / 品牌后置

先建不含正文/路径的结构指纹；layout 验证必须有人工/视觉确认，机器坐标测不出压没压到图。

公共推荐不在本轮范围。

07验收与硬边界

1
分档纯函数可复跑

同输入同输出；≥20 条断言；阈值等号边界有显式用例。证据不足（层 < 6 或不同字号 < 2）时按钮禁用并写明原因。

2
无分档时行为不变

旧 v1/v2 profile 照常读；信封无 tiers 时执行结果与 HEAD 逐字节一致。manifest 键集与 digest 不变。

3
同族无线索就不推

该字体族没有更粗/更细的脸时，明确说「没有可用字重」，不跨族替代、不猜脸名。

4
推荐永不自动应用

点「应用」只写 localStorage；未点执行不产生助手请求；执行前仍显示这次真正会用的值。

5
合同门全绿

npm run test:trust-chain 与 npm run test:batch-row-contract 均 rc=0，才允许上测试站。

6
隐私先改再开云端

Phase C 上线前，隐私文案与同意范围必须更新；未更新就不开启。用户要能有单独的关闭入口。

明确不做

不自动改 PSD；不把建议值当已应用值；不推荐原稿字体脸；不把排版证据塞进 manifest 或云端回执；不做跨用户公共推荐；不为了推荐去改结算与报价。

08边界与覆盖缺口

  • 样本量未知：本轮没有连数据库，无法判断 personal 门槛（≥5 任务、≥2 模板）今天有没有人能达到。
  • 批量入口未穷尽：只在 src/ 内 grep 了上传调用点，助手侧是否另有入口未查。
  • 环境值未读：测试站/生产的 LEARNING_* 需要服务器权限，本轮未探。
  • 字号单位未决：扫描器读 textItem.size.value 未显式转 pt，阈值可能受文档标尺单位影响。
  • 无真机验证：没跑 Photoshop，没点排版面板，也没有用真实原稿试分档。
