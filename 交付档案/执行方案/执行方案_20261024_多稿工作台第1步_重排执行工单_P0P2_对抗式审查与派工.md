## 2. P0 工单：表册纯函数（不动 UI）

新增 `src/lib/workbench/table-inventory.ts`（纯 TS，无 React）：

- 类型：`TableReadStage = 'listed'|'reading'|'ready'|'error'|'truncated'`、`TableRecord`（id=规范化路径、path/relPath/ext、langs、rows、sheets、stage、error?、usedBy[]、readAt）、`SourceMatrixCell`（draftPath、language、tableId|null、sourceLabel、coverage|null、status: 'ready'|'wait'|'bad'|'unread'|'unbound'|'noscan'|'na'、issues[]）
- 函数（全部纯函数＋单测）：
  - `normalizeTableId(path)`：大小写/斜杠规范化（Windows 路径）
  - `buildTableInventory(scan, choices, readStates, parsedMeta)`：从扫描结果＋绑定＋读状态派生 TableRecord[]；孤儿表（usedBy 空）照列；`tablesTruncated` 为真时清单尾部出一条"只列了前 N 张"的记录型说明（不许静默）
  - `deriveSourceMatrix(drafts, inventory, coverage)`：行=稿、列=全批语言并集（≤12，语言列判定沿用 `csv.ts` 现有逻辑，不改语义）；格状态机＝设计方案的 §3.2（一稿一表；na=本稿表无此语言；noscan=稿未扫；unbound=未配表；unread=表未读全文；ready/wait/bad 按覆盖率 95/80 阈值，**coverage 为 null 时一律 unread/noscan，不得给数字**）
  - `planTableReadQueue(inventory, opts)`：读表顺序（绑定表优先→未用表→异常表靠后）＋上限 12＋并发 2 的切片
- 单测 `tests/unit/table-inventory.test.ts`：路径规范化（大小写/反斜杠）、共用表只一条记录、孤儿表、truncated 说明行、语言并集、格状态机七态各至少 1 例、覆盖率 null 不判色、队列上限/优先级。夹具写在测试文件内（小对象字面量），不建新 fixture 目录
- **出口**：`npx tsc --noEmit` 0 错＋`npx vitest run tests/unit/table-inventory.test.ts` 全绿；不改任何既有文件
