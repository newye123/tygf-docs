**Spec:** `product-specs/typography-fit.md`（权威）、`changes/active/20260917-auto-wrap.md`（已批准范围）、本文档 §0（取证事实）。

  行数搜索 `N = lo..min(lo+1,3)` **首个可行即最优**（不要二分——二分会跳过可行的小 N）；`dpFixedN` 为 `O(N·n²)` 分段 DP（n=断点数，拉丁≈12、CJK/泰≤80）；**代价函数必须逐行可加**（可行性 → Σ张力`slackU²/1000` → 禁则 → 断点等级 → 寡行），**行间方差不得进 DP 目标**（非可加，且会把短行推向超宽）；超宽与禁则是硬约束（over>0 即该 N 不可行）；末行免张力罚；寡行 <2 CJK 簇 / <3 拉丁字符罚 5000；预算 `budgetU = floor(墨迹px*1000/fontSizePt)*0.985`，非左对齐再 ×0.98；宽度表由**助手侧**按 `(fontPostScript, style, sizePt)` 上传并带 sha256（Web 无用户本机字体，不得自算）；**Web = 唯一求解与冻结权威，助手执行前只校验不改判**，不符则落 `typography_mismatch` 事实 + 进例外清单等人工，**不自动重排、不自动重跑**（要重排走显式重报价，计费仍不变）。取消 `MAX_EM_CHARS=4000` 静默截断（`:1364`），截断即 `fail`。
- **P5 版式体检预览页**：不写盘，逐对象显示行数/最宽行占比/超界标记 + 画板裁剪缩略图，用户选「保持原样 / 换行 / 我自己改」。这是"自动改动"上线前的**唯一安全形态**。
