## 卡一 · Google Search Console（唯一现在就有数据的地方）

1. 打开 `https://search.google.com/search-console/about` → 用 9-17 那次建资产的 Google 账号登录（域名资产是 `sc-domain:tuyigf.com`，靠 DNS 里那条 TXT 认的，**那条 TXT 记录不要删**）。
2. 看三格，就三格：
   - 左栏「**效果**」→「搜索性能」：看 **展示次数**、**点击次数**、**平均位置**。10-14 那次实拍是「效果 5 次点击」。
   - 左栏「**索**引」→「页面」：看 **已编入索引 / 未编入索引** 两个数。10-14 实拍是 3 已编入 / 4 未编入。
   - 左栏「**索引**」→「**网站点地图**」：确认 `https://tuyigf.com/sitemap.xml` 仍显示成功、已发现页数＝**8**（我今天现读 sitemap 就是 8 条 `<url>`）。
3. **这一格能说明什么**：Google 愿不愿意收录、给了多少次展示。
4. **不能推成什么**：① "平均位置"**不是**位次——Google 官方定义它是"你站点页面的最高位置的平均"，官方自己建议"更关注展示与点击，而不是位置"；② 表里没列出的词≠没人搜：Google 定义的两三个月只有几十人搜的查询**在表格和 API 里一律不列**（加任何过滤器就整体被忽略），Ahrefs 用 146,741 个站实测 **46.08% 的点击来自这些隐藏词**；③ 这里**完全没有** ChatGPT／豆包／Kimi 的引用信息。
5. 另有一格叫「**生成式 AI 性能报告**」（2026-06-03 宣布、2026-08-31 铺到全球所有站点）：**只有展示次数**，没有点击、没有查询词、没有位次，而且**API 里拿不到**（`searchconsole` 的 discovery 文档 rev 20260805 里 `generative`／`ai mode`／`datasource` 全部 0 命中）。**基线只能从 2026-08-20 之后起算**（Google 自认 08-13 起该报表因日志 bug 系统性偏低）。

## 卡四 · Cloudflare（这一格是本轮新找到的，免费、不引脚本）

1. 打开 `https://dash.cloudflare.com/` → 选 `tuyigf.com` 这个 zone → 左栏 **AI Crawl Control**（旧名 Crawler Traffic Management；各套餐含 Free 都可用、零配置）。
2. 看 **Crawlers** 表：每一行是一个爬虫（GPTBot、ClaudeBot、PerplexityBot、Google-Extended…），列里有 **Requests（允许数与失败数，带趋势）** 和 **Robots.txt violations**。
3. 这一格能说明什么：**这些 AI 爬虫到底来过没有、来过几次、有没有被拦**。这是我们目前唯一能看到的"AI 侧真实取用"读数——我们自己的 nginx 日志只记**进到源站**的那些，被边缘挡掉的那部分只有这里看得见。
4. 不能推成什么：Cloudflare 官方自己写明"失败请求可能来自任意规则或响应错误，不只是 AI Crawl Control 的 block"⇒ **GPTBot 来过 ≠ 我们被引用**。
5. 顺手两格：**Analytics → 域名**（cookieless 统计的读数，如果我们没开就仍是空）；**自适应分析（Adaptive Analytics）**保留期自 2026-10 起每套餐至少 30 天，且**同一批数据可以用 GraphQL Analytics API 拉**——这条让"每周自己拉一份 JSON 存下来"零成本可行，也是 §执行方案 C4 之外唯一不需要 OAuth 的自动化路径。
