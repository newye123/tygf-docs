## 02 执行序

1. 第一笔：`git -C worktrees/production cat-file blob main:public/llms-full.txt` 取权威字节 → 落成 develop 的 `public/llms-full.txt` → 用 `git hash-object` 与 production 树该文件的 blob 对比一致 → 提交（纯加法，1 文件）。
2. 第二笔：四处文本精度化（`llms.txt` zh 要点行＋英文 Key facts 行；`llms-full.txt` `:18`＋`:64`）＋ `llms.txt` 加反分类句（zh/en）→ 跑 `tmp/scan-copy.mjs` 机扫两文件 → 提交（含 L2 登记）。**不部署**。
3. 操卡：`交付档案/执行方案/操卡_20261017_站外四道人工闸_手点清单.md`——每道口写清"打开哪个地址、点哪个钮、会遇到什么平台限制（CSDN 三级标签限制、头条草稿箱三份同名取舍、抖音本人短信、搜狐号需绑手机）、发布后 30 秒怎么自查"。md＋HTML。
4. 记账：TASK_LOG 置顶、ledger 追加＋投影、飞书人话版；本轮无代码语义改动 ⇒ 不跑合同类 smoke，只跑与文本相关的检查并如实记 NOT RUN 项。
