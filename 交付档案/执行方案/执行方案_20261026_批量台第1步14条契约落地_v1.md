## 2. 设计决定（先钉死，免施工时自由发挥）

**D1 剔除落在「稿×语言」这一层，不落表。** 新增会话内状态 `slotExclusions: Record<masterPath, string[]>`（值是这门稿被点掉的语言码）。不写进 `MultiPsdEntry`、不写进归组内核入参、不进 `input.excluded`。

**D2 只有一个减法点。** 纯函数 `applySlotExclusions(languages, excluded)` 定义在新文件 `src/lib/workbench/slot-scope.ts`，`multiDraftLanguages` 与「当前稿有效语言」都调它。任何地方要问「这批这一稿真做哪几门」，只许调它，不许自己 filter——这是防"两套账"的硬规定。

**D3 门跟份数同源。** `readiness`/`derived` 的 `selectedLanguages` 从 `targetLanguages` 改为 `effectiveTargetLanguages`（＝当前稿语言减去当前稿剔除）。这样点掉一格，`allLanguagesReviewed` 不再等那门，门不会永久关不上；复原后重新等它。

**D4 撤销是「按稿」不是「全局」。** 「全选回来」只清当前那一组（当前稿）的剔除；顶栏再给一个「全部复原」清全局。理由：Owner 的痛点是误点后要能一次回来，但跨稿批量复原会掩盖别稿的真问题。

**D5 本轮不动计费公式。** `computeRowLanguageStandardUnits`（`src/lib/billing/batch-v3.ts:56-83`）与 `computeBatchLanguageBilling` 一字不改；剔除靠「语言集合变小」自然生效（服务端 `:157/:189` 按 payload 语言集算）。因此**不触发**「合同变更纪律」的四层同改，但 `test:batch-row-contract` 与 `test:trust-chain` 必须当回归跑绿（scope 相邻）。若跑红，本方案停在此处上报，不硬改公式。

**D6 本轮不做的契约（如实列出，不假装全做完）：** 契约 4（空态文案）、5（扫描四阶段进度条）、6（「扫描并自动配对」一键）、12（「一组表 vs 今天的做法」对照）。理由：四条都是增量 UI，不解决"数不对"；而 1/2/3/7/8/9/10/11/13/14 才决定第 1 步的账是否唯一。做完的 10 条要能用门证明，比铺 14 条皮更重要。

```ts
// src/lib/workbench/slot-scope.ts
export type SlotExclusions = Record<string, string[]>

/** 这批这一稿真要做哪几门——唯一取数口。别处不许自己 filter。 */
export function applySlotExclusions(languages: string[], excluded: string[] | undefined): string[] {
  if (!excluded || excluded.length === 0) return languages
  const drop = new Set(excluded)
  return languages.filter((language) => !drop.has(language))
}

export function toggleSlotExclusion(
  current: SlotExclusions,
  masterPath: string,
  language: string,
  keep: boolean,
): SlotExclusions {
  const previous = current[masterPath] ?? []
  const next = keep ? previous.filter((language) => language !==) : Array.from(new Set([...previous, language]))
  return next.length === 0 ? omitDraft(current, masterPath) : { ...current, [masterPath]: next }
}

export function restoreDraft(current: SlotExclusions, masterPath: string): SlotExclusions {
  return omitDraft(current, masterPath)
}

export function countExcludedSlots(excluded: SlotExclusions): number {
  return Object.values(excluded).reduce((sum, langs) => sum + langs.length, 0)
}

function omitDraft(current: SlotExclusions, masterPath: string): SlotExclusions {
  const { [masterPath]: _drop, ...rest } = current
  return rest
}
```
