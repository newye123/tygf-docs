## §03 GitHub / 业界调研（三路并行回收）

### 3.1 能直接复用的：0 件；能抄形状的：三件

| 件 | license / 星数 | 它做到哪一步 | 我们的用法 |
|---|---|---|---|
| EmilDohne/**PhotoshopAPI** | BSD-3（商用友好）/ 384★ | run 级 + range 级 `set_tracking(int32)`、`set_leading(double)`、`set_faux_bold`，且有 proxy 读回单测 | **当字段名/单位/写入顺序的权威参照**；无 Node 绑定，不装进产品 |
| Agamnentzar/**ag-psd** | MIT / 730★ | 能读写 `TySh/engineData` 的 Tracking/Leading/FauxBold，但作者自陈实现不完整 | 只做**离线取证/读回校验**（我们普查已在用）；**不能当写回主链路** |
| ogkalu2/**comic-translate** | Apache-2.0 / 2975★ | 用 PhotoshopAPI 导 PSD，`_resolve_postscript_font_and_faux`（读 nameID 6 拿 PostScript 名 + faux 判定） | **抄这段解析形状**；它同一文件里的 `_set_if_exists` 静默跳过、失败就拼 `-Bold/-Italic` 造不存在的字体名＝我们红线的反面教材 |

已证实的外部坑（原话在件里，不是我推的）：
- ag-psd 改了文字层**不重绘位图** ⇒ 打开必弹"更新文字图层"（README:26、:479-481）；**竖排**文字层可能造出连 PS 都打不开的文件（README:485）；`FontSet` 是 `// TODO`（src/text.ts:170-172）；issue #251 里它建的文字层 bounds 0×0、PS 里看不见；issue #55 记"缺字体时 PS 弹的是替换字体对话框，把流程打断"。
- PhotoshopAPI 文档：改从盘上读来的 PSD 文字必须先 `invalidate_text_cache()`；`start/end` 是 **UTF-16 code unit** 下标（中英混排/emoji 会错位）；写出的文件**不含有效 merged image**。
- psd-tools（MIT/1479★）README 明列不支持"Editing of texts in type layers"；`photopea` 主仓库**无 LICENSE 且无源码**（README 自陈"not fully open-source"）；`Typr.js`（MIT）可用来在网页侧量字宽。
- 漫画/图像翻译同类（manga-image-translator GPL-3、BallonsTranslator GPL-3）**全部绕开 Photoshop 自绘字形**，对我们不适用（我们必须在真 PS 里落字层才有交付件与取证）；而且**它们都没有"按语言各配一套字体"这件事**——这是我们的差异点，不是我们的缺口。

### 3.2 字体枚举：npm 现成件是坑，正解是我们已有的 fontkit 路线

- **`font-list@2.1.0`（MIT）不能用来喂 PS**：Windows 分支取的是 WPF `typeface.FontFamily.Source`（**族名**，不是 PostScript 名），且每族 `Select-Object -First 1`（拿不到 Bold/Italic 脸），还优先返回 zh-cn 本地化名（"微软雅黑"）。本机旁证：WPF `SystemFontFamilies` 实测 **551 族**。
- **`font-manager`（MIT）方向对**（DirectWrite `DWRITE_INFORMATIONAL_STRING_POSTSCRIPT_NAME`），但 2019 停更 + 要 node-gyp 编 `nan`，Node 24 能否编过**未核实**。
- **正解**：助手扫 `%WINDIR%\Fonts` + `%LOCALAPPDATA%\Microsoft\Windows\Fonts`，用 **fontkit 读 name 表 nameID 6**，每行返回 `family / style / postscriptName` **三列**（`.ttc/.otc` 必须走 `font.fonts[]`，否则 postscriptName 直接 undefined——本机已实证 `msyh.ttc` 有两张脸）。依据：OpenType name 表规范（nameID 1/2 是四脸族组、16/17 才是排印族，"族名＋样式名"**拼不出** PS 名）。
- **浏览器 `queryLocalFonts()`（Local Font Access）**：Chrome/Edge 103 桌面独占，Firefox/Safari 不支持，需 HTTPS + 用户手势 + `local-fonts` 权限。不作权威源（Adobe Fonts 不进浏览器、口径与 PS 不同），**只可当助手不在线时的降级**。`document.fonts.check()` 不能枚举（FontFaceSet 只装文档自己的 FontFace）。

### 3.3 产品形态（业界怎么把它做成用户用得上的东西）

- **档位而不是数字**：Android 系统 fonts.xml 按文种绑 149 条 family，只给 `elegant/compact` 两档疏密，从不暴露 leading 数字；Google Slides 只给 `NONE / TEXT_AUTOFIT / SHAPE_AUTOFIT` 三档且 `fontScale` 明确只读；InDesign 缩放后字号显示成 `20 pt (40)`（数字是结果不是输入）。
- **翻译重排的头部竞品压根没做字体定制**：Canva 翻译设置只有三条勾选（默认"减小字体大小以适应页面"），一次一种语言、≤2000 字；DeepL 文档翻译只承诺"保持原有格式与版面"。**我们现在 4 个输入框比这两家都重。**
- **"按语言换字体"最成熟的键名形态**：Firefox 偏好 `font.name.serif.x-western` 这类"先选语言组、再填一个族"；CSS `:lang()` 挂不同 `font-family`；ASS 一个 Style 一条 `Fontname`。⇒ 印证"每语言 1 个脸 + 1 个档位"，不是"每语言 4 个框"。
- 预设生命周期可抄 VS Code（Export Profile → `.code-profile`/Gist）与 Figma（按 Mode 切整套 token）；"复制自其他语言"这个动词业界没有，业界叫**套用预设**。

## §05 建议路径（P0 已闭，下面是能直接开工的形状）

**助手侧下一班车（六件，字段白名单今天定死了）**
1. `GET /v1.5/fonts` ⇒ 三列 `family/style/postscriptName`（fontkit 读 nameID 6，`.ttc` 走 `fonts[]`），Origin 白名单、无票只读、本机缓存 + `?refresh=1`。
2. `prepare` 收 `typographyProfileByLanguage`，白名单校验：`facePostScriptName`（必填或整语言 null）/ `tracking`（−1000…9999，1/1000 em）/ `leadingMode`（`follow` | `fixed` | `autoPercent`）/ `fauxBold`（默认 false，**不许自动开**）。
3. runner 把 profile 写进 **envelope 顶层旁路字段**（不进 `executionManifestDigest`，与 10-14 方案一致）。
4. `Thin_Executor.jsx` 写循环里按 **固定顺序**：`contents` → `font=PS名` → （要行距就）`useAutoLeading=false` → `leading`/`autoLeadingAmount` → `tracking`；**每项 try + 读回**。
5. 失败码：`FONT_UNAVAILABLE`（本机没这名字）、`FONT_FALLBACK_APPLIED`（读回≠所设）、`TYPOGRAPHY_INVALID`、`LEADING_NOT_APPLIED`。
6. 版本 bump 四件照发版纪律；装完必须核 `/ping` 的 5 个脚本 sha8（#74 教训）。

**顺手能收的一个大红利（#75）**：今天验证出闭式 **h = (n−1)×leading + h₁**（12pt 单行 h₁=13 ⇒ 自动 175%→55、写 60→133、amount 300→85、写 24→61、写 50 三行 113/四行 163，**六个独立点逐位对上**），而 `useAutoLeading` 与 `autoLeadingAmount` 在 PS 22 上实测可读可写 ⇒ 重开验证器终于能算出**真实渲染行数**，不再拿 `size×1.2` 猜（#75 的"30/31 退化成 0"根因就在这）。

**面板改造（属用户可见变更，按 Product Drift Guard 要开 L2）**
- 字体：族 → 脸二级选择器，存 `postscriptName`，列表按"是否含该语言字形"过滤（`hasGlyphForCodePoint` 只查 cmap，**不许用宽度/`layout()` 反推覆盖**——缺字时它静默给 `.notdef`、advanceWidth 1536）。
- 行距：撤数字框，改「跟随原图层 / 紧凑 / 标准 / 宽松」四档，背后落 `autoLeadingAmount` 百分数；数字版收进"高级"折叠。
- 字距：滑块 + 当前值，单位标 1/1000 em（实测口径）。
- 撤"保存到本机"按钮：即时生效；本机与账号各存一份并写明来源（A3 的修法就在这）。
- 告知文案两态（抄 Affinity/Canva 的 `?`/`!` 形状）：「这台电脑没装这个字体」／「字体在，但这些字它没有」，各给一个可点出口，**不写"请补"**。
