## 02 方案 A：投影前对账闸（P0 落地）

**三值比对（每格）**：台账值 `L` / 飞书现值 `F` / 上次投影快照 `P`。

- `L = F` → 无碍（该行全等则整行跳过，不发写命令）；
- `L ≠ F` 且 `F = P` → 正常待投影（放行）；
- `L ≠ F` 且 `L = P` → **人手改**（拦下整行不投影，报告点名）；
- 两边都动 → **冲突**（拦下）；
- 无快照且 `L ≠ F` → 保守拦下（`no-snapshot`）；
- `--force` → 显式全量覆盖（绕过闸；用于确认后强推）。

**改动面**：

- `scripts/sync-task-ledger.mjs`：新增 `--state` / `--state-out` / `--force`；整行覆盖改为「跳过全等行、拦下 held 行、其余照写」；计划命令加 `[ok]/[fail]` 标记；stderr 摘要增 `skip/held` 明细。
- `scripts/sync-task-ledger.sh`：接 `STATE=tmp/readback/last-projected.ndjson`（pending 后缀写入、成功才提升）；`fail>0` → 不提升 + exit 1；`held>0` → 汇报 + exit 1（调用方 `|| true`，不阻塞交付）；`--dry-run` 不写任何状态。
- `scripts/test-sync-reconcile.sh`（新增夹具）：6 例——全等跳过 / 待投影放行 / 手改拦下 / 冲突拦下 / 无快照保守拦 / `--force` 全量。
- 「Owner 批注」列语义不变：永不触碰。

**验收**：夹具 6/6；播种快照后真表空跑（预期 update=0）；`control-plane.sh` 复跑全绿；重复行/漂移 0。
