# 字体排版定制：这回真的能点了（测试站已部署，等您开闸验收）

**解决什么问题**

您上次问「开了灰度怎么没地方操作」，查下来是三层问题叠一起：功能本体一直没做、只部署了一个「建设中」占位条；总开关在运营台上根本开不了（是个死开关）；白名单也还是空的。这轮我按对抗式审查后的方案把能诚实交付的部分做完了：运营台字体排版定制卡上有了真能点的「开启/关闭总开关」按钮；工作台 PS 步骤的占位条换成了一个真的排版面板（选字体、调字距、行距，按语言分开设置，带预览）；面板会老实告诉您「现在执行还不会应用这个定制，要等助手升级」。

**还有什么问题**

PS 写回（真正把您的字体写进 Photoshop）这步还没做——它依赖本地助手发新版，而且按方案要先在真机 PS 上跑半天脚本验证语义，这两件都得您配合，排下一班车。部署时踩了两个小坑（脚本换行符、残留目录），已登记问题册，不影响本次结果。另外 develop 工作树里还有别的线留下的 12 个未提交文件，我没动它们。

**接下来怎么办**

您花两分钟验收：打开运营台 → 找到「字体排版定制」卡 → 点「开启总开关」→ 名单里填上您自己的用户 ID 保存 → 打开工作台走到 PS 那一步 → 展开「排版定制（内测预览）」点着玩一下。觉得面板设计没问题，我们就排下一班车做写回；觉得不对味，现在改最便宜。
