# GitHub 与全网看了一圈：结论是"借它的规范，不装它的代码"

2026-10-18 上午 · GEO 与对外文案线 · 第十四轮

## 一、你让我看的这件事，我先说结论

开源和付费市场上确实有一整套 GEO／AEO 工具，我挑了 8 个仓库逐个查了星数、许可、最近推送和未关闭 issue，也扫了中文商业侧十来个监测服务。结论一句：**它们能量的是"页面准备好了没"，量不到我们真正的病——"在不在场"。** 按它们公开的评分规范给我们线上站打的分是 87.4/100（在它的档位里算 Excellent），而同一时刻百度 site:tuyigf.com 是 0 条收录、品牌词前排 20 条 0 条本站。所以装任何一款工具都不会改变今天的处境。

## 二、候选里我砍掉和排除的，理由摆明

- 最值得借的是 geo-optimizer-skill（1114 星、MIT、今天还在推）。但**我没有装它也没有跑它**。原因：跑它＝在你机器上执行第三方代码，它会抓我们全站，还可能在你用户目录写 sqlite。它的评分规范是公开的，我直接把规范读下来，用自己的脚本实现——信息一样，风险归零。另外它 README 里带着自家付费站 geoready.dev 的对照表和引流参数，所以**它给的分数是厂商自定义口径，不能当成我们的排名**，这条我也写死了。
- getcito（491 星）**许可不明（NOASSERTION）**、indexplease（6 星）**根本没有 LICENSE** ⇒ 直接排除。只看星数就引进来，等于把身份不明的授权写进产品链路。
- elmo 要自托管一个服务，而且挂着 131 个未关闭 issue ⇒ 否决。eGEOagents 要各家大模型 key，我们没有 ⇒ 暂不看。
- OpenGSC（45 星，自托管 Search Console 看板）是唯一对上我们真缺口的一个，但它需要 GSC 授权＋一个常驻服务＋**新增一类上云数据**。上云数据一多，隐私政策和第三方处理方清单就得同步改，那是对外承诺面的变更 ⇒ 我不擅自动，列给你拍。
- 百度推送那两个旧仓（2023／2022 就没动了）不用借壳：百度主动推送就是一个 HTTP POST 加一个 token，我三十行自写更可控。
- 中文商业监测（软文街、GEOBase、AIDSO 爱搜、ImpetaAI、Profound、Daydrm、GoodieAI，以及 Ahrefs、Semrush 的 AI 模块）都是"仪表盘＋订阅"，文章里出现 $19/月、$95/月起的价都是厂商自述、我没核。你定的口径是不投放走轻资产，而且这类工具要我们的品牌词表和内容权限 ⇒ 本轮不选，但它们的**指标口径**值得抄（下一节）。

## 三、只从它们那儿抄三件度量口径

一，别只报"有没有提到"，要报**提及率／Top3 推荐率／首位推荐率**。二，要报**信源溯源**，也就是 AI 到底引用了哪些网址。三，**同一个问题要采样 5 次取最频结果**——这点直接说明我们昨天那批 3/3 是单发读数，形状不够硬，我今天就把复测工具升级成这个形状。有句话值得挂在心上：收录是入场券，引用才是座位号。

## 四、用自己的脚本给我们线上站打了一次分（今天 11:1x 实跑）

分数：83/95，归一 87.4。真不合格 7 条，其中三条最值得看：首页**没有任何 dateModified／datePublished**（内容新旧无法证明）；首页**一条站外引用链接都没有**；全站**没有 Article 结构化标注**——因为根本没有内容页可标，这跟昨天立的"缺教程型承接页"是同一件事的两面。另外首页没有 RSS、feed.xml 是 404、没有 ai.txt，主体信息为空（我们没有公司主体是既成事实，我不伪造）。

比分数更该说的是**我自己错了两处并当场纠掉**：第一次判"首页没有数字"，其实线上有"12 语种""48 个"，是我的正则不兼容空格；第二次判"页面没有联系方式"，其实线上 JSON-LD 里就有 contactPoint（邮箱 tuyi@tuyigf.com，支持中英双语），正文还有"联系作者／微信／小红书"，我只查了 mailto 链接。两处都修了脚本重跑。有 5 项我没评的就标"未评"，不冒充 0 分。

## 五、"更进一步的 HTML"给你做成了能用的作业面

不是静态报告，是一个可以点的作业面：六个标签页（选型评估／缺口映射／体检读数／对抗式审查／作业面／待拍与红线），9 项任务可以勾选，进度条实时动，勾选只存你这台机器的浏览器、不上传，可以一键导出 JSON，四条命令能一键复制。

我没有只看代码就说"它能跑"：用浏览器真打开点了一遍——9 项渲染正常、切到作业面标签显示 9 项、勾了三项后刷新页面仍在、进度 22.2%、导出按钮不报错、控制台零错误。中间还有一次我自己的测试手法错：连点三次只落一次，原因是我拿的是已被替换的旧节点，脱离文档后点击不再生效；改成每次点击前重新取节点就复现正确了。

## 七、要你拍的还是那四格

第一，教程型承接页建不建（建的话首页必须给它分类入口，否则是新孤儿页）。第二，百度站长 token 给我，我自写推送脚本。第三，GSC／Bing 的回看节拍归谁——10-14 实拍一次后到今天没有第二次读数，这不是缺工具，是缺节拍。第四，llms.txt 我建议**不再加码**：按这套规范它只值 6 分且自注"Google 搜索忽略"，我们已经拿满 6 分。这条是第三方口径，Google 官方原文我这台机器连不上（curl http=000），所以标未核实。

另外提醒一条出包敞口：IndexNow 的密钥文件在 develop 树上不存在、只在 main 上，**从 develop 出包会让那条收录通知链当场断**（账本 981 行的既有记录）。你要推测试站或生产前得有人盯这行。
