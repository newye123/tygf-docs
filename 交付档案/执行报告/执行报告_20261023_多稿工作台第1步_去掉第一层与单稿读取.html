01改了什么

删第一层少一步

批量页不再显示多选卡；进入「准备素材」直接是第二层。卡头与单稿共用：左边「准备素材」，右边「排版定制」；没有文件夹时显示单稿样式的入口卡：路径输入、选择设计稿、读取文件夹、只读预扫描。

卡头终于一致同一块

原来卡头藏在「经典逐稿」分支里，批量新壳绕过了它，所以右上「排版定制」消失。现在卡头提到批量/单稿共用层，空态和数据态都有；两个重复的 h1 也删了。

文件夹读取收到父层状态可见

loadStageFolder 统一管理 loading/error，带 request token 防串台；入口卡与数据态都能看到“正在读取/读不了”。

每稿手动选表补出口

「选择译文表…」列出当前文件夹里的表，可搜索、显示已给谁用；选中后按单稿同一套规则读表。自动配对只做建议，缺表/认不出 SKU 不再无路可走。

一表一稿仍守住不放松

手动选择优先级最高；同 SKU＋同交付物内仍拦同一张表；SKU 认不出时没有身份依据，不静默撤掉用户的选择。

单稿原生文件框居中原生

单稿「选择文件…」恢复 Windows 原生文件框（PSD/PSB），可直接选文件；owner 锚点改为应用窗口中心，不再跟着按钮跑右下。

批量恢复选文件夹功能优先

图三的 OpenFileDialog 只能选 PSD/PSB 文件，不能选文件夹；“选文件再取父目录”已撤回。批量入口恢复 Windows 原生 FolderBrowserDialog，直接选文件夹本身；图四老外观要换成图三现代外观，需助手 3.7.25 的现代文件夹接口。
