# 单稿选择文件已改回原生文件框

## 结论

按您说的调整回来了：单稿页的「选择文件…」现在还是原来的 Windows 原生文件框，弹出来就能直接选 PSD，不再是我上一版做的页内文件夹浏览。

居中也不再靠替换弹窗：把传给助手的定位锚点从“按钮位置”改成“应用窗口中心”，原生框会以窗口中心出现，不再跟着按钮跑到右下角。

批量页的文件夹入口、每稿「选择译文表…」这些都没有动。

测试站现在是 `bfdd51ec`，助手 3.7.24 没变，生产站没有动。

## 验证

出包前置 17 道门全过；tsc 0 错、lint 0 error；批量工作台合同 49 passed；UI 合同明确要求单稿使用原生文件框、禁止页内 PSD 浏览。

部署后独立复验：测试站记录的提交就是 `bfdd51ec`；运行身份回执 BOUND；健康检查 200；三个后台进程 online、重启 0。构建产物里能搜到 `selectDesignFileDirect` 和 `window.outerWidth`，说明新的居中锚点进了包。数据库没有动。

## 请点一下

打开单稿工作台，点「选择文件…」，确认：

一，弹出来的是 Windows 原生文件框，不是页内列表。
二，能直接选 PSD/PSB。
三，框不再偏右下，而是以应用窗口为中心出现。

如果它仍然按 Windows 记忆的位置弹，那说明助手没有按 owner 居中，需要发助手 3.7.25 把 `StartPosition` 固定成 `CenterScreen`；这需要另一次助手发布，不会偷偷做。
