# 薄客户端 P2 第一刀：绑定裁决上服务端（A＋P2 同批）

2026-11-03｜范围：`sourceText` 口径同批改 ＋ `compileBindings` 服务端化｜VERDICT：端点已可裁决，但**还没人调用**，用户侧零变化。

## 一句话

服务端现在能自己算绑定计划和权威摘要了——客户端以后只报「看到了什么」，判定权回到服务端。这一步是把 P3（止血）的地基先打好：没有服务端的权威 digest，P3 就没有比对基准。

## 做了什么

**① 新端点 `POST /api/local-assistant/bindings/plan`**

- 只服务持有 `assistantToken` 的本地助手（浏览器没有这个 token）；
- 收「观测 + 译文 + 人工决定」，用**同一份** `binding-core` 在服务端重算，返回 `bindingPlanDigest` 与覆盖统计；
- 限流走 DB 桶（60 次/分钟/安装，key 是安装号的 HMAC 摘要），重启不清零；
- 请求体上限 2 MB；输入级错误 400、认证失败 403、限流 429、内部异常 503；
- **当前无调用方**：助手侧还没接，所以用户侧行为一字未变。

**② 口径同批改（这条最关键）**

`binding-core.ts` 里那两个字段原本写着「不上传」。现在服务端裁决端点会接收它们，注释改成与事实一致：**图层路径与源文字作为绑定输入上行；PSD/PSB 字节仍然不上行**。对外范围不变——隐私政策第五节本来就写着「图层原文、译文与设计稿路径会上传」，公共说法一直是准的，错的是代码里的旧注释。

顺带重生成 `download/local-assistant/generated/*`（注释会传进产物），源码与产物同源断言转绿。
