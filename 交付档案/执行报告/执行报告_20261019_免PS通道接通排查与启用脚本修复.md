## 三、阻断与根因

`node scripts/pc-enable-on-machine.cjs --exe … --guid <本机 GUID>` 抛
`EPERM: operation not permitted, open '…\.tygf_session'`，
而**同一函数写备份那一步成功** ⇒ 目录可写、只有那一个文件不可写。

**根因**：`.tygf_session` 带 `FILE_ATTRIBUTE_HIDDEN`，而 **Windows 对隐藏文件拒绝 `CREATE_ALWAYS`**（Node 的 `'w'` 旗标 / `fs.writeFileSync` 正走这条）⇒ `ERROR_ACCESS_DENIED`。

产品助手 **3.4.4 就为此修过**（`docs/变更记录-本地助手3.4.4-授权持久化.md:3`），实现落在 `download/local-assistant/persisted-state.js:50-87`（摘隐藏 → 换名替换 → 恢复隐藏，并保住 ACL）与 `preparation-cache.js:12-22`。**免 PS 新写的启用脚本没沿用这套。**

⇒ 这是「三键默认全关」长期停在原地的**机制性原因**：不是没人去开，是**开不了**。

**排除法取证（逐条实测，非推断）**

| 假设 | 实测 | 结论 |
|---|---|---|
| ACL 拒绝 | 该文件 ACL ＝ 当前用户 Allow-FullControl、无 DENY | ✗ |
| 被助手/其他进程占用 | `File::Open(ReadWrite, None)` **成功** ⇒ 无任何句柄 | ✗ |
| 文件名被拦 | 同目录改名副本、别处同名新文件**都可写** | ✗ |
| 安全软件（火绒 / Defender） | Defender 服务未运行（`Get-MpPreference` → `0x800106ba`） | ✗ |
| 工具沙箱 | 换用另一条非沙箱执行路径**同样被拒** | ✗ |
| **文件自身的隐藏属性** | **摘掉隐藏属性后，同一个写入立刻成功** | ✓ |

## 四、修复内容（develop `1fe356e`，已推）

1. `scripts/pc-enable-on-machine.cjs` 改为复用 `persisted-state.js` 的 `writeHiddenStateFile`（顺带保住该文件「仅当前用户可读」的 ACL 收紧），并加**写完回读自校验**——解不开即回滚并报错提示。
2. 同片修掉第二个缺陷：时间戳备份只精确到**秒**，同一秒内二次写入会**覆盖**上一份 ⇒「可回滚备份」失效。已加撞名顺延。
3. 新增回归测试 `scripts/smoke-pc-enable-script.mjs`（6 例，**真隐藏文件跑真脚本**，含负控「隐藏文件上裸写必被拒」），挂进 `test:pc-enable` 与 `test:trust-chain` 链尾。

**验证（真实结果）**：`test:pc-enable` **6/6 PASS**；既有 pc 套件全绿（channel 7/7、scanner 4/4、observation 9/9、readiness 7/7、executor 17/17、wiring-freeze 9/9）；`smoke-local-assistant-state-persistence.mjs` 通过。

**牙齿验证**：把实现临时退回裸写 ⇒ 测试**变红**，报的正是真机那条 `EPERM`；还原后脚本 sha256 与改前**逐位一致**（`6fd7305d…`）。

**为什么此前一直没被发现**：既有 6 条 `smoke-pc-*` 全绿，但它们**从没在隐藏文件上写过**（以纯函数与 mock 为主）。**单测绿 ≠ 真机能接通。**

## 五、尚未接通——三条前提都在用户侧（我没有代替执行）

1. **完全退出本地助手**（PID 23400 `图译工坊本地助手.exe` 正在运行）。换名替换会被占用的句柄挡住；且助手不重启不会重读配置，边跑边改还会被它写回覆盖。
2. **关掉全部 `Photoshop.exe`**。通道只在**没有任何 `Photoshop.exe` 进程**时才判成 `engine`（`server.js:482-500` 按**进程存在性**判定，不看窗口）。本机现有 3 个：2 个幽灵（PID 25360 / 38620，2 MB、无窗口）＋ **1 个真身（PID 57144，90 MB，窗口标题 `未标题-1 @ 100% (图层 1, RGB/8) *` ＝ 有未保存文档，我没有碰）**。
3. **助手登录配对**。本机会话文件里 `authToken` / `assistantToken` 为空。

三条满足后，一条命令即可开：

```
node scripts/pc-enable-on-machine.cjs --exe "C:/Program Files/PhotoCraft/photocraft-cli.exe"
```
