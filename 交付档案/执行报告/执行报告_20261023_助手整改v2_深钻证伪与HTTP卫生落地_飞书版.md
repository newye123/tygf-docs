**第二件事：本机 HTTP 卫生三件（已提交 66cbb30e）**

用大白话说：

1、补了 Vary: Origin——助手的跨域许可是随来源变的，之前没告诉中间缓存按来源分开存，有串缓存的理论口子，补上了。

2、私有网络预检应答——新版 Chrome 下，公网页面调 127.0.0.1 之前浏览器会先问一句"允不允许"，不回答就拦。现在只在对方问的时候答。

3、Host 白名单——防"DNS 重绑定"这种打法（恶意网页把域名解析到 127.0.0.1 来打本机端口）。只认 127.0.0.1 和 localhost，别的来就拒。端口跟实际配置走，不写死。

诚实边界：本机上的其他程序仍能伪造请求头直连（这是接受的风险），这道闸只挡浏览器侧的重绑定，不算安全修复。
