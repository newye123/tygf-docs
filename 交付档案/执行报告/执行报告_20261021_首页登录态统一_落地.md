## 1. 结论

**登录后官网首页不再写"登录"了**：服务端在渲染 `/` 时读会话并把摘要注入页面，导航按三态画「登录链接 / 头像菜单 / 34px 骨架」。首屏**零额外请求**、不闪、**无水合告警**（真浏览器实测）。

对抗式审查改掉了方案里的三处做法（不是照抄执行）：

| 原方案 | 实际落地 | 理由（攻击编号） |
|---|---|---|
| 四处 `/api/auth/me` 收敛为一处 | **收敛为「首页 0 次 / 工作台 1 次」**，账号门仍自己取数 | X-3：授权路径吃共享乐观状态 ⇒ 会话刚被撤销的用户仍看得见工作台 |
| 登出后回原处 | **只限首页**；工作台仍跳登录页 | X-4：工作台内容是敏感面，门的取数是一次性的，不为顺滑牺牲 |
| 给 `SiteHeader` 加账号入口 | **驳回** | X-5：`SiteHeader` 只出现在工作台，而工作台自己的 chrome 里已有账号菜单 ⇒ 会变成两个账号入口 |

另外修正了审查报告里的一处误读：**英文站不用动**——`/en` 的导航里**没有登录入口**（`home-view-en.tsx:124-125` 是下载与语言切换）。

## 2. 改了什么

### 服务端

- **新增** `src/lib/auth/session-summary.ts`：把"当前用户"压成**可下发的最小摘要** `{state: anonymous|authenticated|blocked, email, emailVerified}`。**不下发** `name` / `billingPrincipalId` / `sessionId`（延续 #216 的口径）。`blocked` 判定与 `/api/auth/me` 的 403 **同口径**（`accountStatus !== 'active' || deletedAt || accessExpiresAt` 已过）。
- `src/app/(zh)/page.tsx`：读 cookie → `readSessionSummary` → 作为 props 传给 `AppShell`。首页**仍是 `force-dynamic`**（不缓存带会话的 HTML）。

### 客户端

- **新增** `src/components/site/auth-session-context.tsx`（会话 Provider，显示层的单一真相）：
  - 首帧用服务端注入的摘要 ⇒ **挂载时不请求**（首页首屏 0 个额外请求）⇒ 不闪、不产生水合不一致；
  - 状态机：`unknown / anonymous / authenticated / blocked / unreachable`；
  - **网络不可达保留上次已知状态**（P-17：不可达 ≠ 未登录，不回落成"登录"）；
  - 跨标签同步：`BroadcastChannel('tygf-auth')` ＋ `storage` 事件兜底，**广播只带事件与时间戳，不带身份数据**。
- **新增** `src/components/site/home-account-menu.tsx`（首页版账号菜单）：home-v17 风格，**不引 radix/shadcn**（别把工作台那套拖进营销页 bundle）；Esc / 点击外部关闭；`aria-haspopup`；`blocked` 态**只留"退出登录"**（不给工作台入口）；登出后**留在原地**并提示（营销页无敏感面）。
- `src/components/site/home-view.tsx`：导航三态——未知 → 34px 圆形骨架、已登录（含 `blocked`）→ 头像菜单、未登录 → 原来的"登录"链接（**位置与文案不动**）。
- `src/components/workbench/user-account-menu.tsx`：改读 Provider，**不再自己请求** `/api/auth/me`；工作台登出仍跳登录页（安全性质）。
- `src/app/(zh)/auth/login/page.tsx`："已在登录状态"那张卡的按钮（文案"前往工作台"）默认落到 `/#workbench`（尊重显式 `?next=`），不再落到营销首页。
- `src/components/site/home-v17.css`：新增 `.acct*` 样式（头像 34px、琥珀点、骨架、下拉面板），沿用首页令牌。

3. **没给 `SiteHeader` 加账号入口**——会造成两个账号入口（X-5）。
4. **用户可自设昵称**——Owner 已定"先只拆写者"（L2）。
5. **首页隐藏"申请试跑"**——L2，未获批。
6. **英文站**——`/en` 没有登录入口，无需改（顺带修正审查报告里的误读）。
