- 改动（最小 diff）：那半句改成「单批最多 12 个语种，逐语言连续执行」。**除这一句外全文未动**，其余口径核过无违规（`100%` 0 次／`越用越准` 0 次／`备案` 0 次；「在你本机由 Photoshop 执行」不含「不上传」绝对式，无需改）。
- 过程事故（如实记）：Draft.js 编辑器上，我先用整段选中替换成功去掉「平均 3 分钟」，但残留一个 `a` 字符；再用「选中该字符＋Backspace」清残留时，**Draft 把整行 20 字一起删了**（编辑器 innerText 长度 −21）。补救＝在「在你本机由 Photoshop 执行。」段末光标处粘贴 `\n单批最多 12 个语种，逐语言连续执行` 重建该行（长度 +20），随后点「更新」发布。
- 上线取证（重新加载公开页现读）：`平均 ?3 ?分钟` 命中 **0**、全文「分钟」命中 **0**、`单批最多 12 个语种` 与 `逐语言连续执行` 均 **1 次**、无残留 `执行a`；页面 URL 未变（仍是同一条内容，不是新发）。
- **教训入记忆**：在 Draft.js 这类富文本模型里做「删一个字符」的修补是不安全的——DOM range 与模型 block 不同步，退格会跨块吞行。正解＝**一次成句替换**，宁可把目标句整段重写，也不做逐字清理。
