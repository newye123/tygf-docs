# 没注册也能进真工作台：译文表真导入、检查真出结果，AI 和执行一律挡到注册

2026-10-28 · 改在 `worktrees/develop`（未提交、未推 GitHub、未部署）· 没登录就是访客

## 先说结论

你要的「真实的、用户直接就能上传点击的」做完了，不是模拟页：**访客打开工作台就能真传译文表、真看浏览器里算出来的检查结果**；一旦点到要调用模型或在电脑上干活的动作，**弹一句「为什么」再带他去注册**，而且**真的一个请求都不会发出去**。

这对你意味着什么：以前没注册的人看到的是「请先登录」一张卡片，什么也摸不到；现在他能自己走一遍「导表 → 看检查」，摸到价值再决定注不注册。

## 一、访客现在能真做什么

| 动作 | 访客 | 说明 |
| --- | --- | --- |
| 打开工作台首页 | 能 | 顶部常驻一条琥珀色说明条：哪些能真用、哪些要登录，右侧给「登录」「注册内测」两个入口 |
| 上传译文表（CSV / TSV / TXT / XLSX / XLS） | 能，真解析 | 真读文件、真出「N 个语言」，自动进第 2 步 |
| 表格规则检查（缺行、重复、空译文等） | 能，真算 | 全程在浏览器里算，不上传，不调用任何模型 |
| 下载模板 | 能 | 和登录用户同一个模板文件 |
| AI 智能检测 / 检测全部语言 / 单语重跑 | **挡** | 弹「AI 智能检测需要登录」，带登录与注册按钮（`review-step.tsx:396`、`workbench-view.tsx:1472 / :1525`） |
| AI 整理文本（粘贴文本走模型） | **挡** | 弹「AI 整理文本需要登录」，并说明 CSV/Excel 导入不调模型、现在就能用（`csv-step.tsx:235`） |
| 读取设计稿（PSD 扫描） | **挡** | 第 3 步整块换成锁卡，点按钮弹「读取设计稿需要登录」（`workbench-view.tsx:5361 / :6016`） |
| 多个设计稿（多稿模式） | **挡** | 弹「多稿模式需要登录」，且模式不切换（`workbench-view.tsx:4053`） |
| 生成文件（Photoshop 写回） | **挡** | 第 4 步整块换成锁卡（`workbench-view.tsx:6349`） |

挡的这五件，弹窗里都不是干巴巴一句「请登录」，而是各写了一句为什么——比如设计稿：**设计稿不经过浏览器，是你电脑上的本地助手在 Photoshop 里读，助手只认登录并激活过的账号**。这也是实话，不是话术。

## 二、怎么做的（三处关键）

1. **未登录不再停在门口**：账号门拿到 401 时进入「访客」状态，把工作台正常渲染出来，外面套一层访客上下文（`account-gate.tsx:60 / :139-140`，访客模式本体在 `guest-mode.tsx`）。
2. **激活门对访客整体跳过**：这里踩到一个坑——组件里的「提前返回」只能挡住界面，挡不住页面加载时自动跑的那段检查，访客仍会空发一次「查我的内测资格」请求然后吃 403。所以守卫写进了请求之前（`activation-gate.tsx:141`），实测访客全程 0 条邀请码请求。
3. **工作台拆成「外壳 + 内层」**：访客上下文由账号门渲染，读它的必须是它的子组件。原来是同一个组件自己渲染又自己读，永远读到默认值——访客界面压根不出现。这是本轮在浏览器里实测才抓到的问题（`workbench-view.tsx:384-394`）。

服务端一个字没改：访客真要硬调接口，照样 403。界面的作用只是把「点了没反应 / 冒一串英文错误」换成「说清为什么 + 带你去注册」。

## 五、要你拍两件事

1. **要不要推到测试站让你在手机上/别的电脑上点一遍？** 要的话我按规矩来：先推 GitHub，从 GitHub 取代码更新测试站，测试通过再说生产。现在什么都没推。
2. **要不要给访客一份「演示样稿」，让他看到第 3、4 步长什么样？** 现在第 3、4 步只能看到锁卡，看不到对账矩阵和生成结果。加样稿的话，访客能看见「做完了是什么样」，但要额外做一套只读的假数据界面，成本比现在这一刀高。
