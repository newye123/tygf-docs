# 深圳个体工商户营业执照 · 办理作业面

> 2026-10-18 · 所在地深圳 · 结论：**一两天、零成本、不到现场**，唯一真门槛是地址（25 位房屋编码）
> 配套可勾选版：`办理清单_20261018_深圳个体工商户营业执照.html`（勾了会记住，办到哪儿算到哪儿）

## 先定一件事：地址走哪条

**注册地不是自由选的，是你选的地址决定的。**《个体工商户条例》第八条与《个体工商户登记管理规定》第九条都写明：向**经营场所所在地**的登记机关申请设立登记。所以"用老家地址注册"＝在老家县/区市场监管局登记，走老家的材料要求，与深圳的编码体系无关；用深圳地址注册＝在深圳登记。

只有一条例外允许"按人"而不是"按场所"选：第九条第二款——**仅通过网络开展经营活动的平台内经营者**，向**经营者住所所在地**登记机关申请；而第十条规定住所＝户籍记载居所，**经常居所与记载居所不一致的，以经常居所登记**。也就是说，如果哪天你是在微信小程序/某宝这类平台内开店卖，你可以直接用深圳的经常居住地登记、免交经营场所使用证明。但自建站直销不属于"平台内经营者"，这条现在用不上。另注意第十条第二款：共享地址、不具备实际居住条件的集中办公区等集群登记场所，**不得**作为经营者住所登记（集群注册只能当经营场所）。

深圳的三个地址选项，必须带 **25 位房屋编码**（深圳统一标准地址库），没编码系统直接拦，提交都提交不了。

- **A. 自己住的房子（自有或租）** — 零成本。深圳允许住宅登记为经营场所，但要补"住改商"材料：业主同意书、社区/街道场地证明。租房需要房东配合签字。
- **B. 有红本（房屋租赁凭证）的地址** — 材料最硬，后续申请支付通道、ICP 备案都顺。
- **C. 商务秘书企业挂靠 / 集群注册** — 几百到一千多一年。必须挑能给真实房屋编码、且能配合上门核查的。
- **D. 老家的自有房（注册在老家）** — 完全可行，且不用在深圳折腾房东。代价见下。

### D 方案的两道前置与一个敞口

**前置一：农村自建房通常没有房产证。** 要用村委会或乡镇政府出具的**房屋权属／使用证明**替代（写明位置、用途、权属无争议、盖章），地址须能具体到"村、组、号"。

**前置二：下列房子不得作为经营场所**（各地表述略异，但清单普遍存在）：未取得土地/规划/建设手续擅自新建改建扩建的、未通过竣工验收或应备案未备案的、擅自改变结构危害安全的、鉴定为 C 级或 D 级的危房、已纳入政府征收拆迁范围的、超出批准期限的临时建筑。办之前让家里人跑一趟县局问清单最省事。

**要认的敞口**：《个体工商户登记管理规定》第十二条第二款——**个体工商户在其登记机关辖区以外从事依法需要登记的经营活动的，应当另行设立个体工商户**。人在深圳经营、执照在老家，条文上就是这一句。纯线上经营实务中被查得极少（把握度中），但它是条文不是空气。税务侧同理：个体户税务管辖基本遵循"生产、经营所在地"原则，两处以上经营机构可选择并固定向其中一处申报，所以注册地与经营地分离在税法上是有争议的（学界与实务均有指出），实务按注册地核定走。

**D 方案反而更好的一点**：最高频的异常触发机制是"登记机关向登记地址两次邮寄专用信函（间隔 15–30 日）无人签收 → 认定通过登记住所无法联系 → 列入经营异常名录并公示"。老家是自家房子、家里人收信，正好把这条堵掉；而在深圳用挂靠地址，这一条是常年敞着的。

⚠️ 深圳的区级差异要注意：**部分区只接受"房屋编码"这一种填法**，不接受手写文字地址；用 C 方案的话，先问服务方能挂靠到哪个区、那个区认不认。

**排除掉的一条**：深圳"网络经营场所"那一支你用不了——市政府官方答复把它限定为电商平台的平台内经营者，且额外要求申请人是深圳户籍或持深圳居住证。图译工坊是自建站直销，不属于平台内店铺。

## 填报前先备齐（一次性填好，别中途找）

1. 房屋编码（25 位）——门口贴的二维码可扫，也可在深圳标准地址库按关键字检索带出
2. 字号 2–3 个备选（防重名）；不想起名就选"无名称"，以经营者姓名登记，驳回风险最低
3. 本人身份证、手机号、常用邮箱
4. 资金数额：个体户填 1 万元左右即可（无需验资）
5. 组成形式：选**个人经营**（别选家庭经营，会牵扯家庭成员信息）
6. 经营范围：从系统"规范表述目录"里勾选，**不能自己造话**。建议选：软件开发；信息技术咨询服务；计算机系统服务；数字内容制作服务；（按需加）软件销售

⚠️ 经营范围里**不要写"互联网信息服务"**——那会招来 ICP 许可相关核查，而 ICP 许可证（经营性）要求境内公司＋注册资本 100 万以上，个体户根本申请不了。你自己卖自己的软件只需要 ICP **备案**，不需要许可证，两者别混。

## 办理：两条路径

### 路径一 · AI 申报（最快，官方宣传"最快 3 分钟提交"）

微信关注「**深圳市场监管**」公众号 → 公众服务 → **商事登记微申报** → 选 **AI 申报**（应用叫"深小注"）→ 提供经营场所房屋编码 → 对话里说出你想用的名称和从事的行业 → 系统自动推荐名称、匹配经营范围、自动填表 → 实名认证 + 电子签名 → 提交。

### 路径二 · 普通微申报（逐步手填，可控）

同一入口登录后选「**个体设立**」，顺序是：

1. **实名认证**：核验手机号 → 上传身份证正反面 → 实人检测（视频色谱/人脸识别，必须本人，第三方无法代做）
2. **名称自主申报**：字号录入（先点查询，逐个查个体/企业/市场主体相似字号，有完全同名必须改）→ 行业用语 → 组织形式用语（如"工作室"）→ 经营者情况 → 名称组合方式提交并勾选承诺
   - 名称格式：行政区划＋字号＋行业＋组织形式，例："深圳市南山区图译工坊软件开发工作室（个体工商户）"。"（个体工商户）"字样是规章强制的。
3. **登记信息填报**（六步）：基本信息（经营场所录房屋编码 → 点"导出地址"自动带出行政区和街道）→ 经营者信息（默认取登录账户）→ 经营信息（经营范围勾选）→ 附加信息 → 多证合一/刻章（个体户不刻章，按需选）→ 邮寄地址及信用承诺
4. **电子签名 + 提交**：深圳已支持微信扫码进入**音视频双录**完成签名（人脸识别＋语音确认），无需银行 U 盾等介质、无费用；也可用个人 U 盾数字签名
5. **等审批**：承诺办结 **1 个工作日**（法定 20 日，实际多为即办件），到现场 **0 次**，通过有短信通知

### 拿证

审批通过后到「**深圳标准院**」公众号完成邮寄确认，或选自助领证。EMS 是**到付**（个人实测 18 元）。电子营业执照在微信/支付宝"电子营业执照"小程序里领，与纸质同法律效力。

## 拿到执照之后按顺序接上

1. **税务**：30 日内做税务登记/信息确认（深圳电子税务局有开业一网通套餐）。小规模纳税人月 10 万（季 30 万）内免增值税执行到 2027 年底，现阶段基本零增值税；个体户按"经营所得"交个税，深圳多走定期定额核定，税负轻。具体核定方式以主管税务所给的为准。
2. **支付通道**：可申请支付宝/微信支付的**官方商户号**，个体户结算到经营者个人银行卡、**不需要开对公账户**——这是深圳路径上个体户比公司省事的最大一点（公司开户要实际地址上门拍照）。
3. **ICP 备案**：个体户按"企业"类主体备案，通过服务器接入商提交，需执照＋经营者身份证＋人脸核验，广东省管局 20 个工作日内。域名持有人最好与主体一致。
4. **把对外条款解了锁**：主体全称和统一社会信用代码到手后，条款里那 10 处"主体待公示"占位就能填实、页眉"内测阶段文本·主体与备案待公示"那行状态标可以撤——按我们自己定的规矩，那行没去掉之前不允许称正式条款。

## 坑（按代价排序）

- **假地址 / 无备案编码地址**：深圳有网格实地巡查，被查出直接进"经营异常名录"并对外公示——那比不办执照还难看，而且解异要跑窗口。
- **经营范围写了"互联网信息服务"**：招来你拿不出来的许可证要求。
- **字号没先查重就往下填**：走到后面一步才发现同名，整段重来。
- **以为个体户能"升级"成公司**：不能。要公司只能新办一家。出海收款（Stripe/Paddle 类）要公司主体，个体户进不去。
- **拿自己官网域名当经营场所**：规章明文排除"仅提供域名访问/虚拟主机、不提供实际交易服务的平台地址"。
- **EMS 到付**：留错电话或没人收，二次投递要再等。
