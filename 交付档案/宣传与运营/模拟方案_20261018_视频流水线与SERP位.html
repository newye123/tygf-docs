停投判据（写死）

每支片发布后 30／60／90 天取三个数：① YouTube 站内搜索与推荐带来的观看 ② 引荐到 /en 的会话数 ③ 豆包／Perplexity／ChatGPT Search 是否引用该视频。任一连续两拍为 0 ⇒ 停投，不许用"再拍 10 条"追加预算。

为什么不能拿"排名提升"当验收

新页面 1 年内进 Top10 仅 1.74%，Top10 中 72.9% 存在超 3 年；且 YouTube 描述外链抬蓝链没有任何官方机制说明或对照实验。把排名写进验收口径＝必然造出一句无法证伪的话。

取数边界

SerpBear 只查 Google（第三方 SERP API 取数，ScrapingRobot 免费 5000 次/月或 Serper 需 key）；要查 Bing 得另件（OpenSERP MIT，自托管多引擎，但直连爬 Google 有封禁与 ToS 风险）。收录探测用官方 Custom Search JSON API 100 次/日，注意 Site-Restricted 版已于 2025-01-08 停服、site: 计数只作趋势。
