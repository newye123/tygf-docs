先给结论：你这个需求——同一张图（同一个 PSD）做 200 份，只有文本框里的文字要换，换的文字在一张 Excel 表里——Photoshop 自带的「图像 → 变量 → 数据组」就能做完，不用装任何付费工具。下面先给最短路径，再给这套办法**不管**的几件事，那才是很多人"跑通了但交付照样翻车"的原因。

一、最短路径（PS 自带，六步）

1. 把要替换的文字单独做成一个文字图层（一张图一个图层，别混在背景里）。
2. 图像 → 变量 → 定义，给这个图层定义一个变量名，比如"标题"。
3. Excel 里第一行写这个变量名，下面每行写一个要替换的内容；除此之外表格里别放备注、别留合并单元格。
4. 把表格另存成文本文件，在 PS 里图像 → 变量 → 数据组，导入它。
5. 打开"预览"逐条翻一遍，确认变量和文字对上了。
6. 文件 → 导出 → 数据组作为文件，选个空文件夹导出，得到 200 份；要 PNG/JPG 再套一次文件 → 脚本 → 图像处理器批量转。

这个题下已有的几个回答把步骤讲得更细（包括 macOS 上的坑和"变量名称过多"那个报错的成因），可以先照着走。

二、这套办法不管的六件事

1. 同名图层和重复图层名。变量是按你定义的那个图层绑的，一旦稿件里有很多同名图层、或者后来有人复制了一层改了内容，很容易出现"导出的确是 200 份，但换错了层"。多文件的稿子尤其常见。
2. 栅格化文字、智能对象里的文字、已经转成形状的文本，PS 也写不进去。这三种只能改回可编辑文字，或者手工做，任何自动办法都一样。
3. 文字变长放不下。中文换英文、换德文西文，长度普遍涨三成以上。变量数据组不做排版校验，它是照原样写进去，超了就裁掉或者压到框外，导出的时候不会提醒你。
4. 占位符和专名。像 {name}、%s 这种变量占位、注册商标符号®™，最容易被"顺手一起改掉"，改错了要到上线才发现。
5. 没有回读核对。PS 导出完告诉你"跑完了"，但不会告诉你在第 137 份里那个图层其实没被写进去。要确认只能自己抽查，200 份你抽不动。
6. 没有可复查记录。交付出去之后客户问"这句怎么没换"，你手里没有一张能追到具体图层的清单，只能重跑一遍。

三、如果你的场景是多语言（一套稿出好几个语种），上面第 3 条会放大成三个新问题

目标语言需要的字体本机有没有装（缺字体轻则方框，重则替换失败）；阿拉伯语、希伯来语要从右往左排版；同一个词在不同语种里的译法要一致，这个要靠术语表约束，而不是靠"每次都翻一遍"。

四、什么时候才真的需要工具

如果只是 200 份同模板换个文字，PS 自带方案就是最优解，别花钱。需要额外工具的是这三种情况：要一次出 N 个语种 × M 个文件的矩阵；要求每处写入有校验、写不成要能恢复；交付要一份能复查到图层的报告。
