## 6. 音乐与音效

### 配乐：为这部片子代码原创

- 方法：Python 标准库 + FFmpeg 波形合成，参数与随机种子固定、源码留在工程里可复现（`audio-sourcing.md:13-31`，示例源码 `assets/audio/codepilot-score-example.py`）。不调用音乐生成模型、不下载现成 BGM。
- 气质：工具感、克制、干净，偏"工作台在推进"，不要营销号式鼓点。**116 BPM / 45 秒**，4/4，A 小调倾向但落在大调和声上收（要一点"事情办完了"的确定感）。
- 分层：和弦铺底 + 短音旋律 + 贝斯 + 合成鼓点，四轨独立包络与声像；**叮咚/点击绝不写死进 BGM**，否则后面没法分别混音和做让位。
- 段落对分镜：1 迅速建立 → 2–3 减密度（让观众读字） → 4–5 和声推进（揭晓检测/三态） → 6–7 满编（就绪 + 执行） → 8–9 抽掉鼓点留旋律（证据段要安静一点） → 10 完整收束，尾音不淡出糊掉。
- 改变时长/BPM 时统一按 beat/bar 重算所有音符与鼓点范围，改完检查越界与尾音（`audio-sourcing.md:29`）。

### 音效：先找合适的，缺哪类才补哪类

按 `audio-sourcing.md:32-48` 的顺序：先查来源清楚的素材库（含 Pixabay 音效），逐类少量候选、听实际音频不凭标题判定；只有这一类确实没有合适/许可不明/取不到，才用 skill 内置的 11 个原创 WAV，并记 `method: bundled-original` + 真实回退原因。

| 动作 | 需要的声音 | 首选 | 内置回退 |
| --- | --- | --- | --- |
| 拖入表格 | soft drop / 短 whoosh | 素材站搜索 | `whoosh.wav`（落点在文件中间，要设 `syncOffset`） |
| 语言页签切换 | UI pop / soft toggle | 素材站 | `toggle.wav` / `pop.wav` |
| 检测进行中 | 短簇键入 | 素材站 | `typing.wav` |
| 建议/需决定出现 | 轻巧提示音 | 素材站 | `pop.wav` |
| 点击确认 | 短而清楚的 click | 素材站 | `click.wav` / `click-alt.wav` |
| 回读成功 / 通知 | 可识别的 ding-dong，拖尾不能盖住下一句说明 | 素材站 | `ding-dong.wav` |
| 报告落定 | 柔和收束 | 素材站 | `resolve.wav` |
| 收尾字标 | gentle logo chime | 素材站 | `success.wav` |

### 混音

`scripts/mix_audio.py plan.json` 负责对齐 `audio.cues`、关键音效期间压低音乐（ducking 默认开）、分别输出 `music-ducked.wav` 与 `sfx-stem.wav` 便于单独试听，并落 `evidence/audio-mix.json`（含卡点误差）。我会分别听三条：纯音乐、纯音效、混完的，再看成片。
