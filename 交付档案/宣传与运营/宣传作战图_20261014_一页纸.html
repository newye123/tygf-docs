图译工坊怎么宣传：一个轴心、三类人、六个阵地

给市场负责人看的计划。所有物料只重复轴心那一句；所有渠道只服务三类受众之一；所有动作都带单一判据，不过则砍。

轴心 × 受众 × 阵地 Demo 为内容之母 90 天三段节奏

01轴心：一句话打天下

Axis · 所有口径的源头
把已有的译文批量落进 PSD 文字图层——多语言设计稿，一次交付可编辑源文件。
"Batch-localize PSDs into up to 12 languages, keep every text layer editable, and hand your client an auditable delivery package."
为什么是这句：单张改写打不过免费动作（Quicker）和 ¥75 工具（ImageTrans），翻译打不过免费机翻。我们唯一的站位是「批量 × 一致 × 可验收」——卖的不是回写动作，是交付产能。

02三类受众，三套故事

同一产品，三种讲法。永远先确认对话的人是谁，再决定讲哪套。

L1 收入主力 付费承诺

本地化外包 / DTP 车间 / 翻译公司 / 接外包的设计团队
「你的 DTP 车间产能：20 个 PSD × 6 语言，人工 50 人日 vs 一次配置批跑。译文你定稿，我们负责落版和验收包。」
阵地直接邀约 + 报价单 + 现场 demo
判据5-8 家带报价试用；≥3 家付费承诺（≥1 家非自家）
钩子报价单上写「上一单 20 PSD×6 语言收多少你直接刷卡」

L2 案例来源 可公开案例

跨境品牌 / 电商设计团队（持 PSD、按批次交付的精品层）
「素材天然出海一次交付；亚马逊主图豁免自动翻译留下的手工活，我们批量吃掉。」
阵地知无不言 / 雨果网 / 卖家之家 / B 站
判据3 个可公开案例（带真实数据）
钩子「120 SKU / 1200 张 / 半年 3.2 万元」的真实成本结构

L3 漏斗层 不给收入指标

长尾卖家 / 普通设计师
「别再一张张改：批量表丢进去，矩阵出图，源文件还能编辑。」
阵地B 站演示视频 / 知乎长文 / 免费额度
判据试用跑通率；月度观看（K5：6 个月 <1000/月停投）
钩子免费试用 + 「改完能不能用」实录，不吹

03内容之母：20 分钟真机 demo

所有素材都从这一个 demo 长出来：录屏、报价单、邀客话术、案例帖。演示是唯一的信任捷径。

STEP 1

上场

客户自己的真实 PSD + 真实译文表（不是演示稿）。10 分钟讲清定位：不做翻译、只落版、可编辑。

STEP 2

跑批

上传 → 选语言（≤12）→ 本地助手批跑。计时开始——「20 分钟」是钩子数字，实测记录。

STEP 3

翻包

交付三件套：PSD（文字层可编辑）+ JPG 预览 + 核对报告。翻看报告里的未命中清单——如实展示是加分项。

STEP 4

报价

当场出价：按批次报（张数 × 语言数），不问「你觉得贵吗」，问「这单你刷卡多少」。

视觉锤

每支视频/每篇帖子固定用同屏对比收尾：左边「手工逐层改」（录真实操作，别加速），右边「批跑矩阵出图」。对比越朴素越有说服力。

不做的（与做同等重要）

不投冷启动付费广告（低客单桌面工具算术不成立）· 不做 SEO 内容农场（首年自然流量趋 0）· 不与免费功能打消费级功能战 · 不提前挂牌服务（跳过判定门）· GitHub 不做引流 KPI（只做尽调可信度）。

0590 天三段节奏

Day 0-30

备弹药 + 自家首跑

宣传版 README 上线（替换 v0.1 版）· 报价单 + demo 脚本 + 邀前检查表备齐 · GitHub 两辅仓上线 · 自家公司 dry-run 拿到第一组真实数据（张数 × 语言数 × 时间 × 返工率）。这一阶段不邀客——装/配对/链路三卡点先关。

Day 31-60

邀客 + 开案 + 内容开更

5-8 家 L1 定向邀约（邀函+报价单+demo 四步）· 首批 ≥3 家真实批次跑完 · B 站第 1 条上线 · 知乎长文发布 · 私域群建起来。Day 90 判定门从邀客日起算。

Day 61-90

案例化 + 判定

3 个可公开案例成稿 · 定价实验读牌（双形态 A/B + Van Westendorp 四问）· 判定门三选一：通过→加码；半通过→观察+Plan C 并行；不通过→Plan C 转默认路线。

07禁说清单（对外口径红线）

  • 禁说：「全语言 100% 正确替换」（真实批次有未命中层）·「支持 20 种语言」（生产上限 12）·「OCR 图片识别」「macOS 即将支持」（无实现）·「数据不出本机」总括（必须写「设计稿文件本体不出本机」并附边界：图层文字/译文上云）· 任何客户真实素材图。
  • 可说：12 语言 · Windows + Photoshop · 四步流程 · 交付三件套（PSD 可编辑 + JPG + 核对报告）·「本体不出本机」带边界 · 自家实测的时间/张数数据（不注水）。
