# 测试机操作卡：开免 PS 通道 + 判三个 P0（2026-10-19）

> 适用：本机（有 Photoshop、有本地助手、有引擎）。**全程不动站点、不动生产。**
> 本卡每条命令均已实测可跑（`--status` 已读出三键全关）。

---

## 第 0 步：确认现场（30 秒，只读）

```bash
cd "F:/工具开发/图译工坊内测版/worktrees/develop"
node scripts/pc-enable-on-machine.cjs --status --guid 19ee9b79-02f0-4c67-b62a-54a1df6fc399
```

预期输出（当前真实状态）：

```
[pc-enable] 会话文件：...\download\local-assistant\.tygf_session
[pc-enable] 当前三键：pcExecutorEnabled=false pcExePath=(空) pcExeSha256=(空)
```

---

## 第 1 步：三条机器侧前提（**只有你能做**）

| # | 动作 | 为什么必须 |
|---|---|---|
| 1 | **完全退出本地助手**（托盘右键退出，不是关网页） | 助手持有 `.tygf_session` 句柄，不重启不重读配置 |
| 2 | **关掉全部 `Photoshop.exe`** | 通道按**进程存在性**判定（`server.js:482-500`）：只要有一个 PS 进程在，就恒判 `ps`，引擎永不接管。**连幽灵进程也算** |
| 3 | **助手登录配对** | 会话里 `authToken` / `assistantToken` 为空时，扫描链路第一步就断 |

查 PS 是否真的全关（**必须为空**）：

```powershell
Get-Process -Name Photoshop -ErrorAction SilentlyContinue | Select-Object Id, ProcessName
```

> 幽灵进程杀不掉（安全软件拦 kill）时：重启机器是最省事的解法。

---

## 第 2 步：开三键（一条命令）

```bash
cd "F:/工具开发/图译工坊内测版/worktrees/develop"
node scripts/pc-enable-on-machine.cjs --exe "C:/Program Files/PhotoCraft/photocraft-cli.exe" --guid 19ee9b79-02f0-4c67-b62a-54a1df6fc399
```

先干跑看要写什么（推荐）：

```bash
node scripts/pc-enable-on-machine.cjs --exe "C:/Program Files/PhotoCraft/photocraft-cli.exe" --dry-run --guid 19ee9b79-02f0-4c67-b62a-54a1df6fc399
```

写完会打印「已打开免 PS 通道」，并在同目录留一份备份（撞名自动顺延，不会覆盖）。

**然后重新启动本地助手**（不是刷新网页）。

关回去：

```bash
node scripts/pc-enable-on-machine.cjs --off --guid 19ee9b79-02f0-4c67-b62a-54a1df6fc399
```

---

## 第 3 步：验证通道真的切到引擎

启动助手后，在工作台跑一个真实 PSD 任务，看扫描结果里的 `engine` 字段：

- `engine: "photocraft"`（或改名前的新标识）⇒ **引擎通道生效**
- `engine: "ps"` ⇒ 还有 PS 进程在，或旗标没生效

---

## 第 4 步：判三个 P0（**不用开助手，直接用 PS 打开文件**）

夹具已在：`%TEMP%\tygf-typeedit-probe\`

1. 用 Photoshop 打开 **`out.psd`**（6,168,239 B）
2. 找文字层 **548**（层名已同步为 `TYGF-PROBE-99`）
3. 双击进入文字编辑，看框里显示什么

| 现象 | 结论 | 处置 |
|---|---|---|
| PS 打不开 / 崩溃 | **`#6968` 复现** | 写回绝对不能开放 |
| 能开，文字层显示 `79.6mm` | **`#6971` 复现**（静默错误） | 写回不能开放，用户会拿到没改的稿 |
| 能开，文字层显示 `TYGF-PROBE-99` | `#6971` 在当前引擎**未复现** | 可进入 C2 评估解冻 |
| 对齐/行距/缩进明显变了 | **`#6129` 的表征** | 记录后并入同一判决 |

对照件：`in.psd` 是原件（靶层原文 `79.6mm`），`in.png` / `out.png` 是引擎压平渲染图。

## 附：本轮已确认的事实（避免重复劳动）

- **授权**：引擎上游 `storytold/photocraft` 是 **MIT OR Apache-2.0**，可分发可改名；但 Apache-2.0 要求随附 `LICENSE`+`NOTICE`（当前安装目录没有），且 ArtCraft 商标资产必须移除。
- **测试站不必重部署**：`e8f8452..1fe356e` 在产品面（`src/` `download/` `prisma/`）**零差异**，只差文档和这个运维脚本。
- **三键此前从未真正打开过**：`.tygf_session` 带隐藏属性，Windows 拒绝对隐藏文件 `CREATE_ALWAYS`，旧脚本裸写必 EPERM。`1fe356e` 已修，本卡用的是修好的版本。
